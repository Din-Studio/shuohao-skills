# MiniMax H3 模型适配说明

学习来源：本仓库既有 H3 技术交接实践。写作与审核统一遵守 creation-prompt.md；本文件不另设正文骨架、语言规则或禁人名规则。

- 默认中文五部分模板，显式英文叙述也保留固定中文字段与素材全称。
- 图片按 images 顺序使用 @图片N，本地计划保留有序文件；提交前按实时 schema 绑定，不能假设模型原生识别任意引用标识。若接口要求改写引用，先修改工作单并重新审核，不在批准后静默变换。
- 本链路是整段身份／环境参考，不是关键帧按秒对齐。不加入 Picture 对齐指令、逐镜时间码、<d> 标签或说话人编号。
- 声音直接写在事件发生处，区分当场对白、画外声音、内心声音及实际能听见的角色。无配乐的固定结尾不取消剧情中的现场声。
- 现有离线时长快照为 5–15 秒，分辨率参考 768p／2K。快照不是实时能力或价格承诺；最终提交前发现 schema 与价格，不截短故事适配上限。
- 模型能力无法满足提示词要求时回报，不恢复旧 shots/ambience 骨架，不自动换模型。
