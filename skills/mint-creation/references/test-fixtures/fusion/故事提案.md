# 潮汐电台：先确定故事

停航夜，值班员按规程广播封港通知。通知没有宣布救援成功。画面离开播音室后，同一次广播仍在空走廊继续。广播结束后，备用接收机重播同一句通知，这是原剧本明确发生的第二次发声。最后只展示空码头，不推断失联船员已经获救。

非发声背景：值班员的弟弟在船上。这只指导克制的表演，不得增加呼救、旁白或提前团聚。字幕是封港通知，不属于人物台词。蜂鸣是客观声音。

验收：同一次广播跨镜、跨段、跨场延续，但只拥有一个正文坐标与一次估时；备用机的同文广播另有来源位置，必须另行认领。空码头材料独立，不应导致前三段批准失效。本夹具不生成图像或视频。值班员以 C01 作为无台词可见人物；旋钮、备用接收机、救生圈分别以 P01/P02/P03 交接。原文仅被提及的弟弟不作为可见人物。四个地点分别保持 S01–S04。
