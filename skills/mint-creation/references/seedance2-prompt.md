# Seedance 模型适配说明

学习来源：本仓库既有火山引擎《Doubao Seedance 2.0 系列提示词指南》学习记录（https://docs.volcengine.com/docs/82379/2222480）与技术交接实践。本轮未重新在线核验官方能力。写作与审核统一遵守 creation-prompt.md，不另设主体标签、括号台词或逐镜骨架。

- 默认中文五部分模板。对象全称后紧跟 @图片N，编号与 images 上传顺序一致。不强制 <主体N> 标签或 {} 台词符号。
- 固定镜头参考必须完整保留，其中“禁止单个分镜超过3秒”是全局策略。除完整固定首行以外，仍不写数字秒数、秒数区间和时间码；使用事件先后表达，不逐事件钉秒。该约束不证明成片镜头时长合规。
- 人物多视图可能被识别为多个主体。按本段风险在负面提示词中具体防范身份互换、重复人物等问题；不要在批准后的 manifest 中换图。需要替换参考图时，更新正式材料并重新审核。
- 优先精简实际素材，但不统一套用其他工作流的图片／音频／视频数量上限。当前仅提交静态图片，不能虚构音频或视频引用。
- 离线时长快照：seedance2.0／fast／mini 为 4–15 秒，seedance2.5 为 4–30 秒；creation 的 maxSegmentSeconds 仍单独生效。不因为新规则就自动改成 30 秒。
- 提交前发现实时 schema、限制与价格，保持已批准的素材顺序与提示词。不能假设接口接受 @图片N 或 negative_prompt；需要调整先回到工作单审核，不静默删改或换模型。
