# 剧本 v4 报告约定

冷灰纸面、铁锈红强调、离线单页，零网络依赖。文本、属性和内嵌 JSON 正常转义，JSON 中小于号转成 \\u003c。导出保持原输入，不添加统计、默认值或评审结论。

## 信息顺序

可选来源版本与覆盖 → 分集正文及非发声说明 → 当前计划与关键事件落点 → 可选问题回答 → 局部引用与台词本 → 估时及有效参数 → 结构问题与内容评审状态。

展示来源引用、声音语义和必要转译记录；非发声 notes 与实际 flow 分开。没有策略选择快照、默认配置或关闭规则列表。可选计划、问题和认领缺省时不建立空表。openingBeat 缺省明确“未标注开场落点；未核验开场表达”，不能把展示第一拍当作人工核验。结束坐标从正文计算。

有大纲时展示当前实际加载的计划，不读取剧本旧副本。没有大纲不猜测节点类型或全剧结局。合法范围不代表节点已经表达；无效范围显示不可用，不能显示零秒。

名称与音色只沿 script.assetMappings 的有效 confirmed 映射读取 cast/art，不按同 ID 或同名回退，也不读取 outline 资产。身份元数据中同时展示局部标记与目标 ID；正文台词的说话者仍显示局部标记，不把资产姓名插入原文表达。未知保持局部标记。映射表展示状态、依据、出处、资产摘要及文档版本，不改写正文原句。

## 状态

检查使用 pass/fail/skipped。warn 的 fail 显示提醒，不计通过、不阻断。缺少上游为 skipped/missing-upstream，骨架未完成为 stage-incomplete。未指定制作依赖且无映射时联合对账为 skipped/no-production-dependencies；缺少任一可选上游时联合对账为 skipped/missing-upstream。局部结构通过不是制作映射通过。基础错误阻断，粗略估时偏差提醒。来源未读取为 skipped/not-performed；实际原件缺失或变化为失败，不能跳过。targetSeconds 未确认时不显示虚构数值；制作前确认目标是单独阻断检查。

始终声明内容评审未执行。读取指南或字段完整不能生成内容质量结论。创作要求变化后重新阅读正文评审。

## 交互与语言

中英 UI，不翻译正文。分集双列、窄屏单列，认领并排区域窄屏改为上下排列。正文支持折叠；坐标链接定位实际节拍。台词复制与可选音色提示保留，特殊 delivery 在台词本展示。

打印前展开 details，之后恢复。导出采用 Blob 并延迟撤销 URL。派生 HTML 不进版本控制。assets/report.webp 仅作示意，不是验收证据。
