# 剧本 v3 报告约定

冷灰纸面、铁锈红强调、离线单页，零网络依赖。文本、属性和内嵌 JSON 正常转义，JSON 中小于号转成 \\u003c。导出保持原输入，不添加统计、默认值或评审结论。

## 信息顺序

分集正文 → 当前计划与关键事件落点 → 可选问题回答 → 场次资产与台词本 → 估时及有效参数 → 结构问题与内容评审状态。

没有策略选择快照、摘要、覆盖路径或关闭规则列表。可选计划、问题和认领缺省时不建立空表。openingBeat 缺省明确“未标注开场落点；未核验开场表达”，不能把展示第一拍当作人工核验。结束坐标从正文计算。

有大纲时展示当前实际加载的计划，不读取剧本旧副本。没有大纲不猜测节点类型或全剧结局。合法范围不代表节点已经表达；无效范围显示不可用，不能显示零秒。

## 状态

检查使用 pass/fail/skipped。warn 的 fail 显示提醒，不计通过、不阻断。缺少上游为 skipped/missing-upstream，骨架未完成为 stage-incomplete。基础错误阻断，粗略估时偏差提醒。

始终声明内容评审未执行。读取指南或字段完整不能生成内容质量结论。创作要求变化后重新阅读正文评审。

## 交互与语言

中英 UI，不翻译正文。分集双列、窄屏单列，认领并排区域窄屏改为上下排列。正文支持折叠；坐标链接定位实际节拍。台词复制与可选音色提示保留，特殊 delivery 在台词本展示。

打印前展开 details，之后恢复。导出采用 Blob 并延迟撤销 URL。派生 HTML 不进版本控制。assets/report.webp 是历史截图，不是 v3 验收证据。
