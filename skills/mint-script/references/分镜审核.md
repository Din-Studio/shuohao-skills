# 分镜审核

## 任务

在独立上下文审核一份分镜的质量。逐段对照剧本 JSON（解析任务同时对照原件），再连起来检查整场与整集。以剧本、场次 notes、已确认的上游计划和制作决定为准。只提交审核结论和可执行的返修意见，由分镜作者修订原稿。

工具已经检查过格式：场次覆盖、段号、节拍归属、本段剧本逐字一致、字段名与顺序、必填字段、占位符、复写配对与不含台词、台词估时与单段上限。审核把精力放在工具无法判断的内容上；仍然可以指出看到的格式问题。

## 质量审核

1. **原文和叙事。** 核对「本段推进」是否写出这段带来的具体变化。「必须呈现的信息」只列观众必须看见或听见的关键事实、因果和揭晓时机，并且与剧本节拍、事件认领和 notes 中的限制一致。补写的细节应与原文、已确认的前情和资产状态相符，不新增剧本没有的事实、选择或结果。段内切镜和运镜由视频模型决定，分镜里出现逐镜机位或运镜时指出。
2. **拆段和时长。** 检查段界是否切断应连续呈现的行动、对白与反应。相邻内容合并后能自然演完、符合上限，且仍能交代关键转折、悬念和时空变化时，提出合段意见。短段能独立承担明确的叙事作用时可以保留。按自然表演节奏估算对白、动作、停顿和段首复写，同时发生的部分只计一次。预计单段超过上限时，指出导致超时的内容和可供重新划段的剧情节点。
3. **段间连续性。** 逐对核对段尾和下一段开场的时空、站位、朝向、关键目光、姿态、接触、持物手和伤势等与剧情有关的状态。下一段开场应能独立读懂。只接续动作结果时，检查结果是否写在段首状态、复写字段是否留空。安排复写时，检查是否只保留剪辑所需的最短可辨认动作，下一段是否从复写起点开始、在复写结束后自然进入本段剧本。换时空时分别记录各自状态，回到原时间线时核对离开时的状态和已发生的变化。跨集时只沿用原文明确的状态，缺集不补写中间经过。
4. **字幕、台词和声音。** 核对后期标注的依据、文案和出现时机，检查是否提前揭晓身份或剧情。跨集人物和场景标注按已有结论核对。本场剧本足以确定的时空标注和剧情说明，按本场内容核对。已有定稿译文时，核对台词对照中的说话人、语言及地区、中文原句和实际发声台词。环境音检查持续和变化，音效检查触发点，背景音乐检查类型或情绪风格及剧情起止点。三项都应符合本段情节，无合适内容时可以填「无」。剧本 sound 节拍与 audio 的发声方式、听者不能被改写。
5. **参考素材。** 按每段实际需要的人物及其状态、场景和道具，检查是否存在资产阶段没有提供、又必须有参考才能生成的对象。缺少时写入待确认事项，交给资产阶段或制作阶段决定，不编造参考。

## 无内容的可选字段

「段首复写」「供下一段复写的内容」「人物说明」「场景说明」「故事理解」「台词对照」保留字段名，空白视为无内容。字段不适用或缺少对应标注结论、定稿译文时，无内容可以通过。仅因未执行台词翻译，不必列为待确认。已有明确依据且应当填写时，无内容属于质量问题。

## 审核结论与输出格式

结论只填一项。有明确错误时填「需返修」。没有明确错误，但缺少会影响交付判断的依据时填「待确认」。其余填「通过」。已证实的问题写入返修意见，需要补证据才能判断的问题写入待确认事项。每个问题写一次，定位到段号、字段或剧情节点，并写清问题和应达到的结果。没有对应事项时留空。结论写入当前工作记录，不保存永久评分或失败累积日志。

```markdown
# 分镜审核

- 审核结论：

## 返修意见

[逐条填写段号或段界｜质量或格式｜位置及问题｜修订要求]

## 待确认事项

[逐条填写位置｜缺少的依据｜影响的判断]
```
