# 来源与正文核验

本指南是本 skill 的独立方法文档。不依赖第三方 skill、兄弟代码或临时调研文件。

## 确认入口与权限

独立创作可以没有来源。已有剧本解析必须读取原件；完整流程还读取已完成的 outline v5、cast 与 art，独立解析可缺少上游并明确联合对账 skipped。不能从梗概重写对白。项目要求和任务授权是辅助输入，不冒称原件事实。

权限未明确时，只整理来源、区分内容性质、报告表达缺口。转译候选留在 .work。正式 flow 或 notes 的 transformation 记录必要变化与真实授权依据，但字段非空不是授权真实性证明。

获准转译后，可以在边界内调整表达渠道或合并重复说明；不能改变事实、选择、结果、揭晓次序和必须保留的歧义。实际对白、明确发声的 VO 和关键字幕默认保留原句。删改这些内容或新增关键行为，需要明确授权。不建立自动权限引擎。

## 读取与归并

按实际提供的集场读取，过长场次沿完整话轮或行动拆分。相邻上下文与本块负责范围分开登记。provenance 描述原件的确定版本、负责范围和完整性；source 始终是作品名。

重叠负责范围按来源位置取并集。不同位置说过两次同一句话，保留两次；不要按文本去重。缺集、缺场、结尾未知都如实保留。scope=complete 要求提供文档全部覆盖、已知总集数和实际 1..N，不能因“读完当前窗口”而宣称全剧完整。

人物、地点和物品按原文区别记录，C/S/P 只是 script 局部标记。同名不等于同一身份；script 不判定别名归并，也不把自己的结论强加给人物阶段。场次序号表示原文顺序，局部 S 标记不等于 art 地点身份，不因重返地点改写原场次边界。同一实物交接或损坏保留发生位置与状态；不自动决定资产拆分或复用。保留无台词人物、匿名声音、未知说话者和非人主体，不能因身份未知而猜测合并。不因只被提及就决定必须出图。

分片工作放在 .work，由一个发布者统一组装正式 JSON，避免阶段目录出现多个互不一致的正式版本。

## 内容分流

- 行动进入 action，明确发生的事及先后结果。不以“心情复杂”冒充可执行行为。
- 实际发声进入 line。保留发声者；通过 audio 区分画外对白、旁白、内心发声以及谁能听见。已知人物不能无故改为匿名 VO。
- 字幕进入 subtitle，声音说明进入 sound；必要秒数明确填写。subtitle 不是台词，sound 不是未登记人物发言。
- 不发声的表演、背景、连续性和限制进入 notes。它们指导表达，但不朗读、不计时、不认领镜头或事件。

背景如果必须让观众知道，需要原文已有的画面、声音或已建立前情。一个眼神不能自动说明身份、日期或因果。多段心理说明可以共同指导表演，不必为每个形容词建立一个事件或镜头。

台词中的否定、条件、承诺和误导可能本身就是行动。不能以“展示而非讲述”为由删除。有限让步不能通过微笑、拥抱或音乐变成和解。

## 连续性与揭晓

只交接当前实际依赖的状态和限制，并附出处：人物位置、道具持有人、伤势、观众和人物的知情范围。闪回遵循当时状态，不套用后来结果。尚未揭晓的身份使用当时可见称呼，显式映射也不意味着可以提前说出真实身份。

区分客观事实、猜测、谎言和转述。未写明的侧别、动机或过渡保持未知。制作补定不能覆盖原件事实。必要的“不发声／不提前揭晓”限制进入正式 notes，不藏在临时笔记中。

## 两种独立核验

**来源文件核验：** 工具读取原件，检查原始字节 SHA256、严格 UTF-8、行数、引用范围和负责覆盖。缺失、改变、无法读取必须失败。纯内存结构检查必须报告尚未执行原件读取。

**来源与正文忠实度核验：** 独立上下文同时读取原文、script、任务授权和实际已提供的上游；完整流程还读取 outline v5、cast/art。逐处检查遗漏、未经授权的改写、人物身份、事件因果、说话者与听者、重复发生次数、信息揭晓和非发声说明。引用集号、场次、sourceRefs、B/Q ID 和实际文字。没有语义证据时写未核验。

制作计划审核另读正式正文、必要 notes、工作单及镜头安排。不能以 prompt.includes、哈希一致或提示词批准替代来源忠实度结论，也不能冒称生成成片通过。

## 交接与失效

flow 与 notes 的 sourceRefs 都是正式依据。改动文字、声音方式、来源关系、相关限制或原件版本后，需要复核对应内容。下游派发材料必须包含所选场次的完整 notes，以及 audioRefs 引用台词所在场次的必要说明与来源身份。相关跨段依赖变化不能漏掉；不相关集场不应使全剧批准失效。

cuts[].beats 保持实际正文的连续、恰好一次归属。audioRefs 只是同一次发声在后续镜头延续；不能重复播放，不能重复估时，也不能免除当前镜头的实际正文归属。具体发声者、次数及语义仍由内容审核确认。

映射依据还须同时位于 script 已负责范围和目标资产来源覆盖，来源版本快照在两个阶段一致。人物身份以 cast 为准，场景及物品以 art 为准，outline 自然语言称呼只提供故事上下文。同 ID、同名或原件哈希相同都不是身份确认。实际制作依赖缺少 confirmed 时阻断对应交接；其他歧义保留 pending/conflict。资产摘要或身份合拆变化只要求重新核验指向它的引用及相关工作单，不把无关场次一并判成失效。
