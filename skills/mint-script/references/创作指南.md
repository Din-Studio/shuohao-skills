# 剧本创作指南

## 职责与输入

剧本把故事计划落实为可表演的动作和台词，不提前安排镜号、参考图或模型提示词。先确定故事，再确定事件，再写场次。没有大纲也能独立创作，不伪造上游。

阅读用户自然语言要求，识别希望观众经历什么、人物怎样表达、哪些承诺需要完成、哪些边界不能越过。将实际要求记录在项目 production.creativeBrief；独立剧本可以使用本地 creativeBrief。两处同时存在要求时先人工合并。题材、画幅和画风不能自动决定台词长度、兑现频率或集尾方式。

指南只提供选择，不是机器规则，也不以版本或摘要阻断创作。改动指南或项目要求后，应重新阅读受影响正文；结构检查通过不代表已经符合新要求。

## 从人物目的组织场次

每场先问：谁想改变什么？对方为什么配合或拒绝？失败会失去什么？将选择与回应写进 flow，不能只写“关系发生改变”。人物在场名单保留无台词人物，不能从 speaker 自动替代。

- 人物剧情：让同一事实引出不同选择。正例是放下签字笔、拒绝担保、对方收回合同。反例是动作栏只写“双方关系巨变”。
- 生活题材：事务真实影响交流，保留劳动和观察。正例是边分配饭菜边协商轮班，明确各自不能承担的时间。反例是停下所有事务，轮流宣讲家庭价值。
- 悬疑题材：区分发现证据、解释证据、采取行动。正例是核对登记时间与停电记录，再排除候选人。反例是毫无依据地宣布“我全明白了”。

不适用情形：梦境、主观记忆或故意不可靠叙事可以暂时隐藏因果，但需要让观众知道信息视角，而不是将创作缺口冒充谜题。静态人物或普通配角不必强行发生性格转变。

## 选择表达强度，而非统一语气

- 强烈表达围绕信息、选择与代价推进攻防。承认账本上的签名可以改变谈判；反复吼叫“你会后悔”不会自动增加冲突。强度高不等于所有台词短促。
- 克制表达让可观察的细节承载未说出口的意思。先问列车时间，看到行李后再问是否送站，可以传递理解。连续填写“沉默良久”却没有信息或关系变化，是空白而不是克制。
- 温暖表达尊重双方需求与拒绝权。对方不想谈时，放好热水、确认下次安排，比强行拥抱后宣布隔阂消失更可信。温暖不要求伤害发生后立刻原谅。

delivery 只填写无法从台词与情境理解的特殊差异，例如笑着掩饰惊讶。不要每句复制“平实”。lighting 仅记录对叙事或连续性有意义的状态，不设计完整布光。动作与台词不必机械交替；台词写入 line，动作不能夹带未登记的整段对白。

## 结构、节奏与结束方式

单元故事可以完成本集任务再安静结束；连续故事也允许局部 closure。不要为统一格式在已经完成的场景后附加陌生来电。连续追更确实依赖悬念时，让具体事件提出问题，后续通过实际查证或选择回应，不只写“悬念陡生”。

密集推进优先减少重复说明与无效过渡，保护证据、决定和后果。渐进推进允许观察和推理，但每轮核对应该改变信息。舒缓推进允许完成工序后再回应，工序应有表达价值。以上建议不建立统一开场拍数、句长或动作比例。

不适用情形：证词、教学、仪式或必要停顿不宜为了短句而打碎。需要暂缓揭示的故事不必提前提供答案。开放结局可以完成“自愿开始谈话”的承诺，而不强行确认身份；已经明确承诺回答的问题不能以改标签逃避。

## 节点认领与具体证据

有大纲时逐个 B ID 对照 setup/outcome 寻找核心表现，包含两端，按上游顺序且互不重叠。共同铺垫可以放在认领之外，核心段允许跨场次。同类型不同 ID 不能合并认领；未分类节点同样不能遗漏。

《修伞簿》的 B01 发现线结，B02 选择不凭纹路认亲。两者即使发生在同一工作台前，也要分别定位发现与选择。只填写“我明白了”不能证明决定已发生。

上游 opening/ending 只有大纲一份编辑源，报告读取当前实际加载的计划。openingBeat 可省略，省略只表示未标注，不能声称第一拍已核验。结束位置由最后一项 flow 计算；位置正确仍不证明集尾事件完成。Q 计划仍由大纲负责，报告按 resolves 和 beatClaims 展示回答位置。

修改正文后重新计算受影响的 openingBeat（若填写）与 beatClaims，不能依靠旧坐标凑巧还在范围内。通知制作阶段重新检查真实镜头覆盖；剧本不会自动重写下游。

## 估时修订与批次交接

字符语速与固定动作秒数是统一估算模型，不是成片秒表。超标只提醒。先检查是否重复表达，再保护证据、必要停顿、人物选择和结果。不足时检查是否遗漏行动，不为补秒增加寒暄。

用户明确改变语速、动作秒数或容差时才保存覆盖；不要为了检查通过任意加速。无法容纳时，与上游协商目标时长或事件安排，不能静默改变 targetSeconds 掩盖目标不一致。

建议每批最多三集。交接上一批人物位置、知情范围、道具状态、已作选择与未兑现承诺。批次末集不等于全剧末集。没有上游时明确哪些节点、资产与问题尚未核对。

## 内容评审问题与记录

逐项引用集号、B/Q ID（适用时）、坐标和实际台词或动作：
1. 行为来自处境、目标、关系还是作者移动节点的需要？
2. 证据出现、人物理解、行动、结果之间是否连贯？
3. 人物是否知道不可能知道的事？跨场道具与位置是否连续？
4. 每个节点是否实际发生，还是重复认领同一个结果？
5. 开场和集尾是否表达当前计划？结束坐标合法是否掩盖事件未完成？
6. 登记的问题是否真正得到回答，而非只提到同一名词？
7. 慢热是否推进信息？密集是否省略因果？开放是否兑现本次承诺？
8. 估算能否容纳可理解的表演？哪些部分需要试读？
9. 修改要求、计划或正文后，哪些上下游需要复核？

记录判断、证据、建议和复核状态到当前工作记录，不新增永久总分、爆款概率、失败累积日志或统计。没有证据就写未核验。
