# 《修伞簿》：先确定故事

本样例为原创，专供 mint-script。大纲、美术和角色夹具均在本目录独立编写，不读取其他 skill 的样例。

修伞人林禾从小与母亲失散。客户陈岚送来一把旧伞。伞上的绕线方法让林禾想起母亲，但她没有据此认亲。她先完成客户的修补委托，再查阅留存的修伞簿，发现相同手法曾传授给多人。

陈岚愿意转交询问，却不愿提供另一个人的私人地址。林禾尊重这个边界，留下自己的联系方式。第三集，一位名叫许秋的修伞师傅到来。林禾没有先称呼母亲，而是询问她是否愿意谈谈当年的事。许秋答应明天再来，身份仍未确认。

三个单元分别完成：交还修好的伞、递出有边界的邀请、开启双方自愿的谈话。共同故事线是林禾从凭物证寻找确定答案，转向接受对方也有选择。前两集没有兑现节点，不伪造追更悬念。最终开放的是身份答案，不是是否完成本次交付。

创作方向：生活题材，温暖但尊重边界；三个单元舒缓推进，不要求每集反转。先写人物选择，再安排节点，最后编写场次与节拍。样例没有分镜、真实图片或生成结果。

数据表达：开场与集尾计划留在本地大纲夹具，结束坐标由正文计算，第二集不单独标注开场落点。情境已能说明语气的台词不填写 delivery。修伞簿-source.txt 是本 skill 自己撰写的测试原件，不冒称外部原剧本。另见《夜班水尺》完整解析样例。
