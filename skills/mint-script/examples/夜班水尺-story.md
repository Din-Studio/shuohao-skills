# 《夜班水尺》故事与测试意图

这是 mint-script 自己的解析样例，不借用其他 skill 的故事。

## 先确定故事

值夜员沈汀曾因抢开闸门导致事故。她正在等待复核信号，而不是已经确认安全。老同事在门外提醒她等待。搬运工始终在场，但没有台词。沈汀的内心声音只让观众听见，不让其他人物得知事故背景。

提供的原件只有第七集和第九集。第八集未提供，全剧共十集。不能补写中间事件，也不能把第九集当作全剧结局。两次“等灯灭了再开门。”是不同位置实际说出的两句话，不得按文本去重。

第七集结尾，沈汀把手从开关上移开。这只是接受等待，不是赎罪完成或同事和解。第九集换班时，钥匙仍归沈汀保管。原文没有解释她如何度过第八集。

## 再确定执行表达

原件的心理说明进入非发声 notes。实际发声逐句进入 line。报警声进入 sound。显示屏文字进入 subtitle。所有 flow 都有一基、包含端点的 sourceRefs。局部人物标记 C03 为无台词搬运工，不从场内人物名单删除。C/S/P 只在 script 内区分对象，不代表项目资产身份。本样例不提供 outline/cast/art 或资产映射，联合对账为 skipped；不能因此改变原场次、猜测身份或默认进入制作。

第七集的内心声音属于同一次播放。测试制作计划让它在开关前开始，持续到移开手的画面，再延续到门外雨棚收起记录纸的画面。后续镜头分别拥有各自的行动正文，只通过 audioRefs 延续此前台词，不再认领或估算那句台词。

## 核验边界

文件哈希和坐标通过，只证明版本与位置一致。是否错误表达了许可、赎罪或知情边界，需要独立上下文回查原件。本样例没有生成视频，没有声称完成语义审核。
