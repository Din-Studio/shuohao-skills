# 《旧站时刻》故事提案

本 skill 自有故事，不借用兄弟故事、样例或原文。故事先于剧本与任何镜头设计；本次不生成分镜或图片。

旧站撤并前，林蔚发现末班接驳车未进入电子到站表。退休调度员许钟回来核对，知道纸簿补记习惯，也隐瞒自己二十年前曾把漏报归咎于司机程安。调查排除失踪，发现新旧系统交接漏掉补记栏。旧回执与签名支持纠正旧归责，许钟选择把自己的责任写入同一份更正说明。

故事不是寻找幕后坏人，而是区分记录完整与个人名誉。林蔚不能凭自述改档。程安确认事实更正，不承诺原谅。结尾原簿与说明共同移交，关系是否恢复仍未知。

本次先依据既定故事写成六集测试剧本，再对这份真实存在的测试原件做有来源的剧情解析。它是新建立的自有测试来源，不是迁移器从旧大纲伪造出来的原作证据。纯解析生产入口仍只接受已有剧本。

验收重点：第四集的心理背景不发声；同一纸簿跨集交接不换身份；无台词接收员保留；第三与第六集相同一句对白分别发生；事实更正不等于和解；完整六集与缺集片段分别表达覆盖。
