# 剧本解析报告约定

离线中英界面，正文不翻译。故事摘要和分集优先，随后展示事件、来源身份与覆盖、连续性／揭晓限制、资产及可选预算，最后说明结构检查与语义核验状态。不展示已删除的创作规划或虚构时长。

来源范围可回查；覆盖是坐标并集。source-files 未执行时显示 skipped，实际失败阻断。哈希核验通过不代表内容忠实，制作审核也不能替代来源核验。部分来源结构完整不代表全剧完整。

场景关联事件仅指同集，不证明落在该地点。人物资产量只表示交接参考，不代表必须出图或已经生成。可选字段缺省不显示空规划表。

用户文本转义；导出 JSON 保持原值。超过三集可以展开，事件链接定位折叠分集，打印全部展开。报告 HTML 不进入版本控制。DOM 自测不替代真实浏览器布局检查。
