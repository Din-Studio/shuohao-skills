# 已有剧本解析与内容核验指南

## 边界与授权

本阶段只提取已有剧本，不接收小说、大纲或原创构思。先阅读实际原文，再提取故事事实与重要事件，不先设计分镜。测试故事也须先定故事，再写剧本和解析样例，不反向从镜头拼故事。

项目要求和授权是辅助输入，不是源事实。权限未确认时只整理来源、内容性质和表达缺口。转译候选放 .work，不进入正式 JSON。获得授权后，script 可调整表达渠道或合并重复说明，但不得改变事实、因果、选择、结果、揭晓顺序或必须保留的歧义。实际对白、明确发声 VO 和关键字幕默认原句保留；删改或新增关键行为需明确授权。自动驾驶不能扩大授权。

## 最小提取

summary 简述提供范围内的主线和必要结尾说明。没有最终集就不补写终局；opening/ending 只记录实际有交接价值的停点，不强迫选择创作模式。问题未回答就保留未知，不删除 Q 规避校验。

先记录出处，再提取事件和自然语言故事描述。不建立人物／地点／道具身份，不负责别名归并、tier、primary 或资产预算。无台词人物的行动、只出声的主体、仅被提及的背景和非人主体都可以是重要故事事实，不因此自动安排出图。同名不同人使用原文角色描述及位置区分，隐藏身份和未知说话者不猜测。物品交接和受损保留为有出处事实，不分配资产 ID。

B 事件记录真实发生的处境、选择和结果，同集按叙事顺序。不为每个情绪词建立节点，不恢复节奏评分、类型标签或目标时长。
仅保留下游依赖的状态、前情和禁区。notes 区分客观事实与角色说法，并附出处。闪回按当时状态核验，知情晚于当前场的秘密不提前投放。整理补出的场界需在工作记录明确说明；原有集场顺序不随意重排。

## 非发声说明与视听表达

心理说明可以指导一次表演，不必逐句朗读或新建动作。具体背景若必须让观众知道，应有原有行动、声音或前情支持，不能以“眼神复杂”替代日期、身份和因果。存在表达缺口应报告，不能自行补写证据。

承诺、否定、条件及故意误导的台词可能就是剧情行动，不为“展示而非讲述”删除。画外对白、内心声音、明确 VO 与客观声响不是同一概念；下游记录真实发声者、是否可被场内人物听到和必要主观性。非发声说明不参与台词估时或逐字检查。

《旧站时刻》第四集的退休荣誉顾虑只供表演，林蔚尚不知情；不可自动生成许钟内心独白。第六集程安仅确认更正副本，不能通过微笑、拥抱或音乐补成和解。档案接收员无台词，其实际行动仍保留在故事事实中。纸簿交接与旧归责页归还按原文描述，不建立资产身份。

## 来源／正文核验

独立上下文实际读取原件与解析结果；逐条引用 documentId、行号和 B/Q ID：
1. 提供范围是否全部覆盖？边界是否遗漏？重复读取是否只合并相同位置？
2. 同样文字在不同位置是否分别保留？原句是否被摘要重写？
3. 人物描述及物品状态是否有证据？是否遗漏影响剧情的无台词行动、匿名声音或地点变化？
4. 事件、否定／条件／承诺、因果、选择和结果是否保留？
5. 客观事实是否被猜测、谎言或转述替代？
6. 身份、道具持有人、伤势、恢复、闪回和揭晓顺序是否符合当时来源？
7. 未知集数、结尾、动机和侧别是否被补写？未解决的问题是否诚实保留？
8. 心理说明是否错误发声？背景是否被无信息的表情替代？是否存在越权转译？

SHA256、行号和结构通过不能给出这些语义结论。自动报告固定 contentReview:not-performed；人工或 Agent 审核在本次交付说明中链接工作记录，不新增永久评分、门失败累积日志或统计。

## 制作交接与审核

完整流程依次为 outline → characters → art → script → creation，上一阶段完成本次范围和交接后再推进。outline 只交接剧情事实；characters 独立判断人物身份，art 独立判断地点和物品的美术身份；script 同时读取原文，形成唯一执行正文并核对实际引用。人物／美术标明制作补定，creation 负责分镜、声音和提示词，不自行删台词或改剧情。来源遗漏返回 outline，正式表达变化返回 script，镜头问题留在制作阶段。

来源／正文核验不同于制作审核。制作审核消费正式正文、必要说明和制作工作单；一次声音跨镜仍只发生一次，不等于允许重复认领正文。来源或限制变化应触发实际依赖段重新审核；无关集场不能连带失效。本阶段仅提供本地 JSON 接口检查，不宣称完整工作单批准或成片通过。

制作目标在 script 逐集确认；纯解析不强迫填写 targetSeconds，进入制作仍须目标和时长对账。outline 不保存分钟数或复用方案。不新增时间线、粗剪、翻译或成片验证能力。

## 学习来源

内化本仓库既有原文覆盖与证据方法，以及“剧本读取与记录”“合并与正式交付”、长剧本连续性和文本到视听表达研究的逐处读取、按位置合并、对象证据及非发声说明方法。未照搬第三方 skill、固定分批阈值、机械出图或平行登记系统。正式运行只读取本 skill 自带指南与用户输入。
