# 分卷摘要：保留来源的中间材料

仅在长篇尚未完整阅读时使用。每卷产出 JSON，不把摘要当最终交付。阅读覆盖不足必须说明；不凭书名或题材猜测事件。

```json
{
  "sourceRange": "实际覆盖章节",
  "coverageNote": "完整/缺失段落说明",
  "plotlines": [{"name":"行动或关系线","events":"按因果顺序记录实际事件"}],
  "characters": [{"name":"人物","aliases":[],"doing":"本卷行为与关系"}],
  "beatMaterial": [{"moment":"关键事件","type":"自由标签","evidence":"逐字原文片段"}],
  "settings": ["实际发生事件的地点"]
}
```

- 按故事线整理，不把章节边界当情节边界。
- evidence 逐字复制并保留原语言，不把摘要伪装成引文。
- 重要材料不限兑现，可以是事件、压力、转折或选择。
- aliases 支持跨卷人物归并；不要提前合并不同人物。
- settings 只记录实际使用地点，不包括偶然提到的地名。
- 本阶段不执行改编取舍。后续仍须核验关键证据，特别是重叠切分边界。
