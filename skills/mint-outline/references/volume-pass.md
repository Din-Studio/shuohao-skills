# 分块读取与来源覆盖

短剧本直接读取。长剧本按已有集场边界与实际负载拆分；超长场次沿完整话轮或行动分开。工具行数分块只是候选，遇到跨行话轮要人工调整负责范围。不得使用“每批三集”或窗口大小证明读全。

## 操作

1. 保存不可覆盖的原件，确认确属剧本，而非小说或大纲。
2. source-document 读取原始字节生成相对路径、SHA256 和物理行数。不能仅凭剧名登记来源。
3. chunk --kind script 生成 .work/source-chunks.json。每块有 owned（负责范围）及 context（理解用相邻范围），含首尾行号；原行不裁剪、不改写。输出独占创建，已有文件不覆盖。
4. 阅读每一块；在 .work 中记录局部对象、事件、原句、疑问及实际负责范围。工具生成分块不代表人或模型已经读过。
5. 统一发布者归并稳定 ID，并集登记 coverage。上下文重复不产生新事件；不同位置的同句仍是两次发生。按位置核对边界，无空隙、无重复丢失后才能声明所提供文档完整。
6. scope=complete 还需明确全剧总集数与实际 1..N。只拿到第 4、6 集，应登记 partial，不能补写第 5 集。

## 对象与跨集状态

先记录出现依据，再归并身份。同名不同人保持不同 C ID；别名需原文身份关系证据，不能只凭拼写相似。保留无台词人物，区分可见、只出声和仅被提及；只在确有资产交接价值时登记被提及对象。

S ID 表示地点，同一地点的不同场次不重建。P ID 表示实物，交接、受损和恢复仍是同一对象；时间、生效与结束由有出处的 notes 说明。闪回使用当时状态，不套用后续恢复状态。

客观事实与角色猜测、谎言、转述分开。只交接当前任务所需的前情及揭晓禁区；隐藏身份保持当时称呼，不能因统一 ID 而提前泄露。未写明侧别、动机和过渡保持未知，制作补定不能冒充原文。

## 核验边界与学习来源

来源核验读取原件并比对摘要和行号；内容审核仍需逐处对照事实、发声及授权。旧版逐字证据与覆盖方法、原“剧本读取与记录／合并与正式交付”方法，以及长剧本连续性研究已内化于本指南；不需要第三方 skill，不在运行时读取学习材料或兄弟样例。不建设图数据库、全剧知情矩阵或失败日志。
