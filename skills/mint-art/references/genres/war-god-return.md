# 题材 · 战神归来（场景与道具）

和都市逆袭的区别：逆袭的主角真是从零往上打，本题材的主角一开始就在顶点，只是身份没揭开。

## 先记住

1. **按身份层分区**：伪装的市井、对手的权贵、真身所在的权柄。真身层是旧部、组织所在的空间（军部、旧部驻地），视觉上和前两层明确断开。
2. **伪装 ≠ 落魄。** 主角选择低调，不是真的穷：空间整洁有维护，只是不贵。
3. **主角的几套造型是最重要的资产**：同一张脸，几种气场；手上的茧和疤在每一套里都一样。

## 一、分区

| | Z1 市井（伪装层） | Z2 权贵（对手层） | Z3 权柄（真身层） |
|---|---|---|---|
| 用在 | 主角伪装身份的日常 | 岳家、对手企业、宴会 | 军部、组织、旧部所在 |
| 维护 | 旧，但不脏 | 精心维护 | 高度规整、有纪律感 |
| 光照基线 | 顶灯、日光灯管（约 4000–6500K） | 人工照明、水晶灯（约 2700–3000K） | 成排的冷白灯管（约 5000–6500K） |
| 光影锁倾向 | — | 充足，华丽但不刺眼 | 均匀、没有阴影 |
| 色板 | 米黄、水泥灰、褪色蓝 | 黑金、酒红、深棕、香槟色 | 军绿、钢灰、深黑、暗金 |
| 材质 | 复合板、瓷砖、棉麻 | 大理石、实木、丝绒 | 金属、皮革、迷彩、勋章 |
| 服化道 | 普通夹克、旧鞋 | 定制西装、珠宝、名表 | 制服、徽章、战术装备 |
| 空间感 | 紧凑 | 开阔但人多拥挤 | 空旷、对称、纵深长 |
| 适合出现 | 生活痕迹、使用磨损 | 炫耀性陈列 | 秩序、编制、旗帜 |
| 不该出现 | 脏乱、破败、贫民窟化 | 廉价影楼感 | 现代都市的随意感 |

- 旧部认主是核心场面：真身层的人出现在市井或权贵空间里，制服与环境的违和就是压迫感。
- 主角的手（茧、疤）是身份的隐藏线索，在伪装阶段就值得给出清楚的细节。

## 二、世界

- 当代中国都市，现实规则为主。剧本里的组织、军部、家族这类权力结构，靠编制、层级和可见的符号（徽章、编号、令牌）体现。
- 主角的强大来自过往经历和积累的资源，不是超能力；不画成光效、气浪、金光。

## 三、场景

- 宴会厅这类人多的地方是身份揭露和打脸常发生的场所，场景要容得下围观的站位。

## 四、道具

- 身份信物（最重要）：令牌、徽章、编号牌、军牌——揭露的物理载体。
- 对照类：主角的旧表、旧车对对方的名表、豪车。权力类：调令、任命书、印章。战绩类：勋章、照片、旧装备。
- 羞辱道具：被推回的礼物、被撕的名片、被泼的酒。

## 五、光、色与质感

- 基调：**克制的重量感**。不靠特效、不靠浮夸；制服有分量感，不做成塑料质感。
- 不同画风：真人写制服面料、金属徽章和手部细节；二维用三个区各自的色板；3D 用制服材质。

## 六、易错点

- 市井写成脏乱、破败；主角造型浮夸、时装化；几套造型只做一套换配饰。
- 用光效、气浪、金光表现「强大」；超自然元素（属于玄幻）。
- 真身层出现都市的随意感；旧部制服做成角色扮演的质感。
- 所有权贵空间都金碧辉煌。
