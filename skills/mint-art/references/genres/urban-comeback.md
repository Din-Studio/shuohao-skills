# 题材 · 都市逆袭（场景与道具）

和霸总甜宠同为阶层分区，但方向相反：霸总的主角从平价世界走进高奢世界，逆袭的主角是先被挤出权势圈、再打回去，平价世界是他的现实处境。

## 先记住

1. **简陋 ≠ 脏乱。** 主角的现实空间要看得出被珍视、持续维护——工具摆放有序、地面有清扫痕迹、招牌手写但擦得干净。这是主角尊严的视觉载体。
2. **翻身靠看得见的结果**：每次反转都有可见的物证（数据、成品、文件、实物对比），数字和文书可读。
3. **核心对立：主角空间的旧金属、暖木对体系空间的铝合金冷白、玻璃**——个人手艺对资本体系。

## 一、分区

| | Z1 权势区 | Z2 现实区 |
|---|---|---|
| 用在 | 企业总部、高档场所、体系内的机构 | 主角的作坊、小店、出租屋、工地 |
| 完好度 | 完好 | 完好 |
| 维护 | 精心维护 | 旧，但不脏 |
| 光照基线 | 日光灯管、面板灯（约 4000–6500K）；大面积玻璃进来的天光（约 5500K） | 单只钨丝灯泡、工作灯（约 2700K） |
| 光影锁倾向 | 灯位可控、照得均匀 | 灯位低、随意 |
| 色板 | 黑金、冷白、深蓝、大理石灰 | 米黄、水泥灰、褪色蓝、暖白 |
| 材质 | 大理石、金属、玻璃、高支面料 | 复合板、瓷砖、铁皮、棉麻 |
| 服化道 | 定制剪裁、腕表、锃亮皮鞋 | 工装、耐脏面料，有磨损 |
| 空间感 | 开阔、层高高、留白多，有围观空间 | 紧凑、物件密、工具占位 |
| 适合出现 | 秩序感、克制的奢华 | 劳作痕迹、使用磨损、手写标识 |
| 不该出现 | 金碧辉煌的堆砌、浮夸装饰 | 脏乱、破败、贫民窟化、污渍、霉斑 |

- 主角在权势区是异物：他的工装、旧鞋、粗糙的手在大理石和玻璃里格外显眼——打脸段的视觉基础。
- 反派进入现实区是入侵：皮鞋踩在水泥地上、西装蹭到油污。
- 主角的现实空间随剧情逐级改善（简陋棚屋 → 正式店面 → 更大的场所），剧本里有就做成同一空间的不同变体，每一级的陈设和材质都按那一级来做。

## 二、世界

- 当代中国城市，正常运转，现实规则。主角的能力有来源（师承、经验、专业训练），体现在工具、动作和成果上，不做成特效。

## 三、场景

- 打脸和反转常在有见证人的公开场合发生，场景要容得下旁观者的站位。

## 四、道具

- 证据类（最重要）：数据报告、检测结果、实物对比件、文件、录音载体——数字可辨认、前后一致。
- 专业工具：有使用痕迹和年份感。传承类：师父的工具、笔记、照片，跨集同一件东西保持一致。
- 身份对照：主角的旧物和反派的新物同框。文书类：通知书、许可证、合同、判决书，抬头、印章、关键行可读。

## 五、光、色与质感

- 基调：**质朴的市井写实，不是广告片**。说服力来自材质真实和劳动痕迹：保留皮肤纹理、手部粗糙、金属磨损、木器年份。
- 不同画风：真人写手部、工具和材质；二维用两个区各自的色板、粗细不同的线条；3D 用金属磨损贴图。

## 六、易错点

- 现实区写成脏乱、破败、贫民窟；主角空间没有维护痕迹（工具乱放、地面积灰）。
- 没有依据的做旧；设定图加了泛黄的怀旧滤镜；霓虹赛博、科幻蓝。
- 所有权势区都金碧辉煌。
- 关键数字和文书看不清；道具、场景里画进声波、数据流、全息之类的特效；主角靠时装化造型表现「翻身」。
