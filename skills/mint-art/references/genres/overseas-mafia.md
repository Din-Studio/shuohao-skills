# 题材 · 海外黑帮（场景与道具）

海外英语向题材，资产不和中式题材共用。和「海外亿万富翁」的区别：财富来源不合法，空间要有「有权势但不体面」的质感。

## 先记住

1. **按合法性分区**：合法门面、家族内部、女主的世界。不是阶层高低，而是这个空间在法律之内还是之外。
2. **家族内部的灵魂是低照度**：光来自台灯、壁灯、百叶窗透进的条纹光，不开顶灯。
3. **女主的世界正常、整洁，只是平凡。**

## 一、分区

| | Z1 合法门面 | Z2 家族内部 | Z3 女主的世界 |
|---|---|---|---|
| 用在 | 合法生意的门面 | 家族真正运作的地方 | 女主原本的生活 |
| 完好度 | 完好 | 完好 | 完好 |
| 维护 | 精心维护 | 精心维护 | 旧，但不脏 |
| 光照基线 | 商业照明（约 3000–4000K） | 台灯、壁灯（约 2700–3000K）、百叶窗透进的条纹天光（约 5500K） | 顶灯（约 3000–4000K）、白天从窗进来的天光（约 5500K） |
| 光影锁倾向 | 明亮体面 | 低照度、大片暗部，暗部留住结构 | — |
| 色板 | 暖黄铜、深木色、奶油色 | 炭灰、血红、牛血红、金 | 暖米色、褪色牛仔蓝、旧木色 |
| 材质 | 抛光木、皮革、黄铜 | 深色皮革、丝绒、冷金属、大理石 | 复合板、棉、塑料 |
| 服化道 | 三件套西装、丝质 | 同左，加武器、戒指、纹身 | 平价基础款，干净 |
| 空间感 | 开阔、迎客 | 封闭、有暗门、纵深长 | 紧凑 |
| 适合出现 | 体面的奢华 | 权力符号、家族纹章、旧伤 | 生活痕迹 |
| 不该出现 | 违法的东西外露 | 明亮均匀的照明 | 脏乱、贫民窟感 |

- 门面足够体面，「合法」这层皮才立得住：餐厅、俱乐部、洗衣店，干净、正常营业。
- 从门面走进家族内部，要有一个明确的空间过渡（一扇门、一段楼梯、一条走廊）。
- 女主在家族内部是异物：她的平价衣着在丝绒和皮革之间格外显眼。男主出现在女主的世界里，那份违和就是危险的入侵。

## 二、世界

- 默认当代北美都市。财富来源不合法，但具体形态模糊处理，只暗示不展示犯罪细节。

## 三、场景

- 门面（餐厅、俱乐部）剧本里有营业和打烊两种状态的，分营业中 / 打烊后两个变体。
- 办公室和仓库是权力对话和威胁发生的地方。

## 四、道具

- 权力符号（最重要）：戒指、家族纹章、雪茄、酒、武器。
- 忠诚类：家族照片、传承的物件。威胁类：信封、照片、被送来的东西。合法伪装类：账本、菜单、营业执照。
- 女主的平价物件出现在丝绒和大理石上。
- 不用真实黑帮组织的符号。

## 五、光、色与质感

- 基调：高级材质但不炫耀，保留皮肤纹理和旧伤。
- 不同画风：真人写皮革、丝绒和条纹光；二维用大面积深色块配少量血红、金色的色块；3D 用材质反光。

## 六、易错点

- 家族内部用明亮均匀的照明（毁掉全部气氛）。
- 女主的世界画成贫民窟；男主凶相毕露、脸谱化。
- 真实黑帮组织符号；和中式审美混搭的服化道。
