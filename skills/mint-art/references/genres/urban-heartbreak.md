# 题材 · 都市虐恋（场景与道具）

和霸总甜宠的区别：甜宠的情绪主轴是甜，本题材是痛，视觉不共用一套。

## 先记住

1. **按时间线分区：过去的甜、现在的痛。** 两条时间线在画面上怎么一眼分清，由视频的调色负责；资产只按剧本写出的陈设和状态差别拆变体。
2. **痛 ≠ 破败。** 现在的空间依然精致、有人维护，只是空。用「空」（空位、单人份、物件被收走）表达痛，不用「脏」和「旧」。这是本题材最常见的美术错误。
3. **同一人物的两种状态**，以及**剧本写出了两条时间线差别的同一空间**，是全剧最有分量的资产。

## 一、分区

| | Z0 过去（甜期） | Z1 现在（痛期） |
|---|---|---|
| 用在 | 过去那条时间线的场次（闪回） | 现在那条时间线的场次 |
| 完好度 | 完好 | 完好 |
| 维护 | 精心维护 | 精心维护 |
| 光照基线 | 两条时间线同一套：白天从窗进来的天光（约 5500K），夜里顶灯、台灯、落地灯（约 2700–3000K） | 同 Z0 |
| 色板 | 按这个空间本身的物件取，两条时间线同一套 | 同 Z0 |
| 材质 | 按这个空间本身的物件取，两条时间线同一套 | 同 Z0 |
| 服化道 | 明亮的颜色、柔软廓形 | 深色、硬挺、包裹感强 |
| 空间感 | 两人距离近、物件有生活感 | 空旷、留白多、物件被撤走 |
| 适合出现 | 拉开的窗帘、共用的物件 | 空位、单人份、被收起的痕迹 |
| 不该出现 | 空位的暗示 | 破败、脏乱、废墟感 |

- 剧本里同一个空间在两条时间线都出现时（同一间卧室、同一张餐桌、同一个玄关），两边的场次各落在自己的分区；剧本写出的主光或空间状态（比如餐桌上两个杯子 / 一个杯子）不同，就照《术语》「场景变体」拆，布局相同。
- 物件的消失是核心手段：过去有两个杯子、两双拖鞋，现在只剩一个。

## 二、世界

- 默认当代中国一线城市，正常运转，生活水平中上，现实规则。

## 三、场景

- **两人住所在两条时间线里的样子**是本题材最重要的场景资产。

## 四、道具

- 成对物件（最重要）：两个杯子、两双拖鞋、双人餐具——现在只剩一个。
- 情感载体：戒指、旧照片、手写便签、保存的票根。误会道具：手机屏幕、文件、诊断书、别人的物品。时间标记：日历、倒计时、季节性物件。追妻期反复被退回的东西。

## 五、光、色与质感

- 基调：**精致的空**——依然漂亮、有人维护，只是物件少了、空位多了。保持精致，不做旧。
- 剧本里有雨、雾的，现在那条时间线的场景可以有玻璃上的水痕。
- 不同画风：真人写织物与玻璃的材质；二维、3D 照物件本身的颜色和材质画。

## 六、易错点

- 痛期写成破败、脏乱、废墟感；女主「痛」就蓬头垢面。
- 剧本写出了两条时间线的差别，同一空间却没拆开。
- 没有依据的做旧；设定图加了泛黄的怀旧滤镜。
