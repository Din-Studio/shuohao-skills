# 题材 · 宫斗宅斗（场景与道具）

和古装穿越的区别：穿越靠信息差，本题材是礼制之内的博弈，主角没有外来优势。

## 先记住

1. **空间就是权力**：位分越高，居所越宽敞、陈设等级越高。按权力位置分区。
2. **位分的视觉标识成体系，是全剧美术常量的一项**：观众在两秒内能从画面判断谁的位分更高。
3. **冷宫、废院是唯一允许破败的地方**，而且要有剧情依据；其余地方再简省也整洁有人维护——礼制社会里「脏」本身就不合理。

## 一、分区

| | Z1 正殿 / 主院 | Z2 偏殿 / 侧院 | Z3 冷宫 / 边缘 |
|---|---|---|---|
| 用在 | 掌权者居所、议事之处 | 中低位分的居所 | 失势者、待罪者 |
| 完好度 | 完好 | 完好 | 局部破损 |
| 维护 | 精心维护 | 有人维护，简省 | 无人照管 |
| 光照基线 | 天光（约 5500K），烛台成组（约 2000K 以下） | 从侧窗进来的天光（约 5500K）、单烛（约 2000K 以下） | 只有天光（约 5500K），没有灯火 |
| 光影锁倾向 | 白天采光充足；夜里内室亮处暗处差得很多，暗处轮廓看得清 | 夜里内室亮处暗处差得很多 | — |
| 色板 | 朱红、鎏金、玄黑、月白 | 靛青、墨绿、素白、藕荷 | 灰褐、褪色、青苔绿 |
| 材质 | 织锦、漆器、玉石、硬木 | 棉麻、竹木、陶 | 剥落的漆、蒙尘的木 |
| 陈设密度 | 高（屏风、香炉、瓷器成组） | 中（必需品为主） | 极低（空荡） |
| 空间 | 开阔、进深多 | 紧凑、一进 | 狭小、封闭 |
| 适合出现 | 等级陈设、礼制标识 | 简省但整洁 | 蛛网、落叶、无人迹 |
| 不该出现 | 混用低阶纹样和器物 | 脏乱 | 完好如新 |

- 主角的居所随位分迁移（偏殿 → 正殿，或偏殿 → 冷宫）时，同一物理空间的不同阶段，剧本写出了陈设和状态的不同就做成不同变体，各按所在区的色板和陈设来做。
- 陈设的增减就是位分变化的信号：多一架屏风、少一只香炉。

## 二、世界与形制

- 先锁一个朝代的形制作基准（常见唐、宋、明），架空世界也指定参照。
- 位分层级列清楚（全剧美术常量），每一级对应一组服色、纹样、配饰材质、发式规格，再对应随侍人数。侍从也分等级，服色可区分。

## 三、场景

- 掌权者正殿剧本里有日夜两种戏的，分日间 / 夜间烛火两个变体。
- 请安、议事之处的座次就是一张权力关系图，按位分排座。
- 花园、廊下是密谈和偶遇的中间地带。

## 四、道具

- 位分标识（最重要）：服色、纹样、发簪材质、随身配饰。
- 信物：玉佩、令牌、印章、腰牌。博弈道具：密信、药包、账册、证词、被调换的物件。礼制道具：进献的礼品、赐下的物件。
- 陈设等级类：屏风、香炉、瓷器，数量和材质随位分变。
- 资源有限时，优先保证等级看得清，再集中做一两件高光单品，其余从简。

## 五、光、色与质感

- 基调：**等级秩序的质感**。说服力来自形制可信和等级可读，不是华丽堆砌。织物纹理可见、金属有磨损、木器有年份。
- 色：服装、器物以低饱和的颜色打底，位分色做高纯度点缀。
- 不同画风：真人写形制和材质；国漫和二维用位分色板、纹样密度区分高低；3D 用织锦、漆器的材质与烛光。

## 六、易错点

- 影楼风（形制混搭、完全架空、现代感妆发）；朝代形制混用；现代光源、现代妆容；塑料感面料；高饱和荧光色。
- 正殿、偏殿出现脏乱；冷宫完好如新；没有依据的破败做旧。
- 位分标识不成体系，观众分不清高低。
