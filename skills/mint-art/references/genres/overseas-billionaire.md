# 题材 · 海外亿万富翁（场景与道具）

海外英语向题材，人物、服化道、空间按北美审美做，不和国内都市题材的资产混用。

## 先记住

1. **按阶层分区**；叠加了狼人、吸血鬼等超自然线时再加一个超自然区。
2. **普通 ≠ 穷 ≠ 脏。** 女主原本的世界整洁、有人维护，只是物质水平低。
3. **把有限的精力放在人脸和主场景上**，其余从简。

## 一、分区

| | Z1 精英区 | Z2 普通区 | Z3 超自然区（可选） |
|---|---|---|---|
| 用在 | 豪宅、高层办公室、高级场所 | 普通公寓、小店、平价工作场所 | 领地、庄园、森林这类超自然线的地方 |
| 完好度 | 完好 | 完好 | 完好 |
| 维护 | 精心维护 | 旧但不脏 | 按设定，通常维护良好 |
| 光照基线 | 室内灯（约 2700–3000K）、落地窗的天光（约 5500K） | 顶灯为主（约 3000–4000K），窗小 | 夜里只有月光（约 7000K）和火光（约 2000K 以下） |
| 光影锁倾向 | 灯位可控，画面里的实际光源丰富 | 采光受限 | — |
| 色板 | 炭灰、冷钢蓝、深海军蓝、玻璃白，血红只作小件点缀 | 暖米色、褪色牛仔蓝、旧木色 | 深林绿 |
| 材质 | 大理石、拉丝金属、玻璃、精纺羊毛 | 复合板、瓷砖、棉、塑料 | 原木、粗石、皮革、天然纤维 |
| 服化道 | 定制西装、腕表、袖扣 | 平价基础款，干净 | 简化、耐磨；和变身有关的衣服可撕裂 |
| 空间感 | 开阔、层高高、留白多 | 紧凑、物件密 | 开阔的自然空间或庄园 |
| 适合出现 | 克制的奢华、冷硬秩序 | 生活痕迹、使用磨损 | 自然侵蚀 |
| 不该出现 | 金碧辉煌的堆砌 | 脏乱、破败、贫民窟感 | 都市光污染、霓虹 |

- 精英区和普通区的对比是「愿望实现」的视觉载体；精英区和超自然区之间切换时，色温和光源类型明确断开。
- 女主的平价物件出现在精英空间里（她的平价外套挂在衣帽间）是高价值画面，剧本里有就把它设计出来。

## 二、世界

- 默认当代北美都市，剧本另有设定照剧本。财富来源剧本里有一句解释就够，不展开。

## 三、场景

- 女主公寓若剧本里有「改善前 / 后」，按同布局做两个变体。

## 四、道具

- 身份类：腕表、袖扣、车钥匙、黑卡、合同。
- 情感类：戒指、旧照片、手写便条。
- 剧情类：验孕棒、DNA 报告、匿名信、U 盘——剧本里有才做，文字内容按剧本写。
- 超自然类（若有）：吊坠、印记或纹身。

## 五、光、色与质感

- 基调：好莱坞式的质感，资源集中在人脸和主场景。
- 质感「实」：保留皮肤纹理，少修饰；轮廓分明，落地窗的天光可以从人物的侧面、背后照过来，背着窗的一侧暗部可以更深。
- 不同画风：真人写材质和皮肤纹理；二维用各区的色板；3D 用玻璃、金属的反射。

## 六、易错点

- 所有空间都金碧辉煌；场景图画成廉价的平光影棚感；和中式审美混搭的服化道。
- 普通区出现贫民窟感；超自然区混进都市光源。
