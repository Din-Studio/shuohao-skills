# 题材 · 霸总甜宠（场景与道具）

## 先记住

1. **按阶层分区，两个区分别定规范。** 阶层差就是本题材的主线引擎，不能合成一句「现代都市」。
2. **阶层差靠具体物件体现**，不靠台词宣告，也不靠炫富陈列。

## 一、分区

| | Z1 高奢区 | Z2 平价区 |
|---|---|---|
| 用在 | 高档住宅、写字楼、高级酒店和餐厅 | 普通住宅、出租屋、小店、平价工作场所 |
| 完好度 | 完好 | 完好 |
| 维护 | 精心维护 | 旧，但不脏 |
| 光照基线 | 人工照明（约 3000–4000K）；大面积落地窗的天光（约 5500K） | 顶灯为主（约 3000–4000K）；窗小 |
| 光影锁倾向 | 照明充足，灯位可控 | 灯位随意，采光受限 |
| 色板 | 黑金、冷白、深蓝、大理石灰 | 米黄、木色、褪色蓝、暖白 |
| 材质 | 大理石、金属、玻璃、高支面料 | 复合板、瓷砖、棉麻、塑料 |
| 服化道 | 定制剪裁；腕表、袖扣承担身份信息 | 平价基础款，干净整洁 |
| 空间感 | 开阔、层高高、留白多 | 紧凑、物件密 |
| 适合出现 | 秩序感、克制的奢华 | 生活痕迹、使用磨损 |
| 不该出现 | 金碧辉煌的堆砌、浮夸装饰 | 脏乱、破败、贫民窟化、污渍、霉斑 |

跨区的对比是可以主动设计的画面（剧本里有就做）：

- 同一样东西在两区的样子不同（同是一杯咖啡：骨瓷杯和一次性纸杯）。
- 女主的服装演进就是她在两区之间的位置迁移，要看得出轨迹。
- 廉价物品出现在高奢的台面上（外卖盒放在大理石台面上）。

## 二、世界

- 当代中国一线或准一线城市，现实规则。

## 三、场景

- 宴会厅、公司这类围观多的场景，要留得下围观者的站位。
- **男主住宅的「生活痕迹」变体**是本题材特有的：女主的杯子、外套、拖鞋逐步出现，把关系推进变成看得见的东西。剧本里有这个推进时，按同一布局做前后两个变体。

## 四、道具

- 身份类：腕表、名片、车钥匙、合同。
- 情感类：戒指、旧照片、手写便签、女主的发绳。
- 对比类：廉价物和昂贵物同框。

## 五、光、色与质感

- 基调：**广告片式的精致**——光质柔和、亮处暗处差得不多（不出现死黑和过曝）。
- 阶层差靠面料、剪裁、腕表和细节，不靠夸张戏服。
- 不同画风：真人写面料与光质；二维用高奢区、平价区两套色板和干净的大块面；3D 用材质的光泽差（骨瓷与纸杯、大理石与复合板）。

## 六、易错点

- 平价区出现破败、污渍、霉斑；没有理由的贫民窟化。
- 所有空间都金碧辉煌；纯炫富陈列（和关系推进无关的财富展示）。
- 夸张戏服、浮夸配饰；死黑与过曝。
