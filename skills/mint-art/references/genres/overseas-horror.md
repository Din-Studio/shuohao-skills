# 题材 · 海外恐怖惊悚（场景与道具）

海外英语向题材，服化道按北美日常做，不和中式审美混用。

## 先记住

1. **恐怖来自「熟悉的东西变得不对」，不来自阴森的鬼屋。** 安全的地方完全正常、明亮、整洁，落差才出得来。
2. **按安全等级分区；同一空间在剧本里主光不同的两种状态（白天正常、夜里只剩一盏灯）做成同布局的两个变体**，是本题材最有分量的资产。
3. **不做威胁的完整形象。** 只做局部、剪影、痕迹和反射。

## 一、分区

| | Z1 安全（表面） | Z2 临界 | Z3 威胁域 |
|---|---|---|---|
| 用在 | 日常空间、白天 | 走廊、楼梯、地下室入口、夜里的家 | 威胁出没、留下痕迹的地方 |
| 完好度 | 完好 | 完好 | 完好或局部受损 |
| 维护 | 正常维护 | 正常维护（关键） | 按设定 |
| 光照基线 | 天光（约 5500K）、室内灯（约 2700–3000K） | 单一的室内灯（约 2700–4000K） | 单个光源（如应急灯，约 4000–6500K），或者没有主光（无灯） |
| 光影锁倾向 | 均匀、明亮 | 方向明确、大片暗部 | 极低照度 |
| 色板 | 日常家居的本色 | 同 Z1（同一个空间的物件） | 血红点缀 |
| 材质 | 正常 | 正常 | 可以有湿、锈、旧 |
| 空间感 | 开阔、看得见全貌 | 纵深长、画外空间大 | 封闭，或空旷得过分 |
| 适合出现 | 完全正常 | 阴影、反射、画外声源 | 威胁留下的痕迹 |
| 不该出现 | 任何异常暗示 | 明亮均匀的照明 | 威胁本体的完整展示 |

- 画外空间比画内更重要：门缝、镜子、窗外、床底，这些位置在场景的人物交互锚点里标出来。

## 二、世界

- 默认当代北美的日常环境：家、学校、医院、公寓楼。不默认废弃场所。
- 威胁的触发、限制，剧本里怎么写就怎么在空间和道具里体现，前后一致。

## 三、场景

- **主角住所的日 / 夜成对变体**是本题材的关键：恐怖发生在最熟悉的地方。

## 四、道具

- 日常异常类（最重要）：位置变了的物件、多出来的东西、少了的东西。
- 光源类：手电、手机屏、蜡烛、会闪的灯。
- 痕迹类：划痕、湿脚印、指纹、头发。反射类：镜子、玻璃、水面、黑屏。证据类：照片、录音、监控画面、日记。

## 五、光、色与质感

- 基调：「你家的走廊，但灯只亮了一半」。材质完全真实、日常，不做风格化做旧。
- 不同画风：真人写日常材质和单一光源；二维用大块暗部色块，异常处只画局部；3D 用单个点光源和大片暗部。

## 六、易错点

- 安全区一开始就阴森（毁掉落差）；默认废弃场所、鬼屋、破房子。
- 生成完整的怪物形象。
- 临界区用明亮均匀的照明；用滤镜和做旧去「做」恐怖感。
- 和中式审美混搭的服化道。
