# 题材 · 海外狼人（场景与道具）

海外英语向题材，国内没有对应题材，资产不和中式题材共用。

## 先记住

1. **两个世界的规则不同，视觉明确断开**：族群领地和人类世界，色温和光源类型都不一样。
2. **领地的夜里只有月光和火光**，不和都市光源混用——一出现路灯或霓虹，超自然感就塌了。
3. **人物变身成狼的过程不写实呈现**，资产只做人形和临界态（眼睛变色、青筋、指甲）的变体；剧本里本来就是狼、巨狼的，照剧本写实。

## 一、分区

| | Z1 族群领地 | Z2 人类世界 | Z3 敌对族群（可选） |
|---|---|---|---|
| 用在 | 领地、Alpha 宅邸 | 城镇、学校、职场 | 敌对族群的地盘 |
| 维护 | 维护良好 | 维护良好 | 维护良好 |
| 光照基线 | 夜里只有月光（约 7000K）和火光（约 2000K 以下）；白天是林间透下来的散射天光（约 6500K 以上），宅邸里是大窗进来的天光（约 5500K） | 现代人工光（约 3000–4000K） | 月光（约 7000K）加火把、篝火（约 2000K 以下） |
| 色板 | 深林绿、暖木色 | 城市灰 | 冷蓝、炭灰、血红点缀 |
| 材质 | 原木、粗石、皮革、毛皮、天然纤维 | 玻璃、金属、塑料、棉 | 铁、暗色皮革、兽骨 |
| 服化道 | 简化、耐撕裂、层次少 | 现代日常装 | 更硬、更有攻击性 |
| 空间感 | 开阔的自然空间、高挑的木构 | 常规都市尺度 | 封闭、压迫 |
| 适合出现 | 自然侵蚀、篝火、毛皮 | 现代一切元素 | 敌意符号、战利品 |
| 不该出现 | 现代都市光污染、霓虹 | 超自然元素外露 | 和领地同一套色板 |

- 人类世界完全正常，超自然不外露，身份揭露才有冲击力。
- 月亮的形状、月相写在镜头里，不进设定图。
- 和变身有关的服装，剧本里有变身的，做「完好 / 撕裂」两个变体。

## 二、世界

- 默认当代北美，小镇或近郊加森林、山区领地。族群层级、伴侣羁绊、变身条件按剧本设定，在服装、标识、空间上前后一致。

## 三、道具

- 羁绊标识（最重要）：伴侣印记或纹身、吊坠、族群纹样。
- 时间标记类：日历。权力类：Alpha 的信物、族群契约、界碑。
- 对照类：现代物件（手机、车钥匙）出现在领地里。变身相关：撕裂的衣物、爪痕、被留下的东西。

## 四、光、色与质感

- 基调：**自然的野性和克制的奢华并存**。保留皮肤纹理，材质要「实」，少修饰。
- 光：月光方向明确、投影硬，领地的夜里亮处暗处差得很多；火光范围有限；白天林间亮处暗处差得不多。
- 雾、呼出的白汽、飞尘只在剧本或设定里有时才写。
- 不同画风：真人写毛皮、粗石和月光的硬投影；二维用领地、人类世界两套色板和剪影；3D 用月光方向光与火光点光源。

## 五、易错点

- 领地里出现现代光源、霓虹、路灯；人类世界外露超自然元素。
- 和中式审美混搭的服化道；流浪者画成脏乱的流浪汉。
