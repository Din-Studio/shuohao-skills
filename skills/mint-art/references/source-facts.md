# 来源事实与制作补定

## 输入与读取

本阶段消费 outline v4 的资产投影，也支持显式 v3 历史投影。v4 来自已有剧本，不用小说改编计划冒充来源解析。production 保持 v3；独立设计入口不因 outline 的入口限制而删除。

`seed <outline.json>` 回查 provenance 中的文件。路径相对输入 JSON；校验原始字节 SHA256、行数、sourceRefs 和已读范围。LF、CRLF、裸 CR 均为物理换行；末尾换行不增加空白行。重叠已读区间按位置覆盖，不按文本去重。缺集来源保持 partial，不要求虚构全剧结局。API `seedFromOutline(outline,{outlinePath})` 带路径时执行文件核验；不带路径只检查结构，不能宣称已核对原文。

## 事实交接

- 每个资产的 `sourceFacts` 保存 sourceRefs、所引用的来源文件版本，以及已有 notes。CLI 将这些文件路径变成绝对路径，避免资产移到相邻阶段后误读。搬迁项目时重新运行 seed 并核对引用，不依赖旧机器路径。
- Markdown/HTML 报告派生展示 sourceFacts。JSON 是编辑源，不在报告中改写来源。
- 人物 ID 不按名字合并。同名人物可以有不同 ID。无台词人物同样保留。tier 映射 importance；主角组内部角色细分须依据原文，不默认改变分档。
- S ID 是地点身份，不是场次序号。primary 明确消费。道具持有人、破损与恢复沿来源场次回查；闪回不套用后来的状态。
- 画外声音不一定需要独立形象资产；仅被提及不等于必须出图。非人主体和群演先保留身份和依据，再按当前镜头需求分类。不能为符合既有画像模板而删除主体。
- notes 中的限制、有限让步、未揭晓身份与角色说法不能自动变成客观事实或公开表情。设计前回查当前场次的知情边界。

## 身份与产物路径

稳定 ID 不随同名对象合并。名字 slug 唯一时沿用 `images/<名字>-sheet.png`；同名或 slug 冲突时使用 `images/<ID>-<名字>-sheet.png`，防止覆盖。人物装配、报告节点和关系定位优先使用 ID；同名关系不得只凭名字猜测。新增同名对象后重新生成相关离线计划并核对图片路径，不将既有同名图片自动分配给另一个身份。

## 制作决定

复用、变体、材质、左右侧别等未被原文确定的内容是制作补定。写在现有设计字段；不得覆盖 sourceFacts 或伪造来源。outline v4 不再提供 reusePlan；兼容 v3 时旧复用说明仍仅作为历史提示，不升级为原文证据。

先核对故事和表达需求，再设计图像。设计完成后独立检查事实、状态与揭晓是否仍一致。确定性测试仅证明引用和消费路径；不代替内容审核。自动驾驶不能自行扩大转译或改写授权。

## 方法来源

内化自 script-parsing 的逐处读取、按来源位置归并和状态事实提取方法（原仓库调研资料名：剧本读取与记录、合并与正式交付）；以及本仓库长剧本连续性、视听表达调研。运行只读取本 skill 文件和用户输入，不依赖这些学习材料或兄弟 skill。
