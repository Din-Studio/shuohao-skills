# 术语（场景与道具）

本 skill 的 references 和 `genres/` 题材文件里提到《术语》时，指的就是这一份。

| 词语 | 含义 |
| --- | --- |
| **场景** | 戏发生的空间，连同那里的天气和现场效果（雨、雪、雾、烟、火）。天气和现场效果写在场景的光照状态或变体里，不单独建资产。 |
| **道具** | 能脱离人身、被拿来拿去或被特写的物件；车辆（汽车、摩托、自行车等）也算道具。穿在身上的衣服属于人物，不是道具。会被摘下、递出、丢失的挂件（项链、钥匙串、工牌）是道具，使用 `carrierRefs` 关联它的人物。 |
| **设定图** | 给某个资产单独出的参考图，之后的画面照它保持一致。对应 `image.sheet`。 |
| **基准 / 变体** | 基准：资产最常见的样子，从零画出。变体：剧本里出现的另一种稳定外观，以基准图为参考只改差异。场景的变体见**场景变体**；道具的变体是 `states` 里第二个及以后的状态。 |
| **场景变体** | 同一个空间的另一种稳定样子：**光的状态**持续变了（开灯、关灯、天色变化），或空间状态变了（清空、破损、布置）。人物情绪和剧情时刻不改变光，也不构成变体。需要出图的场景变体建成带 `variantOf` 和 `changes` 的变体场景；只需要文字约束的，留在母场景 `lighting` 的后几个状态里。 |
| **光源** | 画面空间里发光的东西：太阳和天空的光（叫**天光**）、月亮的光（叫**月光**）——这两样室外直接照到，室内从窗、门、天井进来——以及灯、火、屏幕、车灯。画面里的光都来自光源。 |
| **光的状态** | 此刻一直亮着的光源各从哪个方位照来、多亮、什么色温，它们照出来的亮处和暗处差多少（光比），加上天色。剧本让光源持续地变了（开灯、关灯、开门、点火、灭火、天色变化）它才变，变了之后一直有效；换镜头、换段、换机位都不变。情绪和剧情时刻不是光源，不改变光的状态。 |
| **主光** | 一直在、位置不动、亮灭会改变整个空间明暗的光源。一个空间可以有一个主光，也可以有几个一起照亮整个空间，比如白天开着顶灯的办公室（天光、顶灯）、夜里的街（路灯、霓虹）。几个主光写进状态名时按亮度从高到低排，如「日·天光·顶灯」。同一盏台灯，顶灯亮着时它只照亮桌边，不是主光；顶灯关了、只有它亮着，它就是主光。提示词里不写「主光」，写成 `the light comes mainly from …`。 |
| **局部光和其他光** | 主光以外的光：只照亮自己附近、亮灭不改变整个空间明暗的**局部光**（顶灯亮着时的台灯、手机屏、蜡烛），以及闪一下、扫过去、跟着人走的光（闪电、扫过窗户的车灯、手电）。它们亮灭、闪动、移动，写在镜头里，不写进设定图。 |
| **光影锁** | 一个场景光照状态里一直在、照着整个空间的光，写在这个状态的 `lighting[].prompt` 里，并写进出图的那张设定图。有主光时，就是主光的光源、方位、软硬、色温，加上这些光照出来的亮处、暗处、光比和阴影；空间里没有主光时，是一层很弱的环境光，画面压暗，墙、门、家具的布局看得清。 |
| **光照基线** | 剧本和场景设定都没写光源时，这类空间常有的光源，用来取主光；同一空间只取一次。取光按这个顺序，前一样有就不看后一样：剧本写的光源 → 场景已定的光影锁 → 光照基线（题材文件分区表里有）。 |
| **色温与冷暖** | 光源的颜色，随光源变。数字越高光越冷。约 2000K 以下暖橙（烛火、油灯、篝火）；约 3000K 暖黄（室内暖灯约 2700–3000K，清晨、斜阳的日光约 2700–3200K）；约 4000K 中性白；约 5500K 白（晴天日光）；约 6500K 以上偏冷（阴天、阴影、蓝调时刻）；月光按影视惯例处理成偏冷的蓝，约 7000K。 |
| **调色** | 不改变任何光源、对整幅画面统一做的处理：色调偏向、饱和度、整体反差和明暗风格。调色属于视频阶段，设定图不带调色。能指出是哪个光源造成的冷暖和明暗归光；整幅统一处理的归调色；墙面、陈设、材质本身的颜色归色板。 |
| **色板** | 物件本身的颜色：墙面、陈设、材质的颜色。同一个空间只取一套色板；色板归资产，设定图照它画。 |
| **方位** | 前后左右写清以什么为参照。**场景里的东西**：光、地方，点名从哪件固定的东西那一侧来，如「从卷帘门那一侧照进来」；光的高低另写。**场景自己的前后左右**：「前」是这个空间的主视方向，正对主要陈设或主入口的那面；四宫格各格的名字、锚点的方位、平面图的朝向都按这一种写。**某件东西自己的前后左右**：道具的正面、背面、左侧按道具自己写，如「盒盖的右后角」。 |
| **画风类别** | 按成片是拍出来的还是画出来的分两类。**拍出来的**：真人实拍质感。**画出来的**：再按手段分二维绘画（国漫、日漫、写实国漫、插画、水彩，使用线条、色块）和三维渲染（3D CG，使用建模和材质）。用户自己说的画风，按它成片的样子归进这几类。画风正文仍以 production 的 `style.scene` 为准。 |
| **固定句** | 规则里给出原文、并标明「固定句」的句子或句式。产出时照抄原文，只填句式里留的空。 |
| **照抄** | 把一段已有的文字原样再用一次。哪些地方要照抄，写在用到它的规则里。 |
| **估** | 一定要有值的项剧本和用户都没给，但剧本里有一句话限定了它，换一个值就和那句话对不上，按那句话推出来的值是估；剧本里没有限定它的话、哪个值都不和剧本冲突，按空间挑的是设计。见 [principles.md](principles.md) 第一节。 |
