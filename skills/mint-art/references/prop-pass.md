# 道具设定 · 怎么填

独立阅读原剧本的物品线索，先**选择**再**登记**，需要视觉设计时再填写设计字段。seed 不自动理解物品；designStatus: none 不执行本页设计要求。**只输出 JSON，不要解释、不要围栏。**结构见 `schema.md` 的 props 段；全局原则见 [principles.md](principles.md)，术语见 [glossary.md](glossary.md)。

## 先选择：什么配当叙事道具

是否需要特写连续性、跨集复现或承载剧情，可以作为建立美术资产的制作依据，不要求三个条件同时满足。口头提及不自动建立资产；背景陈设也不自动成为道具。记录 decision 与来源，无法判断时保持待确认。3–8 件只是参考，不是最低数量或隐式硬预算；明确预算保存在 art.budgets。

| 类型 | 归属 | 例子 |
| --- | --- | --- |
| **叙事道具** | 入选，单独建资产 | 旧留言板（代存与归还）、夹纸铁盒（核对归属） |
| 车辆 | 算道具，按叙事道具同样判断 | 主角的旧摩托、肇事的货车 |
| 会被摘下的挂件 | 算道具，使用 `carrierRefs` 关联人物 | 项链、钥匙串、工牌 |
| 穿在身上的衣服 | 属于人物，不入选 | 外套、制服、鞋 |
| 场景陈设 | 场景锚点或功能性元素已覆盖，不入选 | 挂钩、棚板、排水槽 |
| 一次性手部道具 | 按实际连续性需要决定，通常不独立建立资产 | 一碗茶、一份报纸 |

拿不准就问一句：这件东西被镜头怼着拍过吗？观众记得住它吗？剧情少了它转不动吗？三个都不是就不入选。

## 硬规则

1. **`summary` 写戏剧功能，再写实际尺寸。**「需要归还给邻居的私人留言记录」是戏剧功能；「棕色牛皮材质」只是材质。先说它在剧里干什么，末尾补一句实际尺寸「约长 × 宽 × 高」（剧本限定了就标「估」并写依据，见 [principles.md](principles.md)）。

2. **锚点要经得起特写。**道具的锚点比场景的更小更细：绿色边框的掉漆位置、铁盒角上的凹痕。特写镜头会把这些放大到全屏，**缺了立刻穿帮，多了核对不过来**——照旧 3–5 个。锚点的方位按道具自己的前后左右写（「盒盖右后角」）。

3. **尺度按长边定档，写死。**`scale` 三档：**手持级**（长边 30 厘米以内）、**桌面级**（30–60 厘米）、**家具级**（60 厘米以上）。档位决定设定图右格画哪一种尺寸参照，`image.sheet` 里必须出现对应的英文句（prop-scale 门查），并写 `actual size about <长 × 宽 × 高，带单位>`（prop-size-ref 门查）。AI 把手持道具画成家具尺寸是高频事故，右格的手或人就是用来压住它的。

4. **设定图是三格。**左正面、中格最容易认错的那一面、右格尺寸参照；纯白背景可抠（prop-white 门查）。版式固定句、中格三种角度和右格三档英文见 [sheet.md](sheet.md)。右格的手或人是匿名路人，只作尺寸参照，不是任何角色：不写角色名、不照角色的长相或服装、不露脸。

5. **反向词不禁手、不禁人。**右格本来就要画手或人，反向词写 `hands`、`people` 会和版式自相矛盾（prop-size-ref 门查）。道具的反向词写水印、商标、签名，本来不该有字的再加 `text, letters`。不必把画风那一块的每一条都带上——画风里冲着「环境别太干净」去的那几条和白底自相矛盾。

6. **状态变体从剧情反推。**留言板有夹纸、取纸，铁盒有合上、打开——道具的状态弧跟着剧情走。`states[0]` 是基准状态，`image.sheet` 画的就是它，它的 `prompt` 写一句这个状态的英文描述；这句不要求逐字出现在 sheet 里，但 sheet 的主体区必须把这个状态画出来，两者是否一致由内容复核检查（[sheet-prompt.md](sheet-prompt.md) 第六节）。`states[1]` 及以后每个状态写一条**完整的英文变体提示词**，按 [sheet-prompt.md](sheet-prompt.md) 第三节四块写：照抄版式段、正面光那一句、画风段和纯净画质段；以 `Based on the reference image,` 点名保持三格版式、主体结构、材质、形状、比例、颜色和右格尺寸参照的姿态与取景；以 `Change only the following:` 只写变了的状态（破损、燃烧、浸湿、磨损、碎裂、打开、带血的具体样子）。出图计划为每个后续状态导出一个依赖基准图的任务。没有状态变化的道具写一个主状态即可。

7. **关联要挂上。**`relatedScenes` 挂它主要出现的场景（id 必须存在），`carrierRefs` 明确引用 characters 已确认的 C ID、依据和 sourceRefs，不能使用自由名称猜测身份。这两样进报告，是排生成任务时查「这场戏桌上该有什么」的索引。

8. **提示词永远英文，绝不出现角色名**——图像模型会把它认识的名字画进去。画风段取用 `style.scene` 的渲染句（与场景同一套），质感短语写 `still-life studio texture`。

9. **磨损要指名道姓。**`vintage` / `worn` / `used` 太抽象，模型会画成崭新的复刻品。要写清坏在哪：珐琅缺了一角、皮带边缘磨毛、黄铜氧化发暗、杯沿一圈茶渍、常年被手握的那一处磨得发亮。**能写进锚点的磨损，才是能核对的磨损**。展开见 `realism.md` 第 4 节；画风非写实的那几档只取它通用的那半边。

10. **道具的光写柔和均匀的正面光**（`soft even frontal studio lighting`），物件上没有明显的阴影和色光：参考图上的光会被视频模型当成物件本身的颜色带进每一段视频。

11. **本来带字的道具写明文字的语言和内容。**文件、证件、包装、屏幕按 [sheet-prompt.md](sheet-prompt.md) 第五节写；剧情不需要看清的写难以辨认的小字。

12. **`image.prompt` 是单张白底展示图**：只画这件道具，纯白背景，不画手和人，同样写尺度和材质；它不进出图计划，供人审和下游挑选使用；写得再完整也不能代替 sheet 里的主体描述。

## 输入格式

```
画风（production.json 的 style.scene，渲染句与场景同一套）：
  render: …
候选物品线索（独立读取原件并记录 sourceRefs）：
- 许桂兰找出邻居代存的旧留言板，核对后归还（第 1–3 集）
- 夹纸铁盒暂存已分清归属的便条（第 2–3 集）
- 菜摊边的空塑料筐（没有独立剧情功能）
已有场景：S01 菜摊雨棚、S02 公共水池、S03 雨棚清空状态
```

上面第三条就该落选——既无独立连续性需要，也不承载剧情；不是因为名词出现就要建资产。

**学习来源**：道具与衣服、挂件、车辆的归属，三格版式，尺寸参照三档与「匿名路人仅作尺寸参照」，以及状态变体的四块写法内化自短剧资产图片提示词 skill（assets）的《术语》《人物》《道具》《设定图提示词》。

## 创作背景边界

先读 [creative-background.md](creative-background.md)。creativeBrief 仅作为项目自然语言要求，不推导规则。视觉正文必须来自 production.style.scene。节点无需分类；道具只保留显式 beatIds 引用，节点结果用于阅读，不凭同集出现推断精确节点归属。正式样例先确定《雨棚留言》故事提案，再设计资产；没有分镜或真实图片。
