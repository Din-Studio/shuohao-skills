# H3 填法

学习来源：MiniMax H3 官方 I2VA 提示词方法，经过本仓库参考图直出实践内化。本文件保留自然语言原则，不采用关键帧按秒对齐的私有语法。骨架见本地 method.md。

仅有效模型为 MiniMax H3 时读取。默认英文，显式中文要求可覆盖；台词、歌词及画面可见文字始终逐字保留原语言。英文正文以通用身份描述代替人物名字，台词中的人名不修改。

按图片顺序写 Picture k is …。每镜用 [Shot k]，同时包含本镜景别、运镜、动作及台词。说话人首次出现交代身份、年龄段、音色与语速；全段使用稳定称呼。不要凭空新增人物设定，缺少必要依据反馈主 session。

画外音写为 says in an off-screen voiceover while their lips remain completely closed。不要使用说话人编号、<d> 标签、Picture aligns 指令或精确切点。

环境声、动作声与配乐合并到 ambience:；没有配乐明确 no music，不新增 overall_soundscape 或 non_diegetic_music 字段。动作改变后声音也必须同步，不能让声音指令引入额外动作。

优先常见可观察动作，交代人物此刻位置；参考图锁定身份与材质，不能被文字描述矛盾覆盖。复杂精细交互及微表情不能承诺一定成功。

历史技术快照为 5–15 秒与 768p / 2K；提交前由主 session 查询实时 schema。超过上限不能截短故事，参数改变后重新审核。本文不构成视频生成授权。
