# 来源事实与制作补定

正式 cast v1 直接读取原剧本。outline v5 仅是可选故事背景，不能提供人物权威。旧 outline v3/v4 的资产、sourceFacts 和预算仅通过显式迁移成为待核对材料。

## 核验边界

- seed 保存原始字节摘要和物理行数，不读取语义、不生成覆盖声明。
- 人工或模型逐处阅读，填写 provenance.coverage 与身份 sourceRefs。位置必须在文档和已读范围内；quote 必须位于指定行范围。
- LF、CRLF、裸 CR 均为物理换行；末尾换行不额外增加行数。UTF-8 解码非法即失败。原始字节摘要不会忽略换行差异。
- partial 可以正式登记局部身份，但不能宣称全剧完成。complete 必须覆盖所有原件。
- 输入路径相对记载它的 JSON。源文件缺失、损坏或改版均阻断；可选背景未提供才是 skipped。

## 身份与设计

sourceRefs、aliases 的证据和 notes 是原文身份依据。persona、image、voice 是可选设计，包含推断时标注“（推断）”。人物可以只有身份而没有画像、音色或图片。

同名、匿名、非人、无台词、声音和提及身份均不因缺少设计而删除。未知项保留 unknowns；不靠名称字符串匹配决定归并或正文映射。

## 变化与审核

reconcile 消费既有 cast。相关文档的摘要变化会使实际依赖该文档的身份进入 recheckIds，ID 不变；无关文档不自动使所有身份失效。身份改名、别名或出处纠正要记录 correct 及依据。合拆删保留退役登记和显式映射，历史 ID 永不复用。

参考图、图片计划、联合映射、工作单和内容审核必须按受影响的实际引用重新核验。图片计划中的 identityFingerprint 只证明计划绑定的身份输入，不是图片审核证明。review.inputHash 变化时原语义确认失效；reconcile 对身份、来源和范围变化输出 pending，纯重排可沿用绑定摘要不变的既有审核。
