# 术语（人物部分）

本 skill 文档和 `genres/` 题材文件里提到《术语》时，指这一份。

| 词语 | 含义 |
| --- | --- |
| **人物** | 剧中的人和人形主体，连同穿在身上的衣服、鞋、一直戴着的配饰。衣服属于人物，不是道具。 |
| **道具** | 能脱离人身、被拿来拿去或被特写的物件，车辆也算。会被摘下、交出、拿走的挂件和手持物是道具，归 mint-art 登记，不画进人物设定图。 |
| **群演** | 成群入镜、不单独区分的人。一批群演登记成一个 `entityType: group` 身份，出一张群像图；单个路人只登记身份，不出图。 |
| **设定图** | 给某个人物单独出的参考图，之后的画面照它保持一致。本 skill 里它就是 `image.sheet` 那条提示词出的图。 |
| **身份卡** | 人物的固定数值和特征：性别、年龄段、身高、人种标签，以及设定图会画出来的外观。在 cast v1 里对应已登记身份加上 `persona` 已定的外观；设定图提示词照它写。 |
| **基准 / 变体** | 基准：人物最常见的样子。变体：剧本里出现的另一种稳定外观（换装、受伤、跨年龄），以基准图为参考只改差异。cast v1 每个身份只有一个 `image` 块，没有变体槽位，所以本阶段只出基准图，变体写法见 [sheet-prompt.md](sheet-prompt.md) 第四节，作备用说明。 |
| **人种标签** | 写成「国籍或地域 + 族裔 + 性别」，如「美国白人男性」「美国非裔女性」「巴西拉丁裔男性」；国籍或地域本身已看得出族裔的（中国、「东亚」）只写一次，写「中国女性」「东亚男性」。性别写「男性」或「女性」。族裔每个人各按剧本定；架空、非人的种族，外形是人的，族裔一项写「种族名、人形、看起来像哪类现实人群」，如「精灵族女性，人形，东亚长相」，剧本没线索就按角色设计；外形本来就不是人的，人种标签写种族名和性别，外形照剧本写。英文提示词照英文语序写，如 `Chinese woman`、`Black American man`。 |
| **方位** | 前后左右写清以什么为参照。人物身上的东西（伤痕、配饰、持物的手）一律按**这个人自己**的前后左右写，如「他的左脸颊」「她的右手腕」；不按画面左右写。 |
| **画风类别** | 按成片是拍出来的还是画出来的分两类。**拍出来的**：真人实拍质感。**画出来的**：再按手段分二维绘画（国漫、日漫、写实国漫、插画、水彩这类，使用线条、色块）和三维渲染（3D CG，使用建模和材质）。写实国漫名字里有「写实」，成片是画出来的二维。用户自己说的画风，按它成片的样子归进这几类。画风正文本身只来自 production 的 `style.character`，见 [style.md](style.md)。 |
| **固定句** | 规则里给出原文、并标明「固定句」的句子或句式。产出时照抄原文，只填句式里留的空。 |
| **照抄** | 把一段已有的文字原样再使用一次。哪些地方要照抄，写在用到它的规则里。 |
| **估** | 一定要有值的项剧本和用户都没给，但剧本里有一句话限定了它，换一个值就和那句话对不上，按那句话推出来的值是估；剧本里没有限定它的话、哪个值都不和剧本冲突，写手按角色挑的是**设计**。估在 `persona` 里标「（推断）」，设计不标，见 [principles.md](principles.md)。 |
| **存疑** | 剧本没写清、按最合理的理解做了、需要用户点头的选择。写法见 [principles.md](principles.md) 第二节。 |
| **全剧美术常量** | 题材文件里标明「是全剧美术常量的一项」的设定（形制、阵营色板、感染体形态等），全剧所有人物照同一套写，前后不变。 |

---

**学习来源**：内化自短剧资产图片提示词 skill（assets）的《术语》，只保留人物会用到的词，并补上和 cast v1 字段的对应关系。
