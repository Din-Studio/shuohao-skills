# 独立阅读与身份扫描

读取原剧本，不以 outline 的称呼或其他人物表作最终判定。脚本只做骨架和确定性校验，人工或模型负责语义识别。

1. 先填写实际已读取的文档和范围。记录每处身份依据的行号；覆盖缺口不可以宣称已读。
2. 建立永久 identityKey。增量时先读取本阶段既有 cast，以身份事实和出处认领旧 ID，不能按名字或出现序号重新分配。
3. 同名人物没有同一身份证据就分别登记。别名只有出处足够时才归并；同姓、职业相同、声音相似不能代替证据。
4. 无台词、匿名、仅出声、非人主体、仅被提及人物均登记。对未知说话者建立有限定位置的描述，unknowns 保留不确定性；不能为了清空待确认项猜测身份。
5. 多处声音不能确认同人时保留不同 identityKey。人物出场顺序不应提前揭晓后文身份。
6. 来源事实放 sourceRefs、aliases、notes；画像、声线和服装补定放可选 persona、voice、image。
7. 初次 ID 可留空交给 reconcile；增量新身份也不手填 ID。所有合拆删纠正通过显式 changes 保留映射与依据。

## 人物和资产的边界

登记身份时顺带判断哪些东西归人物、哪些不归，后面出图才不会画错：

- **穿在身上的属于人物**：衣服、鞋、一直戴着的配饰写进 `persona` 和 `image`。
- **摘得下的是道具**：会被摘下、交出、拿走、特写的挂件和手持物（信物、钥匙、箱子、武器），以及车辆，归 mint-art 作道具登记，用 `carrierRefs` 引用本阶段的 C ID；不画进人物设定图。
- **成群的群演按一批登记**：成群入镜、不单独区分的人，按一批登记成一个 `entityType: group` 身份，需要视觉呈现时出一张群像图（见 [crowd.md](crowd.md)）。不同批次分别登记，不按名字合并。
- **单个路人只登记不出图**：只出现一次、没有连续性要求的单个路人照常登记身份（无台词也登记），不写 `image`。
- **未成年人物**：年龄 17 岁及以下的人物照常登记；剧情要求的睡衣、泳装、湿透、洗澡、躺在床上这类状态不出图，在交付汇报里写明不出图和理由（见 [sheet.md](sheet.md) 第四节）。
- **外观变化不另立身份**：换装、受伤、变老是同一个人的变体，不新建身份。cast v1 没有变体槽位，本阶段只出基准图，变体写法见 [sheet-prompt.md](sheet-prompt.md) 第四节。

学习来源：上面几条内化自短剧资产图片提示词 skill（assets）的《术语》「道具」、《人物》《群演》中的归属与出图规则。

示例：examples/回声台.txt 的两名许禾分别是 night 与 morning；小禾是夜班员的别名。隔壁喊话者、扬声器声音和第二集窗外声音不能自动合并。灰点为非人主体；梁师傅仅被提及；女孩无名且无台词。

身份登记没有按名字自动归并的路径；同人判定只能来自原文证据或显式 changes。

语言、字段和来源核验见 [schema.md](schema.md)。创作背景见 [creative-background.md](creative-background.md)。
