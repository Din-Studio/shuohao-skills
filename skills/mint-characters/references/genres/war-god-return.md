# 题材 · 战神归来（人物）

和都市逆袭的区别：逆袭的主角真是从零往上打，本题材的主角一开始就在顶点，只是身份没揭开。

## 先记住

1. **按身份层分区**：伪装的市井、对手的权贵、真身所在的权柄。真身层是旧部、组织所在的空间（军部、旧部驻地），视觉上和前两层明确断开。
2. **伪装 ≠ 落魄。** 主角选择低调，不是真的穷：空间整洁有维护，只是不贵。
3. **主角的几套造型是最重要的资产**：同一张脸，几种气场；手上的茧和疤在每一套里都一样。

## 一、分区（只列和人物有关的两行）

| | Z1 市井（伪装层） | Z2 权贵（对手层） | Z3 权柄（真身层） |
|---|---|---|---|
| 用在 | 主角伪装身份的日常 | 岳家、对手企业、宴会 | 军部、组织、旧部所在 |
| 服化道 | 普通夹克、旧鞋 | 定制西装、珠宝、名表 | 制服、徽章、战术装备 |

场景的分区由场景设定负责，这里只用来判断人物在哪个区出现、穿什么。

## 二、世界

- 当代中国都市，现实规则为主。剧本里的组织、军部、家族这类权力结构，靠编制、层级和可见的符号（徽章、编号、令牌）体现。
- 主角的强大来自过往经历和积累的资源，不是超能力；不画成光效、气浪、金光。

## 三、人物

- 主角：剧本里有对应身份的，按伪装 / 被迫穿正装（不合身）/ 制服分别做，不做成一套换配饰。站姿和眼神要可读——他话少、不解释，压迫感来自克制；造型不浮夸。
- 妻子或家人：关系的承载者、被轻视的人（剧本里有对应场合时，可分日常 / 被羞辱场合 / 后期）。
- 岳家或轻视者：势利、浮夸，服装「用力过猛」；剧本里有起落，可分得意期 / 崩溃期。
- 旧部：制服、编号、绝对服从的体态。
- 真正的对手：和主角同层级的人，出身权贵或真身层。

## 四、易错点

- 市井写成脏乱、破败；主角造型浮夸、时装化；几套造型只做一套换配饰。
- 用光效、气浪、金光表现「强大」；超自然元素（属于玄幻）。
- 真身层出现都市的随意感；旧部制服做成角色扮演的质感。
- 所有权贵空间都金碧辉煌。
