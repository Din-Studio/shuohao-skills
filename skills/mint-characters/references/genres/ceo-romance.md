# 题材 · 霸总甜宠（人物）

## 先记住

1. **按阶层分区，两个区分别定规范。** 阶层差就是本题材的主线引擎，不能合成一句「现代都市」。
2. **阶层差靠具体物件体现**，不靠台词宣告，也不靠炫富陈列。

## 一、分区（只列和人物有关的两行）

| | Z1 高奢区 | Z2 平价区 |
|---|---|---|
| 用在 | 高档住宅、写字楼、高级酒店和餐厅 | 普通住宅、出租屋、小店、平价工作场所 |
| 服化道 | 定制剪裁；腕表、袖扣承担身份信息 | 平价基础款，干净整洁 |

场景的分区由场景设定负责，这里只用来判断人物在哪个区出现、穿什么。

## 二、世界

- 当代中国一线或准一线城市，现实规则。

## 三、人物

- 男主：面部质感第一位；西装合体不夸张；腕表、袖扣、领带夹承担身份信息。剧本里有对应场合的，可分通勤正装 / 居家便装 / 正式礼服。
- 女主：路人缘优先于艳丽；服装从朴素到精致有可见的渐变，不做突兀的「换装秀」（剧本里有对应阶段时，可分初始 / 转变后 / 高光场合）。
- 施压者（常是女配或男主家的长辈）：服饰精致，带攻击性的细节（尖锐廓形、浓艳的颜色）。
- 助理、秘书：高度职业化，是男主身份的注解。

## 四、易错点

- 平价区出现破败、污渍、霉斑；没有理由的贫民窟化。
- 所有空间都金碧辉煌；纯炫富陈列（和关系推进无关的财富展示）。
- 夸张戏服、浮夸配饰；死黑与过曝。
