# Seedance 填法

学习来源：火山引擎《Doubao Seedance 2.0 系列提示词指南》https://docs.volcengine.com/docs/82379/2222480 ，经本仓库参考图直出实践内化。这里保存本地方法，不依赖在线文档或其他 skill 执行。骨架见本地 method.md。

适用于 seedance2.5、seedance2.0、seedance2.0 fast、seedance2.0 mini。默认中文；显式语言要求可覆盖，台词原文不改。未知模型不能套用本指南。

以“图 k 是……”按图片顺序说明人物/场景/道具，人物标签稳定复用，中文可以使用原人物名。角色设定图若包含多个视图，应明确其为同一人物的设定参考，不把版面生成成多个人。仅挂载本段实际需要的素材，不堆满引用数量；多人同框需注意身份混淆风险。

镜头描述：下面逐行 [镜头 k]，包含景别、单一运镜、主体位置、可观察动作与逐字台词。台词使用 {} 包裹，明确说话主体，不借发音优化改写台词。环境声与配乐：收尾后可补画质与约束描述；不要把约束插入镜头切片之间。

禁止在 prompt 内写数字秒数、秒数区间或时间码，例如“第3秒”“0–3s”“00:03”。用“随后”“缓慢观察”等顺序表达。总时长由生成参数传递，不放到正文。

一镜不同时要求推拉摇移；避免复杂精细物理交互。画面、声音及人物身份保持一致；不能为了风格新增剧情事实。需要画面文字时说明后期风险，不承诺可读。

历史技术快照：2.0 系列 4–15 秒，2.5 为 4–30 秒。提交前由主 session 核对实时 schema 与价格，超过上限调整制作方案而非截短故事。内容审核不授予付费权限。
