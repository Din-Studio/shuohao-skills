# 单元故事结构：剧本阶段

## 适用目标

让单元有完整的行动与停点，同时保留人物连续性。

## 表达方法

每集场次围绕上游局部事件组织；closure 可以是达成约定或完成一次尝试。终局开放也照常投影，不补造追更悬念。

## 应避免的做法

避免每集重置人物关系；不要在完成后机械附加陌生来电。

## 正例

双方完成物品交接，最后一拍留在他们各自重新安排桌面。

## 反例

单元已完成却加一条神秘短信，只为统一集尾格式。

## 内容评审问题

本集主要行动是否完成？后续人物还记得本集发生的事吗？评审须引用具体集号、认领段与实际台词，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
