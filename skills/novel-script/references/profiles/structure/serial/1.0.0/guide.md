# 连续故事结构：剧本阶段

## 适用目标

保持跨集行动与关系状态连续，容纳局部结束。

## 表达方法

按上游 ending 表现 suspense、closure 或 open；跨批次传递已经知道的信息与已作出的选择。

## 应避免的做法

不要把普通集收束改成威胁；不在剧本另行发明问题期限。

## 正例

核对结束后人物收起已排除的证据，下集从尚未核实的材料继续。

## 反例

下集无依据地让人物忘记上一集已经确认的事实。

## 内容评审问题

跨集状态是否一致？末拍呈现的是已完成部分还是留下的余味？评审须引用具体集号、认领段与实际台词，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
