# 连续追更结构：剧本阶段

## 适用目标

明确表现上游悬念的提出与后续节点的解决。

## 表达方法

opening 与 ending.mode/event 原样投影上游；endBeat 指向本集最后一拍。Q 的期限与解决表仍归大纲，正文通过认领段落实答案。

## 应避免的做法

不能将批次末集当作全剧最终集；不复制 question 字段到剧本 ending。

## 正例

末拍展示被替换的文件，下一集认领节点通过实际查证给出解释。

## 反例

只写“悬念陡生”，末拍却是与该事件无关的道别。

## 内容评审问题

末拍是否表现上游结束事件？后续认领段是否真正回答问题？评审须引用具体集号、认领段与实际台词，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
