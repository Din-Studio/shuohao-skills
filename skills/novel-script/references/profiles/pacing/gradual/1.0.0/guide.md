# 渐进累积节奏：剧本阶段

## 适用目标

允许观察、推理和关系变化占据必要时间。

## 表达方法

不限制开场拍数；单句超过60个计数字符时提醒检查可表演性。使用统一估时记录行动、对话和停顿，较晚揭示仍需有过程推进。

## 应避免的做法

不能继承密集策略的开场硬要求；慢热不能只靠延长空白。

## 正例

人物先核对两份记录，在措辞差异处停顿，再提出一个更具体的问题。

## 反例

相同疑问连续出现三次，每次只增加沉默而不改变信息。

## 内容评审问题

认领段如何增加信息？停顿是否让观众获得观察机会？评审须引用具体集号、认领段与实际台词，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
