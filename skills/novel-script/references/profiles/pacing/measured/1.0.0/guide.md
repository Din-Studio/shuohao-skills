# 舒缓推进节奏：剧本阶段

## 适用目标

让交流和日常过程按内容需要展开。

## 表达方法

开场窗口与台词长度规则默认关闭；仍须提供合法 openingBeat/endBeat 和估时。对话长短服从人物与情境，动作不是可以优先删除的填充物。

## 应避免的做法

关闭长度规则不等于可以超出目标时长；不为节奏制造无上游依据的冲突。

## 正例

两人完成一道工序后才回应先前的问题，工序让回答更有分量。

## 反例

动作栏反复写“继续等待”，不说明等待期间的观察或关系变化。

## 内容评审问题

过程是否有表达价值？正文是否仍能在目标时长内执行？评审须引用具体集号、认领段与实际台词，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
