# 密集兑现节奏：剧本阶段

## 适用目标

较早进入事件，让结果在正文中清楚可见。

## 表达方法

建议开场落点在前3拍，单句不超过30个计数字符；这两项为 warn 提醒，不替代有效坐标与时长校验。优先删除重复表达、无效过渡，不删除关键因果。

## 应避免的做法

不要为短台词打碎必要解释；不能把多个认领段重复放在同一结果上。

## 正例

开场即处理已发生的争议，证据出现后给人物明确反应，再进入新压力。

## 反例

为了快速进入下一节点，把证据、决定和后果全部删成一句旁白。

## 内容评审问题

结果是否可见？较短表达是否仍保留人物差异与因果？评审须引用具体集号、认领段与实际台词，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
