# 生活题材：剧本阶段

## 适用目标

让日常语言、劳动过程与关系边界成为可执行正文。

## 表达方法

让人物在处理具体事务时交流；保留不同生活节奏和表达习惯。普通集 closure 遵循上游，不添加威胁。

## 应避免的做法

避免所有台词只讨论主题；不要给日常争执强加反派口号。

## 正例

两人边分装饭菜边协商轮班，明确说出各自无法承担的时间。

## 反例

人物停下所有活动，轮流长篇宣告家庭价值。

## 内容评审问题

事务是否真实影响谈话？对白是否改变安排或理解？评审须引用具体集号、认领段与实际台词，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。

## 来源说明

依据本仓库《Skills 创作策略解耦改造方案》第5、7、8节整理，并针对本阶段独立编写。示例为本指南原创微型情境，不借用其他 skill 的正式样例。数值是可替换的创作起点，未经真实投放效果验证；不依赖外部 skill 或联网资料。
