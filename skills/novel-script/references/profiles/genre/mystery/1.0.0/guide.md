# 悬疑题材：剧本阶段

## 适用目标

把上游信息推进落实为可表演的发现与判断。

## 表达方法

按 beatId 认领每个节点；在 flow 中区分看见证据、解释证据与作出行动。观众需要有机会看到支持判断的内容。

## 应避免的做法

不增加第二份 Q 计划；不得把调查结论仅交给无依据的旁白。

## 正例

人物先读出登记时间，再看见停电记录，停顿后划去一个候选人。

## 反例

人物突然说“我全明白了”，正文没有提供可检查的材料。

## 内容评审问题

认领段实际展示了哪条线索？错误解释是否有合理依据？评审须引用具体集号、认领段与实际台词，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。

## 来源说明

依据本仓库《Skills 创作策略解耦改造方案》第5、7、8节整理，并针对本阶段独立编写。示例为本指南原创微型情境，不借用其他 skill 的正式样例。数值是可替换的创作起点，未经真实投放效果验证；不依赖外部 skill 或联网资料。
