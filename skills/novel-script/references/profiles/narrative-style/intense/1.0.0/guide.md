# 强烈叙事：剧本阶段

## 适用目标

让紧迫冲突中的每句台词和动作改变局面。

## 表达方法

围绕信息、选择和代价推进攻防；高强度不要求所有台词都短促。关键结果后保留必要反应时间。

## 应避免的做法

避免持续吼叫；不能为压缩时长删除关键证据或选择。

## 正例

对方准备离开时，人物出示原始账本并承认自己的签名，迫使谈判转向责任。

## 反例

角色反复喊“你会后悔”，没有新增信息或行动。

## 内容评审问题

哪一句改变了可选方案？情绪高点是否有因果支撑？评审须引用具体集号、认领段与实际台词，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
