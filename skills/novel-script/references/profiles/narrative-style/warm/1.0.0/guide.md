# 温暖叙事：剧本阶段

## 适用目标

通过可观察的照顾和回应表达理解。

## 表达方法

给帮助者与被帮助者各自的需求和选择；允许拒绝、尴尬和有限和解。

## 应避免的做法

不使用说教台词代替具体帮助；不强迫受伤者当场原谅。

## 正例

对方说不想谈，他把热水放在够得到的位置，转而确认明天的安排。

## 反例

角色强行拥抱被拒绝的人，旁白却宣称所有隔阂消失。

## 内容评审问题

照顾是否尊重边界？回应是否具体而非口号？评审须引用具体集号、认领段与实际台词，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
