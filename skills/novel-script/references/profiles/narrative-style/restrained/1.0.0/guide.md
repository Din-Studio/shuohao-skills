# 克制叙事：剧本阶段

## 适用目标

在可表演行为中保留情绪余地。

## 表达方法

让短句、停顿与细节各有具体作用；停顿使用真实动作或明确表演提示，并计入统一估时。

## 应避免的做法

避免把克制误写为所有角色都不说话；不要删掉理解行为所需的信息。

## 正例

她先问列车几点，看到行李后才改口问是否需要送站。

## 反例

连续写多处“沉默良久”，却没有目光、动作或情境变化。

## 内容评审问题

哪一拍承载未说出口的意思？停顿是否改变对话关系？评审须引用具体集号、认领段与实际台词，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
