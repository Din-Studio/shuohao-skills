# 剧本 v2 报告约定

冷灰纸面、铁锈红强调、离线单页。零网络依赖，正常转义文本、属性和内嵌 JSON。数据内嵌时将小于号转成 \\u003c，导出后还原为输入 JSON，不能追加统计、默认参数或评审结论。

## 信息顺序

作品承诺 → 四维选择快照 → 当前有效参数、覆盖路径与来源 → 分集正文 → 逐拍估算轴 → 节点 setup/outcome 与核心段并排 → 上游 Q 与回答落点 → 场次资产 → 台词本 → 基础检查、策略检查、来源与内容评审状态。

不固定展示爽点密度 KPI。没有 outline 时不猜测认领段类型。无效范围显示不可用，不显示为零秒。

## 状态

检查仅采用 pass/fail/skipped，不维护 ok。warn 的 fail 显示“提醒”，不计通过，不阻断。off 显示“跳过／策略关闭”。缺上游显示“跳过／缺少上游”，不能显示“视为通过”。stage-incomplete 与 not-applicable 单独展示。

报告始终声明“内容评审未执行”，不会依据字段齐全生成内容质量结论。可由当前工作记录另附人工或模型评审证据。

## 交互与语言

中英 UI，正文不翻译。分集双列，窄屏单列。节点并排区域窄屏改为上下排列。正文可通过 details 折叠，节点坐标锚点定位正文。台词可复制，音色只读取给定 cast，不猜测。复制失败显示反馈。

打印展开 details，打印后恢复。导出创建 Blob，延迟撤销 URL。HTML 为可再生派生文件，不进版本控制。旧 assets/report.webp 不作为 v2 验收证据。
