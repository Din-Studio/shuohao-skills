# mint-video-prompt-review

当前交接使用 v4 script/outline；creation/production 仍为 v3。完整规则见 [来源、非发声说明与跨镜声音交接](references/source-audio-handoff.md)。场次 notes 不发声，audioRefs 只延续同一次台词，不跳过镜头、不改变台词顺序。解析来源 ID 必须与上游版本对齐。摘要绑定显式场次资产与局部开场／集尾意图；来源、声音方式或相关限制改变后，仅相关段重新审核。同名资产通过稳定 C/S/P ID 区分图片路径，不修改原始名称。结构／字节核验不是来源忠实性或成片验收。

视频提示词**审核方**。独立审核编写方提交的工作单，把意见写进同一份工作单，并登记结论。

- 审核依据只有剧本节拍、资产表、项目要求和视频模型口径，不采信编写方的自我评价。七个维度与阻断标准见[审核清单](references/审核清单.md)。
- 意见分为 `[必须修改]`、`[建议]` 与 `[阻塞]`。没有必须修改和阻塞就批准；有必须修改才退回；编写方无法单独解决的问题登记为阻塞。意见只保留本轮，不做累积记录。
- 批准绑定内容与输入：批准之后分镜结构或提示词正文被改动，或者这一段依据的节拍原文、参考图内容、模型参数、项目要求发生变化，批准自动失效。
- 只审核，不改写分镜结构和提示词正文，不生成视频。工作单格式见 [worksheet](references/worksheet.md)。
- 通常由调度方以 subagent 方式调用，也可以单独使用。Node 18+，只有标准库依赖；整个目录可以单独复制。

完整步骤与命令见 [SKILL.md](SKILL.md)。
