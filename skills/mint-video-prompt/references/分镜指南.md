# 分镜指南

## 目标与边界

把已经确定的故事变成可以看见、可以听见的行为。先读懂这一集发生了什么，再安排分镜。生成段是技术单位，不是每段都需要悬念的叙事单位。

段的划分与段间衔接由 script 阶段的分镜文件确定（输入材料的 `storyboard`）。编写方按分镜分段，在段内安排节拍认领、表演停留和参考图，再写提示词。cuts 保留为内部节拍认领与估时计划；景别、运镜枚举不要求进入正文，段内实际切镜与运镜交给视频模型。不新增故事事实，不改写台词，不替人物补上剧本没有写的心理结论。

## 从要求判断方向

先读项目要求。把「克制」「强烈」「温暖」这类形容词追问成实际目的：观众需要观察什么，人物希望隐瞒什么，哪一次选择改变了关系。不要把题材、画幅或模型名称变成默认的剪切频率。

没有项目要求时，提出一个符合实际正文的表达方向，并在回报里说明依据。要求与正文冲突时引用具体节拍，请调度方转交作者决定。

## 按分镜分段

输入材料带有 `storyboard` 时：

- 段号、所属场次和节拍范围与分镜逐段一致。工作单的 `id`、`sceneIndex` 与 cuts 认领的节拍范围必须等于分镜对应段；结构检查逐段对账，不一致即失败。
- 分镜的单段上限不超过制作单段上限。分镜某段装不进有效视频模型的时长区间，或者分镜本身有误（拆段、状态、揭晓顺序），不要自行重新拆段：在回报里说明，由调度方退回 script 阶段修订分镜。
- 「本段推进」「必须呈现的信息」是这一段必须完成的事；「段首状态」「段尾状态」是正文开头与结尾必须成立的状态；「段首复写」「供下一段复写的内容」是剪辑需要的重叠动作；环境音、音效写进正文发生的位置；背景音乐、人物说明、场景说明、故事理解、台词对照交给后期，不写进生成正文。
- 段首复写的时间计入本段第一个分镜的 seconds；全集总时长因此偏高时，向调度方报告，不删减剧本内容。

输入材料没有 `storyboard` 时（单独使用本阶段），按下面的拆段原则自行分段，并在回报中说明分段没有经过 script 分镜确认。

## 拆段原则

- 每段对应一次生成，不跨场次，换场必须另起一段。
- 先找出人物的目标、情节的关键变化，以及观众何时得知每条关键信息，把需要连起来看的动作、对白、反应和结果组织在同一段。
- 超出单段上限时，优先在一个结果已经看清、下一步行动尚未开始的位置拆开；长对白或连续动作必须跨段时，选语意完整的停顿或动作阶段的交界。不要放在一句台词或一个动作的中间。
- 相邻两段内容需要连起来看、合并后仍不超过上限，并且观众仍能辨认时空变化和情绪转折时，合并。短段能独立承担明确的叙事作用时可以保留。

## 节拍认领

- 每个分镜认领同场的连续节拍。全集节拍恰好被认领一次，顺序不倒退。跨镜声音通过 audioRefs 指向更早镜头拥有的同一次台词，不重播、不重复认领。每个延续镜头仍拥有实际 flow。
- 完整读取 `source-audio-handoff.md`：notes 不发声，字幕不冒充台词，声音 mode/audibleTo/subjective 不得偷换。来源或正式表达有疑问返回上游，未授权转译候选留在 .work。
- 段长不超过单段上限，并落在模型合法区间内。超出单次能力的长镜头应当调整分段方案，不承诺多次生成天然连续。

## 停留与切换

- 每次停留都要有具体内容：人物两次调整物件位置后才递出，比写「情绪复杂」更可观察。
- 每次切换对应信息、关系或空间的变化。频繁换角度导致观众分不清物件归属时，减少切换。
- 证据需要可读的停留：文字、印章、物件比对要给足时间，不与台词挤在同一镜里一闪而过。
- 人物的选择与选择的结果都要进入画面，不因为时长紧张而省略其中一个。
- 没有通用的建议时长硬门，也没有长镜头天然更高级的规则。

台词估时不是实际表演速度。时间不够时先压缩重复表达和无效过渡；仍然不够就在回报里说明，由上游调整目标或分镜，不擅自删改原文。

## 开场与集尾

开场和集尾的意图来自上游。材料里标注了开场节拍时，对应镜头要真正表达开场；没有标注时不要把第一拍称为已经核验的开场。集尾按剧本实际的最后一拍收束：已经发生的收束就表现收束，留下的余味就保留余味，不为了追更制造剧本没有写的新威胁。

## 段间连续

相邻两段分别生成，模型不会记得上一段。每段正文从分镜的「段首状态」写起，重新交代人物此刻在哪里、手里有什么、朝向哪里；有段首复写时，先完整写一次复写，再进入本段剧本。正文结尾写到分镜的「段尾状态」成立。上一段结束时站着的人，下一段不能无故坐着。光线、服装、手持物和声音环境保持一致；确实无法保证的连续性在回报里列为未验证风险。

## 参考图

挂载这一段实际引用的设定图，并让 @图片N 的编号与 images 数组顺序一致。在参考素材和正文写出对象全称及对应引用。文件存在不证明构图、人物身份或文字辨识会成功。画面里需要观众读清的文字，在回报里注明可能需要字幕或后期。

## 学习来源

内化自本仓库 mint-creation 既有的分段、节拍认领与参考图实践，其创作指南中关于信息、停留与连续性的讨论，以及用户提供的 storyboard-video「分镜」规则中的拆段与段间衔接原则。正反例为本 skill 自有的微型情境。不依赖其他 skill，也不声称经过真实投放效果验证。
