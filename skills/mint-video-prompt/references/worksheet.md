# 工作单格式

每段一份，路径固定为 `<工作单目录>/<段号>/prompt.md`。它同时是编写与审核的协作文件，也是视频生成时读取提示词的文件。

````markdown
---
segment: E01-01
status: in_review
round: 1
model: MiniMax H3
promptLang: en
bodyHash:
inputHash:
---

# E01-01 · 视频提示词工作单

## 分镜结构

```json
{ "id": "E01-01", "sceneIndex": 1, "cuts": [ ... ], "images": [ ... ] }
```

## 审核意见（仅本轮）

（尚未审核）

## 编写回应（仅本轮）

（无）

---

<提示词正文>
````

## 谁写哪一部分

| 区域 | 编写方 | 审核方 |
| --- | --- | --- |
| 状态头 | 通过 `submit` 命令改写，不手工编辑 | 通过 `verdict` 命令改写，不手工编辑 |
| 分镜结构 | 编写 | 只读 |
| 审核意见（仅本轮） | 只读 | 编写 |
| 编写回应（仅本轮） | 编写 | 只读 |
| 提示词正文 | 编写 | 只读 |

## 状态头

| 字段 | 说明 |
| --- | --- |
| `segment` | 段号，集号加两位序号，与文件夹名和分镜结构的 `id` 一致 |
| `status` | `draft` 草稿 → `in_review` 待审核 → `changes_requested` 要求修改、`blocked` 阻塞 或 `approved` 已批准 |
| `round` | 已经提交审核的次数。每次 `submit` 加一 |
| `model` | 编写时依据的视频模型。更换模型后必须重新编写并审核 |
| `promptLang` | 提示词语言，`en` 或 `zh` |
| `bodyHash` | 批准时写入的内容摘要，绑定分镜结构与正文。批准后任何改动都使批准失效 |
| `inputHash` | 批准时写入的输入摘要，绑定这一段依据的输入材料，见下一节 |

## 批准绑定什么

批准同时绑定两样东西，任何一样变化，批准都失效，需要重新提交审核：

- **内容**（`bodyHash`）：这一段的分镜结构与提示词正文。
- **输入**（`inputHash`）：认领与声音延续正文、来源证据、相关场次 notes 与显式 characters/props、局部开场或集尾意图、事件认领、挂载参考图与资产证据、模型参数、语言、目标时长、同框与单段限制、项目要求。无关场次不失效，跨段声音依赖变化会失效。详见 [来源与声音交接](source-audio-handoff.md)。

绑定范围只到这一段。别的段被修改、别的集的剧本发生变化、上游文件里与这一段无关的字段被调整，都不影响这一段的批准。设定图重新生成、认领的台词被修改、更换模型或分辨率、修改项目要求，会让受影响的段失效。

`blocked` 表示审核方发现了编写方无法单独解决的问题：缺少设定图、剧本台词本身有误、目标时长无法容纳。此时循环暂停，由调度方协调之后，编写方写明回应并再次提交。

## 三条格式约束

- **提示词正文是最后一条分隔线之下的全部内容。** 状态头之后只允许这一条单独成行的 `---`；审核区和正文里都不能再出现。
- **二级标题只有三个：「分镜结构」「审核意见（仅本轮）」「编写回应（仅本轮）」。** 区域按二级标题切分，意见或回应里需要小标题时使用三级标题或加粗；多出二级标题的工作单会被所有命令拒绝。
- **审核意见与编写回应只保留本轮。** 新一轮覆盖旧内容，只有 `round` 记录轮次。不保留历史意见，不做累积记录。

## 分镜结构

json 代码块保存这一段除提示词以外的全部结构，不包含 `prompt` 字段。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 段号，同状态头 |
| `sceneIndex` | int | 这一段属于该集第几场（从 1 起）。一段不跨场次 |
| `cuts` | cut[] | 段内分镜，按时间顺序。段秒数是各分镜秒数之和 |
| `images` | image[] | 参考图挂载清单，数组顺序就是 Picture 序号 |
| `note` | string | 备注，可选 |

### cut（分镜）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `beats` | [int, int] | 认领该场第几拍到第几拍，含两端。全场节拍恰好被认领一次，连续且不倒退 |
| `audioRefs` | [int, int][] | 可选，延续本集更早镜头拥有的台词坐标 [场次, 拍号]，可跨段跨场；不新增播放、不重复估时；不能代替 beats |
| `seconds` | number | 分镜时长，有限正数。认领节拍的台词估时必须装得下 |
| `size` | enum | 景别，见下表 |
| `camera` | enum | 运镜，见下表，一个分镜一种运镜 |
| `characters` | string[] | 画内人物编号，必须属于该场人物；空镜给空数组。超过同框上限时写 `note` |
| `props` | string[] | 画内道具编号，可选 |
| `note` | string | 备注，可选 |

### image（参考图挂载）

| 字段 | 说明 |
| --- | --- |
| `kind` | `character` / `scene` / `prop` |
| `ref` | 资产编号，来自调度方提供的资产表 |
| `role` | 这张图在本段的用途，一句话 |

只挂载这一段实际引用的资产。越需要精准参考的素材越靠前，主角排第一。一段尽量不超过五张。

### 景别短语表

`size` 对应的短语必须出现在这个分镜自己的 `[Shot k]` 行里。

| `size` | 英文短语 | 中文短语 |
| --- | --- | --- |
| `extreme-wide` | extreme wide shot | 大远景 |
| `wide` | wide shot | 全景 |
| `medium` | medium shot | 中景 |
| `close` | close-up | 特写 |
| `extreme-close` | extreme close-up | 大特写 |

### 运镜词表

`camera` 填英文原词。英文提示词里原词出现在自己的 `[Shot k]` 行；中文提示词里出现对应的中文词。

| `camera` | 中文 | `camera` | 中文 |
| --- | --- | --- | --- |
| `Static Shot` | 固定 | `Pedestal Up` | 升 |
| `Push In` | 推 | `Pedestal Down` | 降 |
| `Pull Out` | 拉 | `Arc Shot` | 环绕 |
| `Zoom In` | 变焦推 | `Tracking Shot` | 跟拍 |
| `Zoom Out` | 变焦拉 | `Shake Slightly` | 轻微晃动 |
| `Pan Left` | 左摇 | `Shake Strongly` | 强烈晃动 |
| `Pan Right` | 右摇 | `POV` | 主观视角 |
| `Truck Left` | 左移 | `Roll Clockwise` | 顺旋 |
| `Truck Right` | 右移 | `Roll Counterclockwise` | 逆旋 |
| `Tilt Up` | 仰摇 | `Tilt Down` | 俯摇 |

## 时长

每次台词估时按正文顺序装进拥有镜头与连续 audioRefs 延续镜头的共享秒数，不重复估时，不倒序，不跳过中间镜头；段内分镜秒数之和不超过单段上限（默认十五秒），并落在视频模型的合法时长区间内；全集段秒数之和接近剧本的目标秒数。秒数只存在于分镜结构里，不写进提示词正文。
