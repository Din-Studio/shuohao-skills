# 《旧站时刻》故事提案

原创故事，不使用兄弟 skill 的故事或原作证据。

撤站前，年轻站务员林蔚发现最后一班车没有进入电子到站表。退休调度员许钟回来协助核对。他知道纸质交接簿的补记习惯，也知道自己二十年前曾把一次漏报归咎于司机。调查逐步排除车辆失踪与司机擅离：新旧系统交接漏掉了临时接驳车。两人需要纠正当下记录，更需要决定是否把旧失误一并公开。

故事的核心不是抓住幕后坏人，而是区分记录的完整与个人名誉的完整。林蔚不能凭许钟的自述修改档案；许钟必须提供能核对的原始签名。结尾是交接簿和更正说明一起移交，不承诺受损关系立即修复。

正式样例采用连续故事、克制表达、渐进累积。前两集只有事件、施压和信息转折，没有兑现。第五集完成迟到的事实澄清，第六集以移交结束。最终节点是 event，不伪造终局大兑现。

测试中的密集兑现与单元生活变体只用于隔离契约测试，不把标签调整冒充新的完整创作提案。本提案先于节点及分集文件建立；不生成分镜或图片。
