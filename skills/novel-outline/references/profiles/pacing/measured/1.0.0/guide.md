# 舒缓推进节奏：大纲阶段

## 适用目标

允许日常过程、观察与单元完成感决定节奏。

## 表达方法

按有意义的生活过程安排事件，不强制逐集兑现或状态变化字段；填写状态变化时仍保持合法结构。新问题不自动设置期限。

## 应避免的做法

不要为满足不存在的密度要求伪造结果；舒缓也需要明确发生的事情。

## 正例

人物共同修复一把椅子，过程中协商各自愿意承担的工作，结束时完成约定的一部分。

## 反例

整集只有“大家相处得很好”，无法说明发生了什么事件。

## 内容评审问题

观察段是否带来细节或关系理解？单元停点是否清楚？评审须引用具体集号与节点，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。

## 来源说明

依据本仓库《Skills 创作策略解耦改造方案》第5、7、8节整理，并针对本阶段独立编写。示例为本指南原创微型情境，不借用其他 skill 的正式样例。数值是可替换的创作起点，未经真实投放效果验证；不依赖外部 skill 或联网资料。
