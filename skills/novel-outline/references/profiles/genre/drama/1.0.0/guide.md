# 人物剧情：大纲阶段

## 适用目标

通过人物选择及代价建立冲突，不预设胜负或单一主角。

## 表达方法

把目标、责任和关系中的矛盾落实为可发生的事件；群像分别保留立场。终局说明人物实际接受或拒绝了什么。

## 应避免的做法

避免只使用情绪标签；不把每次争执都登记为重大兑现。

## 正例

两名合伙人对是否公开亏损作出相反选择，账目披露后合作关系改变。

## 反例

人物突然愤怒并离开，但没有说明触发信息或行为后果。

## 内容评审问题

选择前后有什么不同？代价由谁承担？终局回应了哪项作品承诺？评审须引用具体集号与节点，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。

## 来源说明

依据本仓库《Skills 创作策略解耦改造方案》第5、7、8节整理，并针对本阶段独立编写。示例为本指南原创微型情境，不借用其他 skill 的正式样例。数值是可替换的创作起点，未经真实投放效果验证；不依赖外部 skill 或联网资料。
