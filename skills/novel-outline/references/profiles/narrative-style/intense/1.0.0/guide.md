# 强烈叙事：大纲阶段

## 适用目标

集中呈现选择的压力与后果，不使用重复事件堆高强度。

## 表达方法

让压力逐步改变可选方案；反转依赖已建立的材料，兑现必须是新的结果。情绪高点之间留出理解后果的位置。

## 应避免的做法

避免每集重复同一种羞辱与反击；不把所有节点都标为 major。

## 正例

听证前证人撤回签字，负责人必须在延期与公开自己责任之间选择。

## 反例

连续三集只更换指责者，冲突结果完全相同，却登记三次重大兑现。

## 内容评审问题

新的压力改变了什么选择？观众理解代价吗？相邻高点是否有不同结果？评审须引用具体集号与节点，不得以字段齐全代替内容判断。

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
