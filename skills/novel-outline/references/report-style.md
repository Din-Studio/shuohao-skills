# 大纲报告约定

实现位于 scripts/lib/outline-report.mjs，离线 HTML，无外部脚本/字体请求。中英界面由同一词表选择，故事正文不翻译。

顺序：作品承诺 → 组合与当前有效参数/覆盖/来源 → 节点时间轴和明细 → 阶段 → 分集 → 人物/场景/道具 → 调度矩阵 → 资产量折算 → 改编证据 → 分类检查 → 内容评审状态。

节点数量不等于兑现数量；不把没有 payoff 显示为通用缺陷。场景与节点按同集关联，标签明确不能证明真实场景落点。一次性场景不是失败；reusePlan 只作建议。

状态固定 pass/fail/skipped，没有 ok。error 的基础或策略失败阻断，warn 失败显示提醒且不计通过；来源提醒不阻断历史读取。off、缺上游、阶段未完成、不适用分别显示。报告不能把“没有阻断”写成“全部通过”。

长表在窄屏自身滚动，卡片缩至屏宽；图表/表格切换，超过三集可展开。打印展开全部。所有用户文本转义，数据块对小于号转义；导出还原输入 JSON 的值，不保证原文件空白与缩进相同。Blob 延迟回收以兼容下载。

预算显示默认与覆盖合成后的实际值；资产折算只是制作计划，不代表已经生成。HTML 每次重建，不进入版本控制。旧截图不代表 v2 实际界面，当前浏览器验收结果应单独记录。
