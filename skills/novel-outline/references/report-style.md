# 大纲报告约定

离线中英文界面，正文不翻译。作品故事与分集正文优先，其后为事件、阶段、资产与必要关系，再展示目标时长、用户预算/工具参考值，最后展示结构检查和内容评审状态。

未填写的可选字段不显示空表或空配置区。场景与节点标明“同集关联”，不证明实际场景落点。资产工作量只表示规划，不代表媒体已经生成。

结构失败、提醒、缺少上游、阶段尚未完成、内容评审未执行分别说明。结构通过不能代替内容或联合检查。报告不展示选择快照、摘要、覆盖路径、关闭规则。

用户文本转义；JSON 数据块转义小于号，导出恢复原值。长表局部滚动，超过三集可展开，事件链接可定位折叠分集，打印展开全部。报告 HTML 不进入版本控制。DOM 自动测试不替代真实浏览器布局检查。
