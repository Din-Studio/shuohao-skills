# 悬疑题材：视频创作阶段

## 适用目标

让证据何时进入视野、人物何时理解证据可辨认。

## 表达方法

按剧本节拍认领安排视线与信息呈现；需要辨认文字或物件时给足观看时间。镜头不能新增剧本没有确认的事实。

## 应避免的做法

不依靠无法看清的快速闪回冒充线索呈现；不在视频阶段补写 Q 计划。

## 正例

先给登记时间可辨认的画面，再切人物比对另一份记录的反应。

## 反例

关键证据仅出现一帧，随后人物已得出结论。

## 内容评审问题

观众能否看到支持推理的材料？镜头是否泄露了剧本尚未提供的信息？评审须引用具体集号、节拍与镜头，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
