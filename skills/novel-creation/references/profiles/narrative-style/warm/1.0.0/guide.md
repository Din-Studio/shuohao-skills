# 温暖叙事：视频创作阶段

## 适用目标

通过关注、距离与动作回应呈现互助，不取代视觉正文。

## 表达方法

依据 production.style 的正式视觉要求安排画面；暖色情绪不是自动修改色调的授权。给被帮助者的选择保留独立画面空间。

## 应避免的做法

不能使用柔光替代具体关心；不能擅自添加亲密身体接触。

## 正例

保留递水之后对方自主接过杯子的动作，并体现双方距离。

## 反例

提示词仅写“温暖治愈”，删除了对方拒绝帮助的剧本行为。

## 内容评审问题

画面是否尊重人物边界？温暖来自什么具体行动？评审须引用具体集号、节拍与镜头，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。

## 来源说明

依据本仓库《Skills 创作策略解耦改造方案》第5、7、8节整理，并针对本阶段独立编写。示例为本指南原创微型情境，不借用其他 skill 的正式样例。数值是可替换的创作起点，未经真实投放效果验证；不依赖外部 skill 或联网资料。
