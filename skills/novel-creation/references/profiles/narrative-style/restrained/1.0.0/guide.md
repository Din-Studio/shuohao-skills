# 克制叙事：视频创作阶段

## 适用目标

给观察和细微行为留出可见空间。

## 表达方法

减少无功能的强调；允许稳定构图、缓慢移动或静止主体。每个停留仍须有表达目的，所有时长遵循模型能力。

## 应避免的做法

第一切不必主体运动；不能把连续多段生成冒称已保证无缝长镜头。

## 正例

保持中景，看人物两次调整信封位置后才递出。

## 反例

每个细小动作都配一次快速推进，遮蔽整体关系。

## 内容评审问题

停留让观众看到了什么？技术拆段是否损害了表演连续性？评审须引用具体集号、节拍与镜头，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
