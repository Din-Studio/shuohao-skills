# 密集兑现节奏：视频创作阶段

## 适用目标

突出频繁发生的结果与反应，同时保留理解时间。

## 表达方法

cutDuration 提供2–5秒的 warn 建议；按事件与反应组织切换。偏离建议可以记录提醒，有限正时长与模型生成上限仍是基础要求。

## 应避免的做法

不把建议变成所有镜头必须快切的硬门；不要求每个 segment 末尾悬念。

## 正例

使用短镜头展示凭证、判断和实际处理结果，必要证据镜头可超过5秒并说明原因。

## 反例

为满足5秒上限，在人物作出关键决定前切走，导致结果不可理解。

## 内容评审问题

每次切换是否服务事件？兑现的结果和人物反应都看清了吗？评审须引用具体集号、节拍与镜头，不得以字段齐全代替内容判断。

## 契约边界

本指南只指导本阶段表达，不改变稳定 ID、有效引用、上游计划、目标时长与技术能力限制。视觉正文仍以 production.style 为准。规则是否启用及提醒级别以产物当前 params 为准，不根据本指南在校验或渲染时重新套入模板。
