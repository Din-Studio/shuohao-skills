# 分段与镜头表达

输入为已确认的故事、v2 剧本、seedScenes、资产卡以及实际加载的本地创作指南。先读剧本 opening、ending.mode/event 和对应节拍位置，再安排镜头；不从画幅或视频模型推导节奏。

## 分段和切镜

1. 段是一次生成调用，不跨场次。总秒数不超过 maxSegmentSeconds，且落在有效模型合法区间内。超出单次能力的长镜头要调整制作方案，不能承诺多个生成片段自然连续。
2. 每个镜头认领同场连续区间。全部节拍恰好认领一次，顺序不倒退。不要为缩短时长删除证据、人物选择或结果。
3. 真实 seconds 必须是有限正数。表达范围只读取 params.rules.cutDuration：off 关闭；warn 提醒；error 阻断。没有通用二至五秒硬门。
4. 台词估算秒数必须容纳在镜头中。压缩重复表达、无效过渡和无因果作用的动作后仍不足时，返回上游调整时长或事件，不擅改台词。
5. 使用实际需要的景别和运镜。观察、静止、停顿、较长镜头都合法。是否有效由内容评审判断，而不是按切镜频率评分。

## 开场和集尾

openingBeat 必须落在镜头实际认领范围；endBeat 对应本集最后一拍和最后镜头。两者与剧本严格对账。镜头表达可与计划文字不同，但不能改变实际事件。

closure 表现已经发生的收束；open 保留故事实际留下的余味；suspense 表现已声明的疑问。creation 不复制或补造 Q 计划。不是每个生成段都需要悬念，最终集不能因为下游习惯被改成追更结尾。

《收书人》在陈叙认出「致晚晚」后结束，只确认旧诗集的关联。镜头可以停留在独处的反应上，不得把这段画面描述成找到妹妹。

## 参考图挂载与提示词

- 每段按实际身份锚定需要挂载既有角色、场景、道具图；顺序与 Picture 编号一致。
- refimage-coverage 检查资产能否解析到真实文件，不证明构图或身份保持成功。是否需要重复挂载环境图是明确的制作决策，不保证只靠文字就能延续环境。
- 每个镜头的景别、运镜写入自己的 `[Shot k]` 行；台词按原文保留。英文正文的人名限制与中文填法分别遵循技术指南。
- 阅读 creation-prompt.md 的骨架，以及有效模型的独立技术指南。技术约束不能被 pacing profile 关闭。

## 内容评审问题

- 镜头的停留或切换是否服务于具体信息、关系或情绪？请引用镜号。
- openingBeat 所在镜头是否真的表达开场？最后镜头是否表达 ending.event？
- 关键证据是否可见？是否有身体反应但没有可理解的原因？
- 台词和动作是否有足够时间，而不是依赖模型加速表演？
- 参考图、提示词和实际资产是否矛盾？跨生成段连续性有哪些尚未验证的风险？

本指南由仓库方案和本 skill 既有分镜实践整理。具体风格与节奏方法位于所选 profiles 的本地指南；不依赖外部 skill。
