# 切镜：一集怎么分段、怎么切

一次任务切一集。你拿到 seedScenes 工作底稿（每场的节拍清单：编号、动作/台词、每拍秒数、说话人）、场景卡、角色卡（`cast.json` / `art.json` 里已经出好的设定图）。产出：把这一集的 `segments` 从空切满，然后删掉 `seedScenes`。

## 先分段，再切镜

1. **段 = 一次生成调用**，≤ 15 秒（找到 `production.json` 还要落进对应视频模型的时长区间），不跨场次。先把每场的节拍按剧情单元分组（一次交锋、一次进场、一次收尾），每组的时长就是一段。
2. **段内切分镜**，每切 2–5 秒（硬门），围着 3 秒打。一段通常 2–3 切——`novel-creation` 没有分镜图这一层中间产物，切镜的目的是给视频提示词分行，不是给出图排产，切太碎没有意义。
3. **没有第三步。** `novel-storyboard` 这里是「每切一张分镜图」，本 skill 没有这一层——段级直接挂载既有设定图、写一条通用视频提示词就完事了。

## 硬规则

1. **认领是地基。** 每个分镜声明 `beats:[起,止]`，全场连续区间、不重不漏。切完在心里过一遍：每场第 1 拍到最后一拍都有主吗？
2. **秒数决定台词装不装得下。** 认领节拍的台词秒数 ≤ 分镜秒数。4.4 秒的台词就给 5 秒的切。
3. **景别短语与运镜短语进这一切自己的 `[Shot k]` 行。** 运镜用统一词表（Push In / Pan Left / Tracking Shot……）：英文模式写成自然英文动作（a slow push in toward…），中文模式写中文术语（缓慢推近……）。
4. **提示词禁角色名。** 参考图身份说明句和 `[Shot k]` 描述都用通用身份（the young man carrying the worn poetry book），人名只许出现在引号台词里。

## 段级参考图挂载（替代「每切一张分镜图」）

`novel-storyboard` 靠每切一张关键帧钉住构图；`novel-creation` 没有这一层，构图完全交给提示词描述 + 参考图身份锚定。切镜时就想好这一段要挂哪些参考：

- **这段戏里出现的人物设定图**——有几个挂几个，不是「这场戏出现过的全部人物」，是「这段实际入镜的」
- **这段需要重新交代环境时挂场景设定图**——不是每段都要挂：如果上一段刚建立过环境，这一段是纯特写、镜头没有离开那个空间，可以不重复挂载（省一张参考图不代表环境会变，视频模型每次生成都是独立调用，不挂只是没有再给它一次环境锚点，靠文字描述延续「此刻还在原地」就够）
- **这段入镜的叙事道具设定图**——有就挂
- **参考图的顺序就是提示词里 `Picture k` 的引用顺序**，挂载时想清楚顺序，写的时候别凭印象打乱

提示词与参考图冲突时，模型听参考图的——所以提示词专心写**此刻的位置状态**（已经站在柜台前 / 刚推门进来）和这一刻的动作，长相材质交给参考图。

## 导演运镜手感（不设门，但决定像不像专业分镜）

- **3 秒一切是短剧的呼吸。** 竖屏观众的注意力就这个粒度——切快了信息断，切慢了人走。
- **对话切正反打。** 问话给问话人的近景，答话切答话人的近景，来回跳；谁的台词信息量大，谁的脸给得近。
- **进场三件套，第一切给运动主体。** 每集第一切必须有主体运动（推门进来、跟拍走动）——静物特写开场是死画面。
- **关键动作独立成切。**「一张字条从书页间滑落」这种拍值得单独一格 2 秒的特写插入（insert）——它是节奏的重音。
- **反应镜头是免费的戏。** 一句重台词之后，切听者的脸 2–3 秒，不用写词。
- **动接动。** 上一切结尾的动势接下一切开头的动势，段内连贯性交给视频模型，切点选在动作中间而不是动作完成后。
- **段的最后一切留钩。** 每段结尾的分镜要么是悬念的具象，要么是下一段的引子。
- **运镜克制。** 固定镜头是默认；推给情绪、拉给收场、跟给移动。一段里超过两种运镜就该问自己是不是在炫技。

## 常见病

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 舞台剧病 | 一段一切杵到底 | 对话切正反打，动作给插入特写 |
| 均匀病 | 每切都是 3 秒中景 | 深浅相间、长短相间才是节奏 |
| 台词爆仓 | 4.4 秒的台词塞 3 秒的切 | 加秒或拆切 |
| 参考图漏挂 | 段里出现了某个人物/道具，`images` 却没挂他的设定图 | 切镜时同步想清楚这一段要挂什么——`refimage-coverage` 门只查文件存不存在，挂没挂是导演判断，不是门管的事 |
| 编号对不上 | 提示词写的 `Picture 2` 其实是 `images` 数组第 3 个 | 挂载与提示词里的编号必须同步写，别写完提示词才回头补 `images` |
| 换景不换段 | 一段里从书店内部切到街道 | 换景必开新段——一段一个环境锚 |
