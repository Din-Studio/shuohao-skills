# creation-report.html 设计约定

这份是本 skill 报告的全部视觉约定——配色、区块顺序、交互都写在这里，改样式前先读它，别凭感觉发挥，也不需要去翻别处。

## 基调

- 冷灰印张 + 铁锈红印记：`--paper:#eceded` `--panel:#f5f6f5` `--seal:#8a3324` `--seal-2:#c56a4e` `--ok:#3d6b4f`。配色跑过可视化验证器，别私自换色
- 页宽 1600，衬线标题 + 无衬线正文，零外部依赖，离线双击能开
- 模型产出的每一个字都经过 `esc()`；内嵌 JSON 的 `<` 转为 `\u003c`，防止 `</script` 截断

## 区块顺序

当前有效配置、策略来源与上游意图 → 制作参数 KPI → 01 分镜节奏带 → 02 分集分镜表 → 03 参考图挂载单 → 04 配音对齐单 → 05 基础／策略／来源检查。配置区展示作品承诺、四维选择、覆盖路径、来源摘要、模型指南和开场／集尾镜头落点。分镜节奏带只是事实展示，不把未启用的策略当成缺陷。

**报告里唯一的生成产物是视频，不是图**——本 skill 不出关键帧，段卡展示的是「这段挂了哪些参考图（角色/场景/道具缩略名 + 相对路径，图存在就嵌图，不存在显示占位）+ 提示词面板」，嵌进来的图全部来自 `characters/`、`art/` 已落盘的设定图。

## 分镜节奏带（招牌图）

- 每集一行：`E01 | 色带 | 合计`。色带按**生成段**分组，组内每个分镜一片，**片宽 = 分镜时长 ÷ 全集时长**，颜色 = 铁锈红按景别透明度分档（大远景 0.25 → 大特写 1.0）
- 片是 `<a href="#seg-段号">`，点击跳到段卡；悬停 title 带段号#切序/秒数/景别/运镜

## 分集分镜表

- 每集一个块，段卡两列网格（窄屏降档），默认最多 760px 截断 + 渐隐 + 「展开全部段 / 收起」开关
- 段卡：段头（段号 + 总秒·切数徽章 + 场景 chip + 节拍认领范围）→ **参考图条**（这一段 `images` 数组按 Picture 序列出，图存在就嵌缩略图 + 身份说明，不存在显示占位「未找到设定图」——**不猜、不骗**，与 `refimage-coverage` 门查的是同一件事，报告只是把它可视化）→ 五五分栏（左列分镜行：#序号、`0.00s 起 · 3s`、景别·运镜、人物道具 chips、画面摘要从剧本认领的节拍自动带出；右列提示词面板：视频提示词等宽字体，复制按钮）
- `imageExists` 由 CLI 注入（render 时检查工作目录），`renderHtml` 本体不碰文件系统

## 参考图挂载单（下单批次单）

本 skill 不出图，没有出图排产这回事，这一区块只回答一个问题：**下单前这些参考图文件都在不在。** 按段列出这一段要挂哪些设定图（角色/场景/道具缩略名 + 相对路径 + role），图存在就嵌缩略图，不存在显示占位。

## 配音对齐单

- 一张表：段号#切序（可点）/ 说话人 / 台词（衬线）/ 台词秒数——TTS 音频对到哪一段的第几切，全部自动汇总

## 质量门与交互

- 页眉徽章只统计基础／策略的实际 pass，不包含来源核验、提醒和跳过。阻断失败横幅与文末清单分别展示。
- warn 失败显示“提醒”，off 显示“跳过 / policy-disabled”，缺上游显示“跳过 / missing-upstream”。没有确定性模型规则或未引用配方显示 not-applicable。来源漂移／不可核验单列，绝不把跳过视为通过。
- 单独声明内容评审未执行。所有时间均为估算，不宣传成片效果。配置和上游计划展示均转义，导出 JSON 与输入一致。
- lightbox 点参考图放大，Esc 关闭
- 复制按钮 `.copy[data-copy]` 事件委托；导出 JSON 内嵌 Blob 下载，`revokeObjectURL` 延迟 10 秒
- `@media print`：截断全展开、按钮隐藏、段卡双列、白底；`prefers-reduced-motion` 关动效
