# 分镜通用内容评审

结构检查与内容评审分别汇报。结构字段齐全不表示故事成立，参考图存在不表示模型能保持身份，估算时长不表示真实表演自然。

1. 按上游 ep、节点 ID、openingBeat/endBeat 和镜号核对实际表达。引用具体动作或台词，不以「通过」替代证据。
2. 人物反应是否有可见原因？关键证据、选择和结果有没有在压缩时丢失？
3. 画面是否真正表达 ending.event？closure/open/suspense 的实际意义是否与剧本相同？禁止下游补造追更问题。
4. 在所选题材和叙事风格指南下评审镜头。慢热不等于空转，密集不等于重复，开放不等于遗漏。
5. 按 pacing 指南检查信息和情绪是否有时间展开；不能把长镜头本身判作失败。
6. 核对段间位置、手持物、角色状态和声音连续性。分次生成的连续性尚未验证时明确记录风险。
7. 列出模型限制、参考图身份漂移、文字辨识与字幕需求。不能声称生成已成功。

评审材料只记录本次证据和修订意见，可放项目 .work/。没有人工或模型内容评审记录时报告“内容未评审”。不保存永久分数、爆款概率或失败历史。

来源：本仓库创作策略解耦方案及本 skill 既有节拍认领与参考图实践。该文自包含，不需要读取外部 skill。
