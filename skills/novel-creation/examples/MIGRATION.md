# 《收书人》夹具迁移说明

## 故事先行

原文仍是本目录的《收书人》：陈叙从旧诗集的笔迹与「致晚晚」字条确认它曾属于失散妹妹。原文没有写她找到了妹妹。初次迁移保留九拍 flow。后续内容评审发现姐妹关系没有成为可听见的信息，因此在原动作后增加一句自语，形成十拍、四段、九个镜头。沿用既有参考图，不生成新图或视频。

## 手工语义决定

- 开场使用第 1 拍进店及随后卖书问话，不再把整集揭示压缩成 hook。
- B01 是收书交易开始的 event（第 1–3 拍）。
- B02 是笔迹引发停顿和双倍收书决定的 turn（第 4–6 拍）。它不是人物战胜对手的 payoff。
- B03 是顾客离开后认出自己旧字条的 event（第 7–10 拍）。它确认旧物关联，没有实现寻人目标。
- ending.mode 为 open，event 明确停在陈叙独处认出字条。没有伪造 Q、required 承诺或后续解决节点。endBeat 为 [1,10]，落在新增自语的末拍。
- opening/ending 的计划文字在 outline、script、creation 保持相同；原 flow 可以采用具体表演文字。

## 策略与来源

本例明确选择 mystery / restrained / serial / gradual，版本均为 1.0.0。它是针对既有故事的本次确认，不按竖屏画幅推导。creation 通过本地 creative API 显式应用，仅记录所加载 genre/narrativeStyle/pacing 来源；structure 不加载。

## 本次内容核对与限制

内容评审后，B03 在最后一段第 1–3 镜头对应离开、字条滑落、拾起展开并自语。新增台词「晚晚，这是姐姐当年写给你的。」是本次视听改编，不伪称原文引句。最终 prompt 明写字条为「致晚晚」，并逐字保留这句台词；顾客空手离开，书留在柜台。目标仍为30秒，末镜从4秒改为6秒，镜头计划总长32秒，在既定容差内，没有提高语速或放宽技术限制。
