# 视频提示词 · 写法规范（本 skill 自己的方法论）

> 文中提到的门名称（如 `dialogue-verbatim`、`size-phrase`）是调度方完整结构检查里的检查项名称。本 skill 不依赖调度方即可写作；本地自查见 `scripts/novel-video-prompt.mjs lint`。

**这不是任何一个模型的内化版。** 「每个分镜配一张精确钉住秒数的关键帧图」那条路才用得上对齐指令、`<Picture k>` 钉秒数、`<d>` 标签——它们是 MiniMax H3 的私有语法，`seedance` 系列的 `input_schema` 里根本没有这些字段。本 skill 的参考图不按秒数分配、按「这段戏里出现的人物/场景/道具」整段挂载，所以这份文档写的是一条**任何视频模型都吃得下**的自然语言提示词规范。

**这份定骨架，填法另有指南**：本目录下按模型族各有一份填法指南（`h3-prompt.md` / `seedance2-prompt.md`），载入哪一份看这部剧挂的模型——规则在下一节。它们只改填法，骨架永远是这份。

## 这份骨架刻意没有的四样（别从关键帧那套里搬进来）

「每切一张关键帧、多图按秒对齐」的提示词骨架里有四样东西，这份一样都不要——不是漏了，是这里没有它们的落点：

| 多图对齐骨架有的 | creation-prompt.md 没有 | 为什么 |
| --- | --- | --- |
| 对齐指令（`Picture k aligns with the 0.00-second mark…`） | 没有 | 没有关键帧图可对齐——参考图是整段共享的身份/环境锚点，不是钉在某个精确秒数的画面 |
| 切点时刻（`At 00:03.000,`） | 没有 | 同上：切点时刻是给「多图对齐」用的，这里的参考图不分配到具体分镜 |
| `<d>[Chinese] …</d>` 标签 | 没有，改用引号 | `<d>` 是 H3 私有语法，认领台词改成纯文本引号引用（`dialogue-verbatim` 门只做子串匹配，不认标签） |
| `(S1)` `(S2)` 说话人编号 | 没有 | 没有编号体系的必要——身份靠参考图锚定，不靠模型给编号 |

## 先按视频模型载入填法指南 ⛔ 不能跳

骨架跨模型通用（骨架是这份的事，怎么填是填法指南的事），但**填法按 `production.json` 的 `video.model` 动态载入**：**先去读这部剧挂的是哪个模型，再决定读哪一份填法指南**——不要预设某一个模型，也不要因为「H3 是默认值」就跳过这一步。

| `video.model` | 再读哪份填法指南 | 那份加严了什么 |
| --- | --- | --- |
| `MiniMax H3`（两边都没写模型时的默认模型） | `h3-prompt.md` | 默认英文并禁人名、说话人第一次出现给足辨识信息、画外音补唇形闭合句、官方两个声音字段收进一个 `ambience:` |
| `seedance2.5` / `seedance2.0` / `seedance2.0 fast` / `seedance2.0 mini` | `seedance2-prompt.md` | 默认中文、身份说明句带全程复用的主体标签、台词用 `{}` 包、收尾段补画质与约束词、**全程不许出现精确时刻**（`prompt-model-fit` 门查的硬约束） |
| 其它模型 | **没有对应的填法指南**，照这份的通用骨架写 | 不要拿另一族的指南顶上——两族的填法互不相容。汇报里说明这部剧没有该模型的填法指南 |

模型写在 creation.json 顶层的 `video.model` 时以它为准（覆盖生产参数）。三条铁律：

1. **骨架永远是这份**，填法指南只改怎么填，不改结构——基础检查查的是这份的结构
2. **换了 `video.model` 就重读新那一族的指南，并重写这一批的填法**：语言默认、时刻能不能写、台词用什么符号，两族全不一样
3. **没有对应指南不等于随便写**——门一道都不少

运行 `scripts/novel-video-prompt.mjs guide --model <模型>` 会打印该读哪一份，照它读。

## 语言分工

- **语言默认跟着模型走**：挂 seedance 默认整条中文（`promptLang: 'zh'`——官方指南通篇中文术语与中文案例）；其余默认整条英文（`promptLang: 'en'`），不是因为哪个模型要求，是因为兼容面最广：任何视频模型的提示词理解英文都不会比中文差，而「参考图 + 提示词」这条能力本来就是跨模型通用的
- **台词保留原文语言**：认领节拍的台词逐字打引号引用，标点一个不动
- 两种默认都能手动切到另一种语言——偏离默认的备选项，中文模式人名放行

## 结构

```text
Picture 1 is <参考图 1 的身份，不写具体名字，写通用描述>. Picture 2 is <参考图 2 的身份>. …

shots:
[Shot 1] <景别短语>, <运镜短语> — <这一切发生什么，运镜怎么动，谁说了什么（引号原文）>
[Shot 2] <景别短语>, <运镜短语> — <……>

ambience: <1–2 句英文：环境声、动作声、有没有配乐。没有配乐就说 no music>
```

`zh` 模式对应字段：`镜头描述：` / `环境声与配乐：`，`[镜头 k]` 代替 `[Shot k]`。

### 参考图身份说明句

**开头逐张交代每张参考图是谁/是哪**，句式固定 `Picture k is …`（`zh` 是 `图 k 是……`），k 从 1 编到 `images` 数组长度，顺序就是 `images` 数组的顺序——**提示词里引用哪张图，看这个编号，不要打乱**。身份写通用描述（`the young man carrying the worn poetry book`），**不写具体人名**——人名只许出现在台词引号里，人名识别交给参考图本身，不是交给文字。

### `[Shot k]` 逐镜描述

每个分镜一行，**行首固定给两个短语**：景别短语（`references/worksheet.md` 的景别短语表）+ 运镜短语（`references/worksheet.md` 的运镜词表，20 个词——**这张表是通用摄影语汇，不是任何一个模型的私有字段**，任何视频模型的提示词都吃得下「push in」「tracking shot」这类描述；中文模式用表里的中文词）。两个短语后面接一个破折号，再写这一切具体发生什么、镜头怎么动、认领的台词（打引号原文引用）。

写动作遵守常见动作原则：模型见过千万次的日常动作可以放心写（推门、翻书、弯腰拾物），精确物理交互和微表情不要写。人物**此刻的位置状态**要交代清楚（已经在门口 / 站在柜台后），参考图锁长相与材质，文字锁此刻在哪、在做什么。

### 声景与配乐

一个字段收尾，1–2 句英文：环境声、动作声，有没有配乐（没有就写 `no music`）。**声景也是动作指令**——画面动作改了，声景要跟着改。

## 认领台词

- **逐字**打引号引用原文，标点一个不动——`dialogue-verbatim` 门做纯文本子串匹配，改一个字必被拦
- 说话人是谁不需要额外编号或标注——`characters` 字段已经声明了这一切画内是谁，参考图身份说明句也交代过，提示词正文直接引用台词即可
- 画外音：写成「... says in an off-screen voiceover」这类通用描述即可，骨架不强制唇形措辞（没有关键帧图，不存在唇形对不上画面的风险）——挂 H3 时 `h3-prompt.md` 会让你补上官方那半句唇形闭合，那是填法不是结构

## 运镜表（通用摄影语汇，不是任何一个模型的私有字段）

`Static Shot` `Push In` `Pull Out` `Zoom In` `Zoom Out` `Pan Left` `Pan Right` `Truck Left` `Truck Right` `Tilt Up` `Tilt Down` `Pedestal Up` `Pedestal Down` `Arc Shot` `Tracking Shot` `Shake Slightly` `Shake Strongly` `POV` `Roll Clockwise` `Roll Counterclockwise`。可加幅度（小幅/大幅）与速度（缓/快）细化成自然动作句，但行首那个固定短语必须原样出现，门按大小写不敏感匹配。

## 常见病

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 抄关键帧那套 | 把多图对齐的对齐指令、`<d>` 标签原样搬进来 | 没有关键帧图可对齐，这些语法在这里没有意义——删掉 |
| 不看模型就动笔 | 默认按 H3 的填法写完，这部剧挂的其实是 seedance | 动笔前先看 `video.model`，载入对应的填法指南；换了模型这一批要重写 |
| 身份漂移 | `Picture k is …` 写了具体人名 | 改成通用描述，人名只许出现在台词引号里 |
| 编号打乱 | 提示词里 `<Picture 2>` 指的其实是 `images` 数组第 3 个 | 编号顺序必须与 `images` 数组顺序一致——挂载时想清楚顺序，写的时候别凭印象 |
| 短语落单 | 景别/运镜短语写在段首导语里，没进对应 `[Shot k]` 行 | 两道门都是逐切核对，每一切自己的行必须自己带齐 |
| 台词改字 | 剧本改了台词，提示词忘了同步 | `dialogue-verbatim` 逐字比对，改一处必被拦 |
