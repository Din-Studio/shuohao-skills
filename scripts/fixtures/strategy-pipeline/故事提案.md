# 联合测试隔离故事提案

这些原创故事仅属于根目录 scripts 的联合测试，不是任何 skill 的正式样例。先确定以下故事，再编写事件、剧本与镜头。没有外部原作，没有生成图片或视频。内容效果尚未经过人工评审。

## 密集连续：《失物登记》

失物室管理员罗宁发现，过期失物义卖所得并未全部捐出。主管戴衡把缺款解释成账目延迟。罗宁先找回被撤下的捐款凭证，证明第一笔已经被私人账户截留；再查出主管冒用维修名义报销，迫使他退回一笔款项；最后把连续三个月的收据和转账记录交给捐助站，追回全部捐款并公开登记制度。

三集分别兑现不同结果：确认截留并保全证据、追回一笔款项、追回余款并改变公开制度。前两集保留有明确后续答案的问题。所有节点保持稳定编号，第一集同类型的两个节点必须分别认领。全剧阶段终点是最终集的大兑现。不是把同一个揭露反复统计。

## 渐进悬疑：《夜班温度》

冷库记录员许苒发现夜间温度缓慢升高。维护员高路认为是传感器故障。许苒第一夜只留下异常曲线，尚未知道原因；第二夜使用独立温度计与断电测试，排除传感器误报，却发现升温总伴随门磁的短暂断开；第三夜把独立记录和交班签字对齐，确认有人在非装卸时段开门。她封存证据并申请调查，不预演处罚结果。

至少第一集没有兑现节点，仍然推进了可重复核查的异常信息。第一集提出的问题在第三集解决，不以第二集的局部排除冒充全部答案。最终集开放：证据已明确，人的处理结果不在本次承诺内。阶段只覆盖第二至第三集，不要求大兑现。

## 舒缓单元：《楼下早餐》

早餐摊主周姨照顾受伤的家人，邻居阿禾、老郑轮流照看摊位。第一集阿禾发现常客需要软一些的早餐，调整蒸制后完成当天交付；第二集老郑面对突然停电，改为常温饭团，整理完售罄的空盘；第三集周姨回来，看到邻居留下的轮值表，接受每周休息一天。

三集都围绕可以独立闭合的小事，不制造追更问题。前三集均为收束，各集事件有各自因果。镜头允许八秒固定观察：等待蒸汽、整理空盘、看完轮值表。八秒镜头处于 MiniMax H3 的合法五至十五秒生成段范围。不会把舒缓表演改成三秒切镜，也不把生活帮助标成大兑现。

## 制作与验证边界

每集目标二十四秒，是测试短片，不声称等同商业剧集体量。动作估时分别为四秒、六秒、八秒，与上述动作的表演速度对应；容差保持 15%，不通过超大阈值掩盖时长问题。密集组合每段两个四秒镜头，其余组合每段一个六秒或八秒镜头。所有组合维持竖屏成片、横向设定图与同一合法模型，证明画幅不决定节奏。

参考图挂载仅在函数级使用 imageExists 替身验证路径与身份；真实 CLI 保持缺图并报告失败。保留目录可供浏览器检查报告，但不得称为已经生成图片或完成投产。
