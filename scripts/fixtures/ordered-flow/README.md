# 五阶段顺序夹具

故事《井口双签》属于根回归，不读取任何 skill 的样例。

故事先确定：两名同名的值班员分别签署读数与接班时间。二人不能按姓名归并，也不替对方担保。正文随后按原剧本六行整理；制作计划最后按四个正文位置编排。

入口：`node scripts/ordered-pipeline-selftest.mjs`。

- 正式版本：outline v5、characters/art v1、script v4、creation v3。
- 人物及美术从原剧本独立 seed，明确登记身份与证据。
- 局部 `C01/C02/S91/P91` 显式映射至 `C11/C12/S01/P01`。
- 不制作人物画像、音色、提示词设定图或其他媒体；制作段不挂载图片。
- 项目推进实际调用 pipeline 的 init/begin/run/complete/check/reopen。
- 所有阶段调用实际 validator，不注入替身。
- 负例验证顺序、前序缺失、来源版本、身份与映射错配、变更及交接范围阻断。

交接中的作者确认仅适用于原创夹具，不冒充独立语义审核、图像审核或成片审核。临时项目测试后删除，不保存失败累计记录。
