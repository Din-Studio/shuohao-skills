## 复现命令

macOS 下指定真实临时路径，避免 `/var` 与 `/private/var` 路径别名造成字符串断言差异：

```bash
export TMPDIR=/private/tmp
for f in skills/*/scripts/*selftest.mjs scripts/*-selftest.mjs; do
  node "$f" || exit 1
done
```

本轮主进程日志位于 `tmp/split-verification/final/`，不进入版本控制。独立复核在临时工作树另外运行相同 48 个入口及关键 CLI 反例，结束后删除临时工作树；没有修改主工作区。

当前消费者矩阵、升级顺序、路径基准、增量基线、来源改版重核及流程命令见[阶段交接与版本支持](阶段交接与版本支持.md)。

## 验证边界

- 结构与引用检查不判断身份归并或来源理解在语义上是否正确。
- seed、reconcile 和迁移不自动完成内容审核。用户决定及授权依据须真实，脚本只核验其记录与约束。
- 估时、批准协议及离线生成计划不证明实际对白、口型、音频衔接、人物一致性或最终时长。
- 未执行浏览器视觉专项、真实付费生成、试听、粗剪或成片审核。本任务未新增这些制作阶段。
