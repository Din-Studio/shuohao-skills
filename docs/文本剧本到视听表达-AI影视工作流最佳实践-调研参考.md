# 从文本剧本到视听表达：AI 影视工作流最佳实践调研

## 0. 核心结论

**忠实于剧本，不等于把剧本中的每句话都说出来，也不等于按文字段落逐个安排镜头。**

长篇心理说明可能只需要一个动作、一次停顿或一个声音变化。反过来，一句很短的“他终于决定离开”，也可能需要多个视听环节，才能让观众理解决定的依据、代价和结果。

建议把目标从“原文逐项进入画面”调整为：

> **原文完整可回查；关键事实、人物选择、因果关系和揭晓顺序不丢失；表达形式允许在明确权限内转换；最终以观众实际能够看见、听见和理解的内容验收。**

对当前项目的建议：

1. **保留来源，不要求原文全部成为发声正文。** 区分台词、可见动作、心理说明、背景事实、声音和字幕。
2. **先确定叙事功能，再选择表达渠道。** 不能从长段文字直接跳到视频提示词。
3. **引入“受约束的视听转译”职责。** 它不同于无损排版，也不同于自由改写；不必因此新增必经 skill。
4. **允许多段文字由同一个视听时刻承载。** 也允许一个叙事单元通过多个镜头或跨镜声音展开。
5. **保留锁定台词的逐字约束。** 但约束对象应是已确认的发声文本，而不是所有来源说明。
6. **将粗剪和声音设计提前。** 先通过低成本动态分镜验证信息与节奏，再进行高成本生成。
7. **分别审核转译方案和真实成片。** 提示词里写了“犹豫”，不代表视频已经表达了犹豫。

以上是基于公开资料和本仓库现状提出的推荐，不是已经验证的行业统一最优解。本轮只交付调研文档，不修改原方案和 skill，也不视为用户已授权改写剧本。

## 2. 先重新定义“忠实”

### 2.1 五种忠实性不能混成一种

| 层次 | 应当保留的内容 | 可变化的部分 |
| --- | --- | --- |
| 来源忠实 | 原件、位置、说话人、说明性质和来源版本 | 派生格式；不能覆盖原件 |
| 事件忠实 | 谁做了什么、做出什么选择、产生什么结果 | 不改变事件的表演细节 |
| 因果与知情忠实 | 观众和角色何时获得何种证据，事实、怀疑、谎言如何区分 | 不改变揭晓时机的表达渠道 |
| 戏剧功能忠实 | 关系变化、情绪走向、悬念、讽刺、克制或保留歧义 | 镜头、声音、停顿等实现方式 |
| 措辞忠实 | 被锁定的台词、证词、暗号、诗歌、关键字幕等 | 只有授权后才能改字或删除 |

“一个镜头表达了悲伤”不能证明它保留了“她悲伤是因为误以为儿子已经离开”这一事实。

“情绪差不多”也不能成为删掉选择和后果的依据。忠实应落实到具体要求，而不是给整场贴一个情绪标签。

### 2.2 必须保留的未知，同样是一种信息

例如，原剧本只说明“她不知道是否应该相信他”。镜头表现为她没有立即回应，可以保留迟疑；增加释然微笑，则可能替故事回答了“她已经相信”。

转译时至少明确：

- 观众此刻必须知道什么。
- 观众此刻可以怀疑什么。
- 观众此刻还不能确定什么。
- 哪些背景只用于指导表演，不要求观众立刻知道。

这是对前一份跨集调研中“知情范围”的延伸：不仅文字说明会泄露身份，表情、构图、道具特写和配乐也可能提前替故事下结论。

### 2.3 最重要的区分：说明被保留，不等于说明被朗读

John August 明确允许适量“只供读者理解”的描述，它可以帮助导演和演员理解意图；但这不能代替角色真正做出行动。[R1]

因此，剧本中的心理说明可以有三种合理去向：

1. **表演依据**：保留为意图，不进入发声文本。
2. **观众必须理解的信息**：设计可见、可听证据，必要时保留台词、旁白或字幕。
3. **暂不公开的背景**：进入受限上下文，不在当前镜头泄露。

不能把所有心理说明统一转成 VO，也不能把所有心理说明统一删除。

## 3. 调研发现：影视表达不是文本的缩写

### 3.1 表演与剪辑可以替代解释，但不能凭空产生事实

Hitchcock 在《Alfred Hitchcock: my own methods》中，用《Sabotage》的手、刀、目光和对方反应说明如何建立心理情境。他还讨论：说话者继续说话，画面留给听者，可以比单纯拍摄说话过程更高效地组织叙事。[R3]

可借鉴的不是“所有情绪都拍手部特写”，而是：

- 选择能产生明确意义的行为或物件。
- 将观众注意力引向当前真正重要的信息。
- 情绪来自情境与前后关系，不只来自演员脸上的形容词。
- 说话时不必始终显示说话者。

该文是导演个人方法，不能据此禁止长镜头。一个持续镜头和一组剪辑，都可能完成同一戏剧功能；选择应服务场景，而非固定风格模板。

### 3.2 “展示而非讲述”不是“禁止台词”

John August 在讨论对白与说明时，建议让角色主动发现信息，而不是只替作者向观众讲解；同时明确承认，某些剧情和类型需要解释性台词。[R2]

因此不建议设置：

- 每场台词不得超过某个字数。
- 心理必须全部外化为动作。
- 一切说明都要替换成物件特写。
- “电影感”等于少说话、慢动作和浅景深。

审讯、告白、辩论、仪式和误导性的叙述，可能正是通过语言行动推进剧情。删除语言，可能删除的不是冗余，而是戏剧本身。

### 3.3 声音不是最后添加的装饰

Walter Murch 的访谈指出，声音会改变观众对图像的情绪感受；他也描述了剪辑中逐步加入对白、关键音效和音乐，使声画相互影响的过程。[R4]

Disney Animation 的流程说明中，Editorial 从开始到结束参与制作，处理节奏、对白录音、临时音效和音乐，而不是等所有画面完成后才拼接。[R5][R6]

对本项目的直接启示：

- “观众看得见”应扩大为“观众能从画面和声音获得必要信息”。
- 不在画内的脚步声、被打断的回答、环境声的变化，也可以承载情绪或事件。
- 必须区分客观声源与主观听觉，不能用主观声音意外证实客观事件。
- 配乐能够影响理解，但不能代替必须交代的因果证据。
- 默片式检查可帮助诊断画面，不应成为所有场景的验收要求。

### 3.4 分镜和粗剪是试验工具，不只是交付文件

Disney 的 Story 团队会从剧本绘制缩略图，同时考虑情绪、表情、时机、调度和构图。[R5]

Runway 发布的 Gabe Michael 制作案例记录：创作者在图片尚未全部完成时，就开始制作带旁白和音乐的 animatic；之后在生成片段与调整剪辑之间来回工作。[R7]

这支持以下方法：

> 用便宜的占位画面和临时声音验证“这场戏是否成立”，再决定哪些镜头值得精制。

但该案例包含旁白驱动的创作，不能证明所有短剧都应使用旁白；它是厂商发布的单个案例，也不是受控成本实验。

### 3.5 把抽象意图留给规划层，把具体执行交给生成模型

Runway Gen-4 官方指南建议简单、具体的动作描述；图生视频时，图片承担外观与构图，文字主要描述运动。Google 的视频最佳实践也建议短片段聚焦一个时刻，图生视频优先描述运动。[R8][R9]

由此可以建立两层表达：

| 面向对象 | 应当知道什么 |
| --- | --- |
| 转译与导演规划 Agent | 人物为何迟疑、观众应如何理解、哪些结论不能提前出现 |
| 当前镜头的生成模型 | 谁在什么位置，发生什么可执行的动作，镜头和声景如何变化 |

不是把“愧疚、怀念、克制、矛盾、释然”一起塞进提示词，而是先决定这一时刻究竟需要观众读到哪一种变化，再设计证据。

也不能反向规定“提示词越短越好”。Runway 的建议针对具体模型与模式；Google 同一指南对文生视频角色描述和图生视频运动提示有不同建议。模型适配应留在执行层，不升级为剧本规则。

### 3.6 AI 研究支持分层规划，但尚未证明情绪转译已经解决

| 研究 | 可借鉴方法 | 需要保留的边界 |
| --- | --- | --- |
| MovieAgent，2025 [R10] | Director → Scene Plan → Shot Plan；分离全局叙事与局部镜头执行 | 实验输入包括梗概和角色素材；MoviePrompts 只有 10 个故事提示，人工评估来自两名专家。不能等同于忠实转换任意完整剧本。 |
| MovieDreamer，2024 预印本 [R11] | 分层的多模态剧本、身份条件、关键帧与视频渲染分工 | 涉及训练模型与视觉 token，不是给现有 skill 加几个提示词就能复现。 |
| The Script is All You Need，2026 预印本 [R12] | 对话到可执行影视计划，再进行生成和评价；关注内容出现的时间 | 从稀疏对白补全计划带有创作任务性质，不能自动获得补写本项目剧情的权限。 |
| MSVBench，2026 预印本 [R14] | 将全局、场景、镜头及跨镜关系纳入评价 | 人机相关性来自其数据与评估设定，不证明能判断本项目的潜台词和保留歧义。 |

特别值得注意：[R12] 报告了视觉吸引力与剧本遵循程度之间的权衡，也承认口型和细粒度动作仍有偏差。其 VSA 关注事件是否在指定时段出现，但基于视觉文本对齐的指标不能独立证明复杂动机或情绪被正确理解。

VBench 将画质、身份、运动等拆成不同维度，也提醒我们不要用一个“看起来很好”的总印象替代验收。[R13]

**这些研究支持“分层计划＋实际输出审核”的方向，不支持“多配置几个 Agent 就自动成为导演”。**

## 4. 转译前先分类：哪些文字要说，哪些文字要演？

### 4.1 最小功能分类

以下是建议的语义分类，不是本轮新增的 JSON 类型。

| 来源内容 | 默认处理方向 | 关键风险 |
| --- | --- | --- |
| 明确对白、独白 | 保留说话人、措辞与语言行动 | 把必要的话删成一个表情 |
| 明确旁白、内心独白发声 | 保留发声属性；可跨镜承载 | 误写成画内张嘴说话 |
| 心理或情绪说明 | 保留意图，选择表演、声画关系或必要语言 | 擅自变成 VO；或只剩泛化情绪 |
| 可见动作与人物选择 | 保留事件、次序、结果，具体化可表演细节 | 把“迟疑”改成“拒绝”，改变后果 |
| 观众必须获知的背景事实 | 判断前文是否已建立；否则安排明确证据 | 误以为一个眼神能交代日期、身份和因果 |
| 仅供创作理解的背景 | 留在受限制作上下文 | 提前泄露结局；无意义地逐项上镜 |
| 字幕、文件、数字、暗号 | 保持必要措辞、可读性和出现时机 | 画面中出现了物件，却看不清关键信息 |
| 环境声、画外动作、主观声音 | 标明声源、听到者、叙事性质 | 将主观感受变成客观事实 |
| 重复修辞或同义情绪说明 | 可共同由同一表达承载，记录依据 | 按词频删除实际重复发生的事件 |

同一段文字可能包含多种功能。先拆出功能，再决定是否压缩；不能整段统一判定为“内心”后直接省略。

声音还要分开记录发声者身份、是否在画内，以及故事中的人物能否听见。画外人物对白不等于内心独白，内心独白不等于非发声心理说明。不能仅用一个匿名 `VO` 标记代替这些区别。

### 4.2 三种权限，不建议只有“原样保留/自由改写”两档

| 权限 | 可以做什么 | 不能自行做什么 |
| --- | --- | --- |
| 忠实整理 | 分类、来源映射、格式规范化、标记不能直接执行的说明 | 删除台词、补动作结果、替换剧情 |
| 受约束视听转译 | 在已确认边界内，将说明转为可表演表达，合并重复表达，选择声画渠道 | 改变选择、因果、揭晓、关键措辞或保留歧义 |
| 授权改写 | 按用户明确的范围调整台词、事件或结构 | 超出授权；把修改后的内容冒称源事实 |

**推荐未来流程支持第二档，但本轮不把它设为已生效权限。**

默认保守做法：实际对白与明确 VO 先锁定；非发声说明提出转译方案；涉及事实变化、重要新行为或台词删除时，单独请求确认。

仅改变景别、站位或镜头选择，通常属于导演实现；但若站位改变了谁能听到秘密、谁能够看见道具，就已经触及剧情事实，不能按普通技术细化处理。

### 4.3 “一个镜头足够”的判断条件

同时满足以下条件，才适合压缩成一个主要视听时刻：

- 多段文字服务于同一戏剧变化，而不是多个不同事件。
- 必要背景已经建立，或能在该时刻被清楚获得。
- 关键选择和结果仍然可辨认。
- 不需要观众同时阅读两处重要文字、辨认复杂动作并听取关键信息。
- 表演有足够时间形成变化，不能只保留起止姿势。
- 模型能够稳定完成；失败时存在不改剧情的替代表达。

“一个主要视听时刻”不强制等于一个连续镜头。必要时可以通过两个短镜头或一个声音桥完成，而不扩大叙事内容。

## 5. 推荐方法：先确定叙事功能，再寻找最少但充分的证据

### 5.1 场次先回答六个问题

每场先写简短的功能说明，而不是立即写镜头：

1. 场景开始时，观众已经知道什么？
2. 人物此刻想要什么，对方或环境如何阻碍？
3. 本场新增什么证据、选择或后果？
4. 关系或情绪从什么状态变化到什么状态？
5. 结束时，观众应知道什么，还应不知道什么？
6. 哪些措辞、动作、对象和顺序被锁定？

这些是可审查的决策结果，不要求 Agent 输出冗长的内部推理记录。

### 5.2 将“叙事单元”与“镜头”分开

叙事单元表示一次有意义的信息或关系变化。镜头表示一种画面组织方式。发声条目表示一次实际声音呈现。三者不应强行一一对应。

合理关系包括：

- 多段同义心理说明 → 一个表演变化。
- 一条长 VO → 多个镜头上的连续声音。
- 一句对白 → 说话者、听者反应与后果。
- 同一个镜头 → 同时承载行动、关系变化和环境信息。
- 一段来源背景 → 指导整场表演，但不要求在该场成为观众知识。

建议将“唯一归属”和“多处呈现”分开：每条来源记录或发声条目有明确所有者，但可引用多个实现位置。这样既防止漏项和重复播放，也不限制跨镜表达。

不要仅仅删除当前覆盖检查中的“不重复”条件。那会让意外重复发声也合法。应先明确什么只能发生一次，什么只是对同一内容的多次引用。

### 5.3 为候选表达写一张小表即可

| 内容 | 必要记录 |
| --- | --- |
| 来源 | 当前集场、源范围、版本 |
| 必须保留 | 事件、选择、重要信息及揭晓限制 |
| 表达决定 | 保留对白、动作承载、声音承载、共同表达或仅供表演参考 |
| 可感知证据 | 观众具体从哪里看见或听见 |
| 权限 | 普通导演细化、已授权转译或等待确认 |
| 风险 | 可能误读什么；模型无法完成时如何替换 |

这可以是现有工作单内的一个小节。不是要求首版新建大型语义数据库、复杂评分系统或独立常驻服务。

只对有实际转换风险的部分详细记录；普通台词和清晰动作不需要重复撰写大段说明。

### 5.4 先检查是否有更直接、较少歧义的表达

建议依次考虑：

1. 原剧本已经存在的行动，是否足以承载情绪？
2. 现有动作的停顿、节奏、距离和对象关系，是否足够？
3. 听者反应、画外声或声画关系，是否更清楚？
4. 是否仍需要保留一句必要台词、VO 或字幕？
5. 如果必须新增行为或删除原句，是否需要升级授权？

此顺序是防止过度加工的检查顺序，不是艺术价值排名。不要为了避免旁白，强行新增一件象征性道具或一段从未发生的回忆。

### 5.5 压缩的是冗余，不是表演时间

不建议用“每一百字压成几秒”作为转译规则。

应分别估计：

- 实际说出的台词与声音长度。
- 动作起点、执行、反应和必要停留。
- 观众辨认物件、关系或文字所需的时间。
- 能同时发生的声画事件，以及必须顺序发生的事件。

如果对白与动作自然重叠，时长不是简单相加。反之，信息出现后必须等待反应，即使没有新增文字，也可能必须增加时间。

优先采用试读或临时配音的实际时长。没有音频时保留粗估区间与不确定性。不能通过提高全局语速或减少所有动作秒数，让本来不能理解的表演“通过检查”。

## 6. 推荐 AI 工作流

```text
原剧本与授权边界
    ↓
来源解析：对象、事件、说明性质、知情顺序
    ↓
场次功能：观众知识、人物目标、变化、锁定内容
    ↓
受约束视听转译：选择动作／对白／声音／字幕等渠道
    ↓
独立来源审核：有没有改变事实、选择或揭晓？
    ↓
分镜与声音设计：构图、调度、画外声、时间关系
    ↓
低成本动态分镜／粗剪：是否看懂，是否有节奏？
    ↓
冻结当前制作计划，再适配生成模型
    ↓
生成候选素材 → 剪辑、配音、音效与必要合成
    ↓
实际成片审核：来源忠实性＋观众理解＋技术质量
    ↓
按问题归属局部返修，而不是每次重写整场
```

### 6.1 outline：建立事实，不替导演决定镜头

负责来源覆盖、身份、事件、重要背景、知情顺序及需要保持的未知。

可以提炼“本场由拒绝转为有限让步”，但应提供来源。无法确定心理变化时保持未知，不用统一情绪曲线改写原作。

### 6.2 script：建立可执行内容与非发声意图的边界

在忠实整理模式，保留来源分类，不把心理说明自动写成 line。

未来若批准受约束转译模式，script 应负责：

- 确定正式行动与发声内容。
- 保留关键台词及说话人。
- 将非发声意图和揭晓约束交给下游。
- 对改变正式行为或声音内容的方案承担审核责任。

script 不必提前规定焦距、机位或模型专用语法。

### 6.3 creation：承担导演实现与时间组织

在已确认的行动、发声内容和意图之内，选择镜头、调度、声画关系、停留与剪辑。

如果镜头细化需要“她决定原谅”这样的新结论，应回到 script 层处理，不能因为提示词更好写就补进故事。

人物与美术继续提供一致的视觉资产。先确定故事和转译方向，再制作对应参考图；不要先生成漂亮画面，再倒推剧情动机。

### 6.4 提示词编写：做模型适配，不成为第二个编剧

输入应至少包括当前场景功能、必要前情、正式行动/发声内容、镜头设计和局部禁区。

输出以当前模型能执行的明确描述为主。不把全剧梗概和全部心理分析堆入每段提示词。

生成段、镜头、场景不是同一个单位。特定模型可一次生成多个镜头，也可能需要多个片段完成一个连续动作。模型时长上限不应反过来决定故事里必须发生什么。

### 6.5 粗剪：便宜地暴露错误

可采用文字卡、简笔分镜、占位图和临时声音。必要时才制作低成本动态样片。

先检查：

- 观众能否知道发生了什么，为什么重要？
- 转折是否发生在可感知的位置，而不是只写在注释里？
- 停顿是有意表达，还是生成素材在等待结束？
- 是否重复用对白、表演和字幕解释同一信息？
- 是否有声音持续跨镜，而视觉仍被迫等待说话者？

单个清晰镜头可以简化为一次时间排演，不要求所有项目都建立复杂 animatic 工程。高成本、信息密集或有歧义的场景优先验证。

### 6.6 生成、剪辑与返修

按问题分类返修：

| 问题 | 返回位置 |
| --- | --- |
| 不知道人物为何行动、背景遗漏 | 来源/场次功能 |
| 画面让观众误以为已经和解 | 转译或导演实现 |
| 表达正确，但动作生成失败 | 生成、参考素材或局部合成 |
| 关键数字不清楚 | 文字合成与可读性审核 |
| 单镜正确，前后拼接后关系变了 | 剪辑与跨镜审核 |
| 台词过长、当前目标时长无法容纳 | script 与制作目标协商 |

保持情节不变的备选实现，通常比盲目增加提示词更值得尝试。关键微表情无法稳定生成时，可考虑表演驱动素材、较清楚的已授权动作或剪辑证据；仍不清楚则保留必要语言。不能为了模型便利改变角色决定。

### 6.7 Agent 配置保持最小

推荐三个逻辑职责，不要求三个常驻进程：

- **转译者**：提出有来源、有权限边界的表达方案。
- **导演/制作编写者**：实现分镜、声音和生成计划。
- **独立审核者**：分别核对来源忠实性与可感知性。

主会话组织版本与交接。同一场的关键表达先统一，再并行处理已独立的镜头。不要让每个镜头 Agent 自行解释人物动机。

同一模型可以在独立上下文中承担不同角色。先验证职责分离的收益，不默认增加多模型投票、无限循环或永久失败统计。

## 7. 自有例子：一段心理说明怎样变成一个镜头？

以下故事仅用于本研究说明，不属于任何 skill 的正式样例。先确定故事，再讨论镜头。

### 7.1 故事与边界

短片暂名《空座》。沈榆是一位已经离开剧团的音乐指导。罗笙请他听完演出前的最后一次彩排。两人过去有隔阂，但原因尚未揭晓。

本场只发生一件关系变化：**沈榆从准备离开，变为愿意留下听完这一遍。**

本场不承诺复出，也不意味着双方已经和解。隔阂原因不能提前解释。

### 7.2 来源剧本片段

> 罗笙站在排练区，看着门边的沈榆。前排留着一个空座。
>
> 沈榆停在门边。他并不是不想听，只是怕自己一坐下，就像承认过去那些争执已经过去。他甚至准备好了离开的理由。可是罗笙没有催促，也没有替他作出决定。他一时不知道该把目光放在哪里，手仍搭在门把上。那把空椅子让他觉得自己仍被等待着，这种等待既使他不安，也使他不愿再让对方失望。
>
> 沈榆松开门把，走到前排坐下。
>
> 沈榆：我只听这一遍。
>
> 罗笙点头，转身准备开始。

### 7.3 先分类，不急于分镜

| 来源内容 | 功能与处理 |
| --- | --- |
| 准备离开、手搭门把 | 可见动作；建立离开的可能 |
| 多句不安、犹豫和被等待的感受 | 非发声表演依据；不逐句朗读 |
| 松开门把、坐下 | 明确选择及结果，必须保留 |
| “我只听这一遍。” | 限定让步范围；默认逐字保留 |
| 罗笙点头并准备开始 | 接受当前边界，不等于庆祝和解 |
| 过去争执的具体原因 | 未提供；不得补写或闪回 |

### 7.4 候选方案：一个持续镜头

在同一个可读的构图中，保留门边的沈榆、前排空座和等待的罗笙。镜头先容纳他停在门边的状态，再随他松开门把、走向座位并坐下。原句按正式台词发声。罗笙点头，随后准备开始彩排。

表演重点是行动由停留转为落座，不是要求视频模型同时生成“愧疚、怀念、恐惧、释然”等多个抽象表情。声音只落实已有场景中的动作声与发声内容；是否加入音乐是制作选择，不能借音乐宣布和解。

这一方案没有逐句表现心理说明，但保留了可见行动、有限让步和明确台词。是否一个镜头足够，仍要看构图、表演和实际播放效果；不预先承诺固定秒数。

### 7.5 它没有表达什么？

观众不一定能够从这一镜头准确读出“他怕坐下就等于承认过去已经过去”的完整命题。

如果这只是演员理解行动的依据，可以接受。如果作者要求观众此刻准确知道这一心理原因，当前方案就不充分，需要提出补充表达并取得授权。

**这正是“情绪可压缩”和“事实不能凭感觉代替”的界线。**

### 7.6 不能采用的压缩

- 删除“我只听这一遍”，只留下温暖的微笑：可能消除了有限让步的边界。
- 增加拥抱：新增了关系行动，可能提前和解。
- 加入“当年是我错了”的 VO：新增立场与事实。
- 只生成一个流泪特写：没有证明他选择留下，也没有交代结果。
- 让空座变成亡者的纪念席：新增重大剧情，不是视觉隐喻的普通细化。

### 7.7 一镜失败时，不必恢复整段朗读

可以将同一内容改成两个镜头：先建立门边的停留与空座，再承接落座和原句。也可以调整人物距离和构图，使选择更容易辨认。

这些都是同一故事的备选实现，不是重新发明动机。先核查问题究竟来自构图、表演、生成失败还是信息缺失，再决定是否需要增加语言。

## 8. 本仓库现状：已有基础与真正缺口

以下路径和行号以本次基线为准。不能把未实施的融合方案当成现有能力。

### 8.1 已有正确方向，应该保留

- `skills/mint-script/references/创作指南.md:5–35` 已强调可表演动作、人物选择和克制表达；不要求动作台词交替，不设统一句长或动作比例。
- 同文件 `47–51` 已明确字数语速和固定动作秒数只是粗估，不允许为通过检查任意加速。
- `skills/mint-video-prompt-review/references/审核清单.md:13–23` 已禁止新增心理结论、删除选择与后果，同时允许不改变事实的动作细化。
- `skills/mint-creation/SKILL.md` 已区分调度、编写和审核；越权问题应上游协调。

因此，本轮建议不是“把所有忠实规则放开”，而是使忠实规则有准确的语义对象。

### 8.2 action/line 无法完整表达文字的不同功能

`skills/mint-script/scripts/mint-script.mjs:254–264`：每个 flow 条目必须在 `action` 和 `line` 中二选一。

- `action` 只要求非空，不检查是否真正可见。
- `line` 有 speaker，可使用 `VO`。
- `delivery` 是自由文本，不会自动改变发声或估时语义。

所以，当前不是“完全不支持 VO”，而是**没有独立的非发声意图分类**。长篇心理说明放入 action 不会因不可见而被这段代码拒绝；放入 line，则进入台词检查链路。

现有代码没有自动把心理说明改成台词。问题在于，Agent 一旦分类错误，下游便按错误分类继续执行。

### 8.3 估时是按字段类型，不是按实际表演

`skills/mint-creation/scripts/lib/contracts.mjs:6–14` 的 `beatSeconds`：

- action 使用固定动作秒数，默认 2.5 秒。
- line 使用去空白后的 JavaScript 字符串长度除以语速，默认 4.5。
- VO 与普通 line 使用相同计算。

本次 4 项探针结果：

| 输入 | 实际估时 |
| --- | --- |
| 5 个 UTF-16 单位的 action | 2.5 秒 |
| 同一句重复 40 次，共 200 个 UTF-16 单位的 action | 2.5 秒 |
| 同样 200 个单位作为 VO line | 约 44.44 秒 |
| 同样 line，delivery 写“内心说明，不发声” | 仍约 44.44 秒 |

材料：`tmp/audiovisual-research/estimator-probe.mjs`、`estimator-results.json`。

这只验证估时函数，不是完整 flow 校验或制作链路测试。它说明文字长度本身没有定义表演时长，分类也不能只靠自由文本括注修正。

### 8.4 当前不是“一拍一个镜头”，而是“每拍只能归属一个镜头”

`skills/mint-creation/scripts/mint-creation.mjs:678–705` 要求每场节拍按顺序、连续、恰好一次被镜头认领。

因此：

- 一个镜头认领多拍：允许。
- 同一拍跨多个镜头认领：不允许。
- 一条长 VO 配多个画面：现有认领结构没有直接表达其跨镜归属的方式。

不能把问题误报成“仓库强制每段文字单独成镜”。真正需要重新设计的是：文本条目、叙事单元、发声和镜头之间的映射。

### 8.5 逐字检查的边界需要准确表述

同文件 `645–652` 对 line 执行 `prompt.includes(b.text)`，并将认领台词的估时相加，与当前镜头时长比较。

它能够检查整段提示词是否包含原句，但不能证明：

- 原句在正确的镜头出现。
- 正确的人以正确的方式说了这句话。
- 重复台词按要求出现了多次。
- 真实视频确实说出了原句。

这条检查应保留其有限价值。未来转译方案不应简单关掉逐字检查，而应把它绑定到正式发声内容，并补充来源转换与实际音频审核。

### 8.6 审核和审批需要扩展对象，而非只添加字段

现有审核清单重视可见证据，但“观众看得见”没有完整涵盖声音承载的信息。

现有 `skills/mint-creation/scripts/lib/worksheet.mjs:33–59` 的内容/输入摘要也不等于整份意图和跨集上下文已经受批准绑定。

如果后续新增转译决定、锁定台词、声音方式或揭晓限制，应同步扩展实际消费与批准失效机制。不能只在 brief 末尾增加说明，就宣称审核已经覆盖这些内容。

## 9. 后续怎样修改原方案？

**本节是修改建议清单，不是已应用的修改。**

### 9.1 先修改目标句，再讨论字段

原方案第一节的“整理为下游能够消费的结构化正文”，建议后续明确为：

> 将原剧本解析为可追溯的来源事实，并在已确认的权限内形成可表演的行动、发声内容与必要的非发声意图。忠实性以事件、因果、人物选择、知情顺序和锁定措辞为依据，不要求所有来源说明逐句进入成片。

同时保留“script 不根据摘要重新生成原文”的限制。增加视听转译，不意味着可以丢弃原剧本。

### 9.2 按原方案章节列出变化

| 原方案位置 | 建议调整 |
| --- | --- |
| 第一节：结论与尚未确认边界 | 从“忠实整理或改写”二分，扩展为整理、受约束转译、授权改写三个权限层次。 |
| 第三节：目标流程 | 在来源解析和模型提示词之间，显式加入场次功能与视听转译；在生成前加入按需粗剪验证。 |
| 第五节：script 职责 | 明确正式发声正文与非发声说明；必要心理背景不等于必须朗读。 |
| 第五节：正文映射 | 保留来源对应，允许多段来源共同表达；设计跨镜发声，不用文本数组位置替代全部时间关系。 |
| 第六节：数据权威 | 明确源事实、已批准的转译决定、镜头实现各自归属；保持单一正式可执行正文。 |
| 第七节：通过校验不等于忠实 | 增加“提示词通过不等于成片表达成功”。 |
| 第八节：契约审视 | 增加非发声意图、发声方式、语义覆盖、跨镜声音与批准失效。 |
| 第九节：实施步骤 | 先做小规模转译样例与观众理解验证，再定 schema，不先扩张字段。 |
| 第十一节：验收 | 分开来源完整、叙事功能完整、锁定措辞正确和观众实际理解。 |
| 第十二节：职责摘要 | script 决定应发生什么和应说什么；creation 决定怎样让观众看见、听见和理解。 |

### 9.3 不建立第二套可自由修改的全文

推荐保持：

- 原始剧本：不可覆盖的来源。
- outline：全局事实与结构依据。
- script：唯一正式的可执行行动与发声内容，附必要意图和来源关联。
- creation：镜头、声音时间关系、模型执行计划与制作结果。
- 转译记录：从来源到正式内容的决定，不是另一份可自由编辑的完整剧本。

若仍需无损展示原文，直接从来源范围派生，不再维护第二份与正式 script 竞争的正文。

不能直接把心理文本全部移动到新字段就算完成。必须确认它是否被消费者读取、是否参与审核、变化是否使旧批准失效。

### 9.4 最小契约能力，而非预定字段清单

后续设计至少表达五件事：

1. **来源与分类**：内容来自哪里，是对白、动作还是说明。
2. **保护约束**：什么事实、选择、未知和措辞不能改变。
3. **转译决定**：怎样表达，依据是什么，权限是否满足。
4. **实现引用**：由哪些行动、发声条目和镜头承载。
5. **验证状态**：来源核验、转译审核、粗剪检查、成片审核分别是否执行。

来源登记可以要求完整覆盖。最终表现不要求每个源句单独上镜，但不能用“已由氛围表达”一概豁免。每个重要叙事要求仍须有具体证据。

映射可概念性分为：

```text
来源范围 → 叙事要求／表演意图
                    ↓
          正式行动与发声内容
                    ↓
       一个或多个镜头／声音时间区间
```

复用已有 B ID 表示重要事件，不为每个情绪形容词创建新的全局节点。具体字段、文件位置和版本迁移在实施设计时确定。各 skill 保持本地协议实现，不依赖兄弟 skill 代码。

### 9.5 审核约束如何变化

| 当前检查 | 建议保留或调整 |
| --- | --- |
| 来源正文完整 | 保留；这是来源层的完整，不要求全部成为声音。 |
| 每拍唯一镜头认领 | 分离内容所有权与实现引用，支持跨镜但防止重复发声。 |
| 台词逐字进入 prompt | 对已确认、锁定的发声文本继续执行；增加说话人和发声方式核验。 |
| 情绪必须有可见承载 | 改为有可感知证据，可由画面、声音及上下文共同承载。 |
| 字数与固定动作秒数 | 作为初估；关键场次增加试读或时间排演，不直接充当成片时长。 |
| 提示词 approved | 只表示可进入生成，不冒称成片 approved。 |

## 10. 怎样验证“一个镜头足够”？

### 10.1 两种审核问题必须分开

**来源审核者**读取原剧本、相关上下文和候选表达，检查遗漏、越权、错误推断及提前揭晓。

**理解检查者**只观看候选粗剪或成片，并获得正常观众已知的前情，不读取目标情绪标签和作者解释，然后回答：

- 谁做了什么决定？
- 哪个画面或声音支持这个判断？
- 关系发生了什么变化？
- 哪些事情仍不确定？

两者结果对照，才能发现“作者知道得太多，所以以为观众也懂”的问题。

独立模型可以辅助，但不能替代真实观众。首轮可采用小规模人工观看，并明确它不是统计性市场验证。

### 10.2 验证三种产物，不混称“通过”

| 阶段 | 可以判断 | 尚不能判断 |
| --- | --- | --- |
| 转译表与分镜 | 依据、权限、计划中的表达是否成立 | 实际表演是否成功 |
| 动态分镜与临时音频 | 节奏、基本理解、信息密度 | 最终画质、精细表演、完整口型 |
| 实际剪辑成片 | 声画事实、可读性、情绪与连续性 | 普遍传播效果或所有观众理解 |

ASR 可以辅助检查发声文本，OCR 可以辅助检查关键文字，视觉模型可以指出可疑片段。但 ASR 可能漏掉重叠声音，OCR 可能误识别，视觉模型也可能受目标说明暗示。关键内容仍需实际播放复核，并记录时间位置。

### 10.3 建议的自有测试场景

先确定每个故事和人工预期，再写分镜。每个 skill 后续采用各自独立的样例，不共用兄弟样例。

| 测试场景 | 要验证的问题 |
| --- | --- |
| 多句同义心理说明，原文已有明确动作 | 能否压缩说明而保留行动与情绪变化 |
| 一段心理说明包含尚未交代的具体背景 | 是否误以为一个表情能够交代事实 |
| 关键台词含否定、条件或承诺边界 | 压缩后是否改变立场 |
| 不可靠旁白与画面存在有意冲突 | 是否误把冲突修成同一种事实 |
| 同一句台词在不同位置重复 | 是否意外去重，或只播放一次 |
| 一条 VO 跨两个反应镜头 | 能否连续发声而不重复内容 |
| 沉默人物通过选择改变关系 | 是否只保留说话者、遗漏沉默角色 |
| 关键声音来自画外 | 是否错误补出声源或改变谁听到了 |
| 线索是数字、姓名或物件差异 | 是否有足够可读证据，而非只有气氛 |
| 故意保留未和解的结尾 | 微笑、音乐或镜头是否提前宣布和解 |
| 模型没做出关键微表情 | 是否发现失败，改用等价实现而非自称完成 |
| 文本很短，但动作和反应耗时很长 | 是否仍被字数估时压缩成不能理解的片段 |
| 竖屏、手机和实际播放音量 | 证据是否因尺寸、裁切或混音而不可感知 |

### 10.4 对照实验

选择同一批已获授权的短场景，比较：

A. 来源段落直接进入分镜。

B. 先分类并建立场次功能，再做受约束视听转译。

C. 在 B 上增加动态分镜与理解检查。

尽量保持模型版本、资产、目标时长与候选数量可比，随机安排观看顺序。记录一次性实验结果：

- 关键事实、选择和揭晓是否正确。
- 观众能否指出支持判断的证据。
- 有意保留的未知是否仍然未知。
- 锁定台词是否正确，是否出现不必要的解释性 VO。
- 重复表达、无效镜头、生成返工及实际成本。

质量和成本分别报告，不合成一个模糊的“电影感总分”。不预设 B 或 C 必然更好，也不把“减少镜头数”当作唯一成功标准。

这些只用于本次实验报告，不新增永久评分、失败累积日志或统计系统。

## 11. 实施顺序与待确认决策

### 11.1 建议实施顺序

1. **先确定权限和术语。** 明确什么是非发声说明，什么必须逐字保留，什么属于转译而非改写。
2. **人工跑通少量完整场景。** 从来源、转译到粗剪，验证现有文本能否表达关键差异。
3. **再确定最小契约。** 解决来源、正式内容和镜头的对应，不先建通用影视知识图谱。
4. **调整 script 与 creation 的实际消费。** 同步修改估时、覆盖、提示词材料和批准失效。
5. **增加内容理解和成片检查。** 不以 JSON 合法或提示词 approved 代替成片结论。
6. **最后优化并行与自动化。** 只有基准显示收益时，才扩展多 Agent 和更精细的检索。

### 11.2 修改原方案前需要确认的事项

- 是否允许非发声说明在不改变事实的条件下进行视听转译？
- 实际对白是否默认全部锁定，哪些类型允许提出删改？
- 哪些补充动作属于已授权导演细化，哪些必须逐项确认？
- 当前交付终点是结构化剧本、视频提示词，还是包含粗剪和成片审核？
- 主要题材、画幅、目标时长、模型与预算是什么？这些会影响实现，不应反过来统一改写所有故事。

本轮研究不需要提前锁定这些答案。正式修改方案和契约时再确认。

## 13. 最终建议

**不要在“逐字搬运”和“随意改编”之间二选一。建立第三种能力：可追溯、受约束、可验证的视听转译。**

原文层负责完整，叙事层负责不失真，表达层负责可感知，制作层负责实际完成。

一个镜头能够替代很多文字的前提，不是它看起来有情绪，而是它在正确的上下文中，确实保留了这场戏必须让观众理解的变化。
