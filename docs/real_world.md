真实感 = 不完美细节 + 松弛姿态 + 生活化环境 + 原生质感 + 不完美构图

### 1. 不完美细节（打破 AI「完美感」）

* **面部**：毛孔、细纹、法令纹、轻微泛红 / 痘印、眼下暗沉、不对称眼型 / 眉形
* **毛发**：碎发、毛躁感、发尾分叉、发际线不规整
* **服饰**：面料褶皱、穿着痕迹、线头、轻微磨损 / 污渍、领口 / 袖口变形
* **物品**：使用划痕、灰尘、污渍、半用状态（半杯咖啡、用了一半的笔）

### 2. 松弛姿态（拒绝机械感）

* **肢体**：避免对称 / 标准姿势，加入耸肩、歪头、手腕放松、手指微弯
* **表情**：自然半笑 / 微抿嘴，眼神带情绪（疲惫、温和、随意），拒绝「标准微笑」
* **动作**：模拟日常瞬间（刚拿起手机、随手挥手、撑脸），而非摆拍感

### 3. 生活化环境（拒绝样板间）

* **场景**：真实工位 / 居家角落，带轻微杂乱感（散落便签、数据线、半开抽屉）
* **光影**：自然光优先（夕阳 / 阴天 / 窗边光），避免均匀打光，保留明暗过渡
* **背景**：适度虚化但保留生活痕迹（模糊的同事、窗外街景、杂物）

### 4. 原生质感（拒绝磨皮滤镜）

* **皮肤**：保留原生纹理，拒绝过度平滑 / 美颜
* **材质**：衣物 / 物品保留真实质感（棉麻褶皱、金属划痕、塑料哑光感）
* **画质**：轻微噪点 / 颗粒感、手持抖动模糊、镜头反光，模拟真实拍摄设备

### 5. 不完美构图（拒绝 AI 对称感）

* **人物**：偏左 / 偏右、不居中，边缘可裁掉部分肢体
* **视角**：自拍 / 俯拍 / 侧拍，避免正脸平视的「证件照」感
* **比例**：打破完美黄金分割，模拟随手拍的随意感
