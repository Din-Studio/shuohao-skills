## 实施范围与契约

- `mint-outline`：仅解析已有剧本，采用 v4。保存原件版本、已读范围、事实与稳定身份。完整和部分来源分开，不补写缺集、结局或问题答案。
- `mint-script`：采用 v4，保留独立创作入口。解析时同时读取原件与 outline，形成唯一执行正文。行动、台词、字幕、声音与非发声说明分开。
- `mint-creation`：保持 v3，消费 v4 上游。接通 seed、brief、工作单检查、独立审核登记、apply 和 export。
- 编写／审核 skill 与四份角色说明：同步来源、声音、权限与批准依据。工作单仍可编辑，报告仍从 JSON 派生。
- 人物／美术：消费来源事实，保留 tier／primary、别名证据和状态限制。来源事实与制作补定分开展示。同名对象依赖稳定 ID，装配、报告、关系与图片路径不合并身份。
- setup、根中英文 README、流程图、阶段文档、样例、迁移和跨阶段测试同步更新。每个 skill 的实现与样例仍可独立复制。

来源使用原始字节 SHA256。坐标按严格 UTF-8 解码后的物理行计算，LF／CRLF／裸 CR 均分行，末尾换行不增加空白行。文件路径相对所属阶段 JSON；派发时解析为实际来源路径。来源文档 ID、SHA256 和行数须在解析正文与 outline 间对应，不能通过换 ID 绕过版本检查。

outline 不再保存 adaptMode、adaptation、arcs、事件 position／kind／weight、reusePlan 或固定分钟数。script 的逐集 `targetSeconds` 是唯一执行目标；解析可以暂缺，制作入口必须检查。参数默认值不落盘，上游计划和项目要求不重复复制。

`migrate-v4` 显式保留原始字节、完整旧文档、移出字段及待核验事项，不凭空补证据。迁移草稿放在 `.work/`；补齐证据并核验后才能发布。历史 `migrate-v3` 保留独立回归，不能仅改版本号绕过新契约。

## 验证边界

自动测试中的批准是协议模拟，不是实际制作计划的独立语义批准。来源核验、样例语义回查和制作协议验证是不同结果，不合并为“成片通过”。

图片交接测试包含明确标记的非空技术占位字节，只验证路径、身份、依赖和摘要，不证明图片可用或视觉准确。声音校验只证明粗估容量与顺序可满足，不证明模型实际保持同一次声音。实际项目仍须确认转译授权、制作目标及模型是否能实现跨段衔接；无法保证时明确报告，不能自动重播或改写剧情。
